## Installer and bootstrap

SbfFinite_install.fixed_install() has no arguments. Public install entry raises
SystemExit before imports. It checks root IDs, null stdin/output access, inherited
FD inventory and a single thread, then literal fixed setup data. Directory
ancestors are root:root, nonwritable and opened component-relative nofollow.
Fresh 0700 directories are made exclusively. Existing roots fail; there is no
retry-overwrite, unlink, rename, chown, hardlink, reflink/clone, adopted staging,
sudoers, SETENV, general root reader or key cleanup operation.

Source opens compare captured uid/gid/mode/dev/inode/nlink/size/mtime/ctime for
all retained component FDs and alias entries. Links are read, compared against
literal targets and expanded through the admitted complete restart chain; kernel
link following is never used. Exact historical identities may deny a future
host even when bytes match; that requires new reviewed data rather than a waiver.
Historical source ownership is not changed or treated as destination immutability.

Each new file uses O_EXCL|O_NOFOLLOW, mode0600, regular root:root nlink1 and a new
inode distinct from source and every prior destination. Streaming enforces exact
length, SHA256, stable source FDs/chains and a deadline. Writer fsync/close precedes
fresh nofollow readback/hash/identity checks. All writers in BOTH trees close
before any file or directory sealing to0444/0555. Seal checks the complete finite
expected entry sets and rehashes files. Partial failure closes owned descriptors
and retains every created path. A future rerun needs a new reviewed root/name;
this one-shot source never chooses one dynamically.

The package is copied from literal source-pinned bytes in SbfFinite_inventory.py,
not from a user staging inode. SbfFinite-installation.json pins every payload file
and external bootstrap files; package_pins.py cannot authenticate itself. The
initial interpreter, source-loader, installer and inventory bytes require external
lead-reviewed authentication; a self-hash cannot supply that authority. This is
an explicit retained source/bootstrap trust boundary, not a cryptographic waiver.
The proposed fixed noargument root launcher is source text only. It rejects args,
executes only fixed env-i/Python argv, and lands at a currently unconditional
denial. It is not installed by this installer, and no sudo policy is published.

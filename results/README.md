# Measurement and replay records

Runtime measurements, compute-unit records, binary hashes and proof replays.
Release manifests, scripts and research notes refer to these directories by
path, so dated directories stay where they were written.

- `v7-*`, `pool-v1-*`, `registry-v1-*`, `verifier-receipt-*`: dated V7
  and pool runtime records.
- `v7/`, `v8/`: smaller V7 test vectors and V8 research measurements.
- `spend/`: V5 and V6 spend measurements and mainnet cleanup evidence.
- `formal/`, `fuzz/`: formal-build and fuzzing records.

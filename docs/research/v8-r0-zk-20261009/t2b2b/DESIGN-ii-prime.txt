§1.4  Obstruction: (ii′) is false without a completeness premise

  Two F-linear functionals on Payload K vanish on range A:

  (O1) ι(v) := (roundPoly 0 v).eval 0 + (roundPoly 0 v).eval 1 − v .maskSum.
       For v = A t = L(tapeLinear t): L's maskSum is Σ_bits maskLinear(bits) and its
       round-0 polynomial is rounds ch 0 (a ↦ maskLinear a ·), so ι(L τ) = 0 for every
       trace τ by rounds_initial with maskLinear_vdeg (Shift.lean:330, any trace).
       On (★): ι(roundInclusion ΔOR) = bsum fOrig(u_w) − bsum fOrig(u_w′)
       (rounds_initial with vdeg_fOrig), ι(dir) = 0 (dir_mem_initialChain0).  So
         ι(cTilde w − cTilde w′) = bsumB 10 (fOrig x.1 B ch u_w ∘ ofBool)
                                  − bsumB 10 (fOrig x.1 B ch u_w′ ∘ ofBool).
  (O2) v .inactiveSum.  On range A it is Σ_c γ^c · Σ_{r ∈ copyInactiveRows}
       (tapeLinear t) c r = 0, because every lane that tapeLinear writes is balanced
       over copyInactiveRows (semantic noise at 1023, H1 padding and mask lanes at 0).
       On (★) it is γ^26 · (Σ_{r∈I} helper_w r − Σ_{r∈I} helper_w′ r) (semantic lanes
       of u_w are balanced; lanes 16..25, 27, 28 are 0).

  Counterexample shape: any HonestProver with two instances of equal public value,
  one satisfying the constraints and one not (e.g. one bad Poseidon row), at any ch
  with ch.sem 14 ≠ 0 and a zerocheck point zc for which the Boolean sum of the bad
  row's term is nonzero, violates (O1).  HonestProver admits such instances, so
  IIPrime P h B x is not provable for general h; it needs a premise.  (This is the
  "builder completeness" item left open since D11/D12, now pinned to the exact
  two equalities that (ii′) uses.)

§2.2  The structure of C1Lift / H1Lift: opened part STRUCTURAL, rest OPEN

  Per lane the target has, over F: opened 88 limbs (F-lane; 352 for the
  K₄-valued H1 lane), claims 3 values, extra 1, ood 2 (K₄ values: 4 limbs each,
  24 limbs; 24 for H1 as well) — 112 and 376 limbs, matching Z4c and
  DESIGN-T2b-2b §2.2.2.

  Lemma opened_prefix (STRUCTURAL; hypotheses D13Order π, ch.queries.card ≤ 22).
  For every target τ : ch.queries → Fin 4 → F (resp. K₄) there is a word v with
  coefficientsLinear π v supported on indices < 89, ∑ v = 0, and opened(v) = τ.
  Every such v lies in V_c (resp. P_26).
  Proof.
   (a) Realisability: rows π.symm k (k < 89) are in I and eligible in every
       semantic column (D13Order); π 1023 = 1023, so 1023 is not a prefix row.
       A zero-sum vector supported on prefix rows is eligibleLinear of the noise
       with those values (the 1023 balance receives −Σ = 0).  For H1 the padding
       balance row is 0; whether or not row 0 is a prefix row, every zero-sum
       prefix-supported K₄ vector is realised (if row 0 is a prefix row its value
       is the forced −Σ of the others).
   (b) Channels: by encoded_channels (R0/Fold.lean, after :86) and fibre_inverse
       (needs fibre_coordinates_nonzero, R0/Fold.lean:18), the four opened

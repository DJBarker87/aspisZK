§0  Summary

  A staged Lean model of the Rust pair-forest builder now exists
  (buildModel : Public K → ModelWitness K → Trace K, Wspend-shaped witness).
  NonCopyHolds of the model is proved for all seven families from named
  witness premises that mirror the Rust builder's own checks.  What remains
  for BuilderRefines on the model is CopyLinkBalance (136 links, generator
  plan in §4) and base typing; what remains for the Rust builder is the
  refinement of §6, where Poseidon is the hard part.  Proving the families
  exposed a relation gap: no builder at all satisfies BuilderRefines for
  Rspend, because the copy registry and the occupancy family force a
  non-zero change sentinel on transfers (§5, proved).

§3  The Lean model buildModel (R0Z/BuilderModel.lean, host 4201)

  ModelWitness K: Wspend's fields (SpendRelation.lean:15) with PairLeaf
    unfolded: inputValue/outputValue/changeValue : Fin (2^30), sk, salt,
    path : Fin 24 → Bool × Digest K, pairFirst/pairOccupied/pairSecond/
    pairInverse, recipient/change owner and salt.
  Stage B  BlockIn {pre, absorb}; blockIter (rows 0..11 by
    poseidonTransition), blockDigest (row 11 lanes 0..7), blockCell (row 12 =
    absorb, rows 13..15 = 0); spongeInit, nodeIn (pre = [0^8, right, right[7]
    + 0x41531005], absorb = left), ordered.
  Stage W  ownerB, noteB0/1/2 (chunks owner | value, asset, salt[0..6) |
    salt[6..8)), nulB0/1, treeNode/treeCur (24 levels: blocks 4..24, 54..56),
    appBit/appSib/appNode/appCur (blocks 34..53; sibling = emptyRootsNat table
    for a 0 bit, snapshot frontier for a 1 bit), recipB (three zero blocks for
    a withdrawal), outPairB, blocksOf : Fin 57 → BlockIn, pathAuxOf,
    valuesOf, inOccOf, outOccOf (two_outputs / single_output), cellsOf.
  Stage A/M  auxCell (path rows 912..1007, value rows 1008..1016/1020/1022,
    occupancy 1017/1018), layout : Cells → Trace (columns 16..28 = 0).
  buildModel pub w := layout (cellsOf pub w).

  Modelling choices that the refinement (§6) must justify:
  (m1) block rows are DEFINED by the canonical transition; the Rust rows are
       the optimised raw-limb rounds (P2:362-410).  This is the existing
       raw-limb boundary of CoreExt.lean, moved from the verifier side to the
       builder side.
  (m2) the empty-root siblings are the frozen table (EmptyRoots.lean); Rust
       recomputes them (pair_empty_roots PT:217-225).
  (m3) the path aux levels 0..20 are written from the same (current,
       sibling, bit) as the node; Rust reads them back from the legacy
       blocks (FT:216-224).  Equal by write_node's layout (node_left =
       absorption, node_right = pre[8..16) minus the tweak, which is exact
       in M31).
  (m4) Rust aborts on any failed check; the model is total and the checks
       become the premises AuxPremises / DigestPremises.
  (m5) cells are K-valued; BaseTyped (values in the base subfield F) of
       buildModel is NOT yet proved (Poseidon constants and field operations
       stay in F; a closure lemma), so `BuilderSpec` is not yet instantiated.

§5  Finding: the change-sentinel gap in Rspend (PROVED, hosts 4211, 4212)

  change_sentinel_of_balance (BuilderModelSentinel): for any trace A with
  Holds occupancyFamily, Holds digestFamily and CopyLinkBalance, and
  pub.variant = privateTransfer, pub.change 7 ≠ 0.  Mechanism: copy link
  1124073492 (transfer-only) equates row 523 cols 0..7 (change digest) with
  row 1018 cols 2..9; occupancy row 1018 needs A9·A1 − A0 = 0 with A0 = 1.
  refines_forces_sentinel (BuilderModelBridge): BuilderRefines S Rel ⇒ every
  transfer instance of Rel has pub.change 7 ≠ 0, for EVERY builder S.

  Rspend (SpendRelation.lean:41) has no such clause, so `BuilderRefines S
  Rspend` is unsatisfiable as soon as Rspend has a transfer instance whose
  change commitment ends in a zero limb (a ≈2^-31 event per salt).  The Rust
  builder aborts in exactly this case (two_outputs PP:206-226, "a zero
  sentinel is a retry condition for note-salt generation").  Required
  change (lead decision): instantiate Rel := Rspend ∧ (variant = transfer →
  change[7] ≠ 0), i.e. the relation of instances the honest prover actually
  proves, and account for the salt retry on the wallet side (it is a
  witness-sampling retry before proving, not a proof-time abort, so it does
  not enter the HVZK argument; whether the retry affects the distribution
  of public values is not examined here).  The model carries it as AuxPremises.changeSentinel.

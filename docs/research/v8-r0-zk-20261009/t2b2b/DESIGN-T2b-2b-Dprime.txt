§1  Notation and the three natural-basis facts
----------------------------------------------
Notation (as DESIGN-T2b-2b §0 unless redefined).
  K₄ = QM31 (pack basis span), K = WideExact = K₄[v]/(v² − u), [K:K₄] = 2.
  σ : K → K the K₄-automorphism v ↦ −v (σ fixes K₄ pointwise, σ² = id).
  α := α_f = ch.opening 3 ∉ K₄ (K-deg, GoodOpen), ᾱ := σ(α).
  γ = ch.opening 0; a lane ℓ ∈ {m₀..m₉ (16..25), G (27), D (28)} enters the
  batch with γ^ℓ.  For a lane coefficient vector c (K₄- or F-valued),
      β(c) := (roundPolynomial (Q c) w, foldMessage α (Q c)) ∈ K^7 × K^256,
  Q = quotientLinear z₀ z₁ (prover::quotient; total, interpolant included),
  w = totalWeights (Lean `weights` incl. κ⁴·libraWeight, then
  quotient_weights, then τ·e1 + τ²·e2).  bat(m) = Σ_ℓ γ^ℓ β(c_ℓ(m)).
  Channels of a message q: q^(s)_d := q[4d+s] (s = 0..3, d < 256); fold
  fibre d reads exactly channel coordinate d of all four channels.
  lo := message indices 0..55 = channel coordinates d < 14 of all channels.
  f_lo := (f_0..f_13) ∈ K^14 (112 limbs).
  E_ℓ := evaluation-type own functionals of lane ℓ (2 OOD + 88 opened).
  Rw_ℓ := row-type own functionals (claim_0, claim_1, claim_2; extra).
  B₀ := common zero set of the 25 verifier relations (ia, S1, S2, 22×S3_u)
       in the batched space; dim_F B₀ = 1,912 (D21.2, MEASURED Z8c and
       STRUCTURAL as an upper bound, design §2.2.4).
  D-high := D words (balanced, `dWord`) whose natural coefficients 0..55
       vanish, i.e. rows π⁻¹(0..55) = PAD_ROWS[0..56) are zero.  D-high ⊆
       ker R_D (STRUCTURAL: pureRound_libra / L_pure_libra_coeff read only
       coefficients < 56; Z8d asserts it row by row).
  V_D := bat(D-high ∩ ker own_D)  (MEASURED 1,808, Z8c §5 control, Z8d §2).
  V_G := bat(G words ∩ ker R_G ∩ ker own_G)  (MEASURED 1,904, Z8c §6).

Fact 1 (x-multiplication law; STRUCTURAL).  For j < 511 let t be the number
of trailing one bits of j.  Then
    x·N_j = 2^{-t}·N_{j+1} + Σ_{s<t} 2^{-(s+1)}·N_{j-(2^{s+1}-1)}.
Proof: N_j = x^{j₀}·N′_{j>>1}(T₂(x)) with N′ the natural basis in u = T₂(x)
(N_{2m} = N′_m∘T₂ because T_{2^{b+1}} = T_{2^b}∘T₂).  For j even x·N_j =
N_{j+1}.  For j odd, x² = (1+u)/2 gives x·N_j = ½N_{j-1} + ½·lift(u·N′_{j>>1}),
and induction on the level.  (Checked exhaustively for all j < 511 in the toy
of §4.2; Lean: an induction on the bits of j over naturalLinePoly,
CircleNaturalBasisEval.lean:39.)
Consequence: multiplication by x moves natural index j only up by one or
down by clearing a run of trailing ones; the only way to reach an index
below 28 from an index ≥ 28 is through j = 2^i − 1 (and, for x², through
2^i − 2).

Fact 2 (the wrap set; STRUCTURAL from Fact 1).  Let L = a + b·x + c·y be the
chord line (Secant, chord.rs; chordMessage in Lean), acting on messages by
(Lq)₀ = a·p0 + b·x·p0 + c·(1 − x²)·p1,  (Lq)₁ = c·p0 + a·p1 + b·x·p1
(chord_message, chord.rs).  Then the natural coordinates 0..55 of Lq depend
only on q_lo and on the 15 wrap coordinates
    X = {61,62,63, 125,126,127, 253,254,255, 509,510,511, 1021,1022,1023}
      = channel coordinates d ∈ {15, 31, 63, 127, 255}, channels s ∈ {1,2,3}:
    (Lq)_lo = C_ll·q_lo + C_lX·q_X                                     (★)
with C_ll, C_lX the corresponding blocks of the natural-coordinate matrix of
q ↦ Lq (entries polynomial in a, b, c ∈ K₄).  The quotient image is
{q : e1 q = e2 q = 0}; e1 reads only q[1023], e2 only q[1021], q[1022],
q[1023] (FunctionalWeights.e1/e2, chord.rs), so both live on X.
(Z8e: the measured set equals X on every vector; the toy of §4.2 too.)

Fact 3 (the conjugate fold relation; STRUCTURAL).  round_eval
(RoundNormalization.lean:55) holds for every evaluation point.  For a
K₄-valued q, foldMessage_eq_sum gives σ(foldMessage α q) = foldMessage ᾱ q.
Hence for every lane ℓ whose coefficient vector is K₄-valued (G, D) and
every K₄-valued q:
    η_ℓ(γ^ℓ·β-image) = 0,  where for (h, f) ∈ K^7 × K^256
    η_ℓ(h, f) := h(ᾱ) − γ^ℓ·quarter·Σ_d σ(γ^{-ℓ}·f_d)·citedDualFold ᾱ w d.
η_ℓ is σ-semilinear, hence F-linear (and K₄-linear) but not K-linear:
one K-value, 8 F-functionals.  It is not a consequence of the 25 relations:
for lanes ℓ ≠ ℓ′, η_ℓ evaluated on γ^{ℓ′}·β(c) equals
(γ^{ℓ′} − γ^ℓ·σ(γ)^{ℓ′−ℓ})·roundPolynomial(Qc, w)(ᾱ), which is nonzero as
soon as γ ∉ K₄ and the conjugate round value is nonzero.  F-valued mask
lanes satisfy one such relation for every K/F-conjugate of α; they play no
role below.

§2.1  Where (B) stands and what replaces §2.5

(B) is BCond ch := (ker ownMap ⊓ ker R).map batMap = (ker ownMap).map batMap
(J3, unchanged).  bat(ker own) = B₀ (D21.2).  The withdrawn §2.5 tried to
prove (B) with a coordinate split of B₀ (f_0..f_13 from G, the rest from
D-high).  In the natural basis that split does not exist (D22.2), but the
two absorbers still assemble to 1,912 on every structure (D21.5, D22.3).
This design keeps the two absorbers and replaces the coordinate split by an
exact description of what D-high misses.

  Lemma B-glue (new, STRUCTURAL; J3/J7).  Let
     Dhigh   := {m : M K F | m.1 = 0 ∧ m.2.1 = 0 ∧
                  ∀ k : Fin 1024, k.val < 56 → coeffsLinear π (dWord B m.2.2) k = 0}
     Gonly   := {m : M K F | m.1 = 0 ∧ m.2.2 = 0}
     V_D     := (Dhigh ⊓ ker ownMap).map batMap
     V_G     := (Gonly ⊓ ker R ⊓ ker ownMap).map batMap
  Then  GoodCircle ch → B0 ch ≤ V_D ⊔ V_G → BCond ch.
  Proof.  Dhigh ≤ ker R (D's round vector reads only coefficients < 56:
  pureRound_libra / L_pure_libra_coeff), so V_D ≤ (ker own ⊓ ker R).map bat;
  likewise V_G.  bat(ker own) ≤ B₀ is bat_ker_own_le (J4).  Hence
  bat(ker own ⊓ ker R) ≤ bat(ker own) ≤ B₀ ≤ V_D ⊔ V_G ≤ bat(ker own ⊓ ker R).  ∎
  The hypothesis B₀ ≤ V_D ⊔ V_G is the assembly that Z8c §6 and Z8d §3
  measured (1,912 on structures A, B, I, J, K, L, M and on four D-high
  variants).  Everything below describes V_D exactly and reduces the
  assembly to a statement about G alone.

§2.2  The D-high deficit, part 1: the low shadow (STRUCTURAL)

  def Wz (ch) : Submodule F (Fin 56 → K)  (new)
    := the F-span of {q_lo | q : InitialMessage K, q K₄-valued,
                      e1 q = 0, e2 (b c) q = 0,
                      ∀ k < 56, chordLinear a b c q k = 0}
    (a, b, c the secant coefficients of ch.circle 0, ch.circle 1; q_lo := q
     restricted to message indices 0..55)
  def lowFold (α) (v : Fin 56 → K) : Fin 14 → K := fun d => Σ_s α^s·v(4d+s)
  def lowShadow (ch) : Submodule F (Fin 14 → K)  (new)
    := Wz.map (γ^28 • lowFold α)

  Lemma Vd_low (new, STRUCTURAL given GoodCircle).
    ∀ b ∈ V_D, (fun d : Fin 14 => b.finalCoeff d) ∈ lowShadow ch.
  Proof.  For m ∈ Dhigh ⊓ ker own put c := coeffsLinear π (dWord B m.2.2);
  c is K₄-valued, c_k = 0 for k < 56 and oodLinear z_i c = 0.  With zero OOD
  the interpolant vanishes (interpolant_values), so q := quotientLinear z₀ z₁ c
  is the unique preimage of c under chordLinear in {e1 = e2 = 0} (image_iff,
  chordMessage_encoder, injectivity of the exact encoder).  Thus
  (chordLinear q)_k = c_k = 0 for k < 56, q_lo ∈ Wz, and the batched final
  coefficients of the D-lane are γ^28·foldMessage α q, whose first 14
  coordinates are γ^28·lowFold α q_lo (foldMessage_eq_sum).  ∎
  No dimension of Wz is used in the proof.  Facts 1–2 explain why Wz is
  small: (Lq)_lo = C_ll·q_lo + C_lX·q_X, so whenever C_ll is invertible
     Wz = −C_ll⁻¹·C_lX·(Adm),  Adm := {q_X ∈ K₄^X : e1 = e2 = 0},      (W)
  a closed form (C_ll, C_lX are explicit blocks of the natural-coordinate
  multiplication matrix of L; Fact 1 gives their entries).  Z8e measures
  rank C_ll = 56, a 13-dimensional solution space on lo ∪ X and
  dim_K₄ Wz = 4 (rank of C_lX on Adm), hence lowShadow has F-dimension 16
  limbs: exactly Z8c's "f[0..14) projection rank 16" on D-high (structure A,
  §4.1; the toy of §4.2 gives the same).

  This replaces §2.5.1.  In words: an OOD-zero message with natural
  coefficients 0..55 equal to zero has a quotient whose natural low block is
  determined by its 13 wrap coordinates through a rank-4 map, because
  multiplication by x moves natural indices down only by clearing trailing
  ones (Fact 1).  The x^28 picture was right that the low folds are
  constrained, wrong about how: they are not zero, they lie in a 2-K-dimensional
  space (16 limbs, not K-closed).

§2.3  The D-high deficit, part 2: the conjugate relation (STRUCTURAL)

  Lemma eta_single_lane (new, STRUCTURAL).  Let σ : K →+* K with σ x = x for
  x ∈ K4 B hB.  For every K₄-valued q and every ℓ,
    (relationLinear w (γ^ℓ • q)).eval (σ α)
      = γ^ℓ * quarter * dot (fun d => σ (γ^ℓ⁻¹ * foldMessage α (γ^ℓ • q) d))
                            (citedDualFold (σ α) w).
  Proof: round_eval at σ α; foldMessage_eq_sum and σ(Σ α^s q_s) = Σ (σα)^s q_s
  because q_s ∈ K₄.  ∎
  def etaRel (ℓ) : bat coordinates → K  (new): left side minus right side,
  with h the .openingCoeff cells and f the .finalCoeff cells.
  Corollary Vd_eta: ∀ b ∈ V_D, etaRel 28 b = 0.  (Also ∀ b ∈ V_G, etaRel 27 b = 0.)
  The automorphism σ is a premise of the same kind as PackField (§1.1 of the
  T2b-2b design): for WideExact = QM31[v]/(v² − u) it is v ↦ −v.

§2.4  The characterization of V_D (MEASURED; one direction STRUCTURAL)

  Statement DHighChar:
     V_D = B₀ ∩ {b | f_lo(b) ∈ lowShadow} ∩ ker etaRel 28.
  ⊆ is STRUCTURAL: bat_ker_own_le, Vd_low, Vd_eta.
  ⊇ is what Z8c/Z8d's 1,808 plus Z8e's left-kernel report establish
  numerically: the annihilator of V_D (304 limbs) is spanned by the 25
  relations (200), Ψ_lo := the 96 F-functionals on f_0..f_13 annihilating
  lowShadow, and etaRel 28 (8).  (Z8e item 2; §4.1 gives the receipt.)
  Count: 1,912 − 96 − 8 = 1,808.  The design's account of D-high is
  therefore complete: nothing in V_D's deficit is unexplained.

  Proof route for ⊇ (CONDITIONAL; one part not proved for all query sets).
  Fix a target b = (h, f) on the right-hand side.  Write f = γ^28(f′ + α f″)
  with f′, f″ K₄-valued (K = K₄ ⊕ αK₄, K-deg).  Unknown: a K₄-valued quotient
  message q with channels (A₀, A₁, B₀, B₁) := (q^(0), q^(1), q^(2), q^(3)),
  each a line polynomial of degree < 256 in the natural basis N′.
  (i)  Fold: A₀ = f′ − p·B₀ − r·B₁, A₁ = f″ − q′·B₀ − s·B₁ with α² = p + q′α,
       α³ = r + sα (p, q′, r, s ∈ K₄).  STRUCTURAL.
  (ii) Opened: opened(Lq) = 0 ⇔ Enc q vanishes at the 88 children
       (chordMessage_encoder, no_domain_zero) ⇔ all four channels vanish at
       the 22 line nodes (fibre_inverse; x_u, y_u ≠ 0).  S3_u gives
       f′(node_u) = f″(node_u) = 0 (node_u ∈ F), so (ii) ⇔ B₀, B₁ vanish at
       the nodes.  STRUCTURAL.
  (iii) The low/wrap block Z := lo ∪ X.  (Lq)_lo = 0 involves only q on Z
       (Fact 2).  Choose q_X ∈ Adm with γ^28·lowFold(−C_ll⁻¹C_lX q_X) = f_lo
       (possible: f_lo ∈ lowShadow) and with the channel-1 values at
       d ∈ D_X := {15,31,63,127,255} matching f″_d − q′B₀,d − sB₁,d, where
       B₀,d, B₁,d (d ∈ D_X) are themselves X-coordinates.  This needs the map
       Adm → (lowFold∘(−C_ll⁻¹C_lX), f″ on D_X) to have image lowShadow-preimage
       × K₄^5: CONDITIONAL in z and α_f (named GoodWrap).  At d = 255 the
       X-coordinates are tied by e1 (q[1023] = 0) and e2 (q[1021] against
       q[1022]), so f″_255 = (ρ + q′)·q[1022] with ρ = secantB/secantC (the
       leading coefficients of N₅₁₁ and N₅₁₀ are both 2^502), so the top fibre
       needs q′ ≠ −secantB/secantC: exactly the T2b-2b design's top-fibre
       condition "α_f + α_f²·(secantC/secantB) ∉ K₄" (§4.1 there).  GoodWrap
       is necessary for DHighChar ⊇ (the f″ components at D_X are functions
       of X-coordinates alone), so it holds wherever ⊇ was measured.
  (iv) Interpolation block: on the B-channel coordinates d ∈ J := [32, 54),
       evaluation at any 22 distinct nodes is invertible, because
       N′_{32+e} = N′_32·N′_e (e < 32) and N′_32(node) = T₃₂(node) ≠ 0.
       STRUCTURAL given (NZ): T_{2^k}(node_u) ≠ 0 for k ≤ 7 and distinct
       fibres have distinct nodes.  (NZ) is a circle-group order fact:
       node_u = x(2P_u) with P_u of order 2^21, and x(R) = 0 iff R has order 4.
       Not yet in Lean; small (fibre_coordinates_nonzero is the k = 0 case).
  (v)  What is left: 12 K₄-linear conditions (48 limbs) on the remaining
       B-coordinates: claim_0..2(Lq) = 0, ind(Lq) = 0 (the inactive-row sum;
       S2 ties it to h₀ + h₄), and the 8 K₄-dimensions of h not fixed by S1,
       S2 and etaRel 28.  They must be independent modulo the evaluation
       block (iv).  This is a Schur complement R_O − R_J·Ev_J⁻¹·Ev_O whose
       value depends on the query set through Ev.  I do not have a witness
       valid for every query set: `ind` is a fixed dense functional
       (810 of 1,024 rows are copy-inactive, Z8e layout line), so no choice of
       challenges makes the conditions vanish on the block J, which is what a
       uniform witness would need.  Call this TP_D (transversality of D-high);
       it is OPEN.  A candidate structural route is in §5 (R2).
  Hence DHighChar is: ⊆ proved; ⊇ MEASURED on structure A and reduced to
  GoodWrap (conditional, query-free) and TP_D (query-dependent, OPEN).

§2.5  The G part: what the assembly asks of G

  With DHighChar, the assembly B₀ ≤ V_D ⊔ V_G is equivalent to
     GCover:  T(V_G) = F^104,   T := (Ψ_lo, etaRel 28) restricted to B₀,
  i.e. G's own-silent round kernel must reach the 104-limb quotient
  B₀ / V_D.  MEASURED (Z8e item 3: rank of T on V_G).  GCover splits into
  three statements by the size and nature of what they need:

  Lemma lowfold_identity (new, STRUCTURAL given C_ll invertible; Facts 1–2).
  For every lane ℓ and every lane word with oodLinear z_i c = 0:
     f_lo(γ^ℓ·β(c)) − γ^ℓ·lowFold(C_ll⁻¹ c_lo) ∈ span_K (lowShadow).
  Proof: q := Q c satisfies L q = c, so by (★) q_lo = C_ll⁻¹(c_lo − C_lX q_X);
  the X-part q_X is admissible, so −C_ll⁻¹C_lX q_X ∈ Wz ⊗ K (take the message
  with that low part, that X part and zeros elsewhere).  ∎
  Let Ψ^K := the 80 F-functionals on f_0..f_13 annihilating span_K(lowShadow)
  (span_K has 32 limbs).  On own-silent G words,
     Ψ^K(f_lo(bat)) = Ψ^K(γ^27·lowFold(C_ll⁻¹·c_lo(G))),
  a function of G's natural coefficients 0..55 only, i.e. of the 56 rows
  PAD_ROWS[0..56) = π⁻¹(0..55).  (Z8e checks this identity exactly.)
  Then GCover follows from:
   (G1) G-low:  restriction of Gonly ⊓ ker R ⊓ ker own to the rows π⁻¹(0..55)
        is ker(extra) ⊂ K₄^56 (220 limbs).  PREMISE; MEASURED (Z8c, Z8d, Z8e:
        220).  This is the T2b-2b design's G-low, now with the extra claim
        accounted for (D21.5) and in the correct basis.
   (G2) Ψ^K∘γ^27∘lowFold∘C_ll⁻¹ maps ker(extra) onto F^80.  CONDITIONAL,
        coefficient-side only (z, α_f, γ, α through libraWeight), no rows, no
        queries; MEASURED (Z8e).

§5  Risks and open points
-------------------------
R1 (main) No proof route for (B) valid for all query sets.  Three of the
   pieces are query-dependent transversality statements: TP_D (§2.4 (v)),
   and G1/G3, or equivalently Gb = OT-open⁺_G (§2.5).  They are of the same
   kind as the T2b-2b design's OT-open (F7/O1): row-side or fixed
   functionals against evaluations at 22 queried fibres.  They are measured
   only on structure A, vectors 0–4.  On the other six Z8c structures only
   their joint consequence was measured (BCond and the assembly 1,912), not
   each piece.  No probability bound exists for their failure.

R2 Candidate route for TP_D and Gb (OPEN, not attempted beyond the
   statement).  Both reduce to: a fixed, query-free linear family Φ of
   functionals on a structured subspace S of messages must contain no
   nonzero member that is a combination of ≤ 22 point evaluations per
   channel.  On S := N′_128·K₄[u]_{<127} per B-channel (D-high: channel
   coordinates d ∈ [128, 255), clear of lo and of D_X; 22 + 12 ≤ 127 leaves
   room), or on G words
   supported on rows 512..1023 (see R5), a combination of k point
   evaluations is a functional of Hankel (moment) rank ≤ k.  So a sufficient,
   query-free condition is "every nonzero member of Φ|_S has Hankel rank
   ≥ 23 on some channel".  This is avoidance of a secant variety of a
   rational normal curve by a challenge-dependent linear space: a proper
   algebraic condition in the continuous challenges, whose bad set could be
   bounded by an effective degree (elimination) bound and a witness.  None
   of this is done: neither the degree bound nor a witness nor a check that
   the dimensions leave room (for G, Φ includes rowspace R_G restricted to
   the top half, up to 165 K₄-dimensions since rank R_G = 660 limbs).

R3 GoodWrap (§2.4 (iii)) and the invertibility of C_ll are conditional in
   the circle points only.  Each needs a nonvanishing witness and a degree
   bound through the circle sampler's parametrisation.  Z8e measures
   rank C_ll = 56 (K₄) on structure A; that is a witness for the polynomial
   being nonzero only once the computation is certified (it is an exact
   computation, but not a Lean one).

R4 Fact 1 and Fact 2 in Lean.  Fact 1 is an induction over naturalLinePoly;
   Fact 2 is its consequence for the 15-element wrap set and must be proved
   symbolically (AGENTS: no evaluation of 1,024 unit vectors in the kernel).
   Medium effort; the statement is small and the toy checks it exhaustively.

R5 Upper-half tensor structure (a lead for R2, not used above).  PAD_ROWS ⊂
   [13, 478], so the D13 transport is the identity on rows ≥ 479
   (transport.rs order(): every coefficient ≥ 89 is the next unused row,
   and all 89 pad rows are below 479).  On rows 512..1023 the row bits are
   the natural-index bits: message index m = 4d + s with r_9 = part,
   r_{8−b} = bit b of j = m>>1, so N_j(x)·y^part = ∏_i φ_i^{r_i} with
   φ = (T₂₅₆(x), …, T₂(x), x, y).  There the opened values are multilinear
   (monomial-basis) evaluations at the doubling points φ(P), the claims are
   eq-MLE evaluations at the opening points, and the inactive-row sum is a
   Boolean-face evaluation.  This makes OT-open-type statements statements
   about multilinear evaluations.  D13Order does not give "identity on rows
   ≥ 479"; Lean would need that registry fact as a refinement premise.

R6 K-structure premises: σ (§2.3) and K-deg (α_f ∉ K₄) are used by the
   structural lemmas; γ ∉ K₄ is needed for G3 to be true (if γ ∈ K₄, the
   conjugate relations of all lanes coincide).  All three are one-coset
   events with mass about P⁴·μ_W ≈ 2^-124 each, or field facts.

R7 Scope.  Clause (ii′) is still not covered.  The R1 payload (two folds, 64
   final values, D18 transport) changes the low block (the wrap set depends
   on where the low coordinates end), so Z9 must redo §2.2–2.5; Facts 1 and 3
   carry over unchanged.

## Stage 1: relative replay

`GamesR1.R1Adv` has just `prog` and `decide`, with no adversary cost semantics.
`GamesR1PBin.fsR1P.ideal` runs this program through the actual `runLog` at
`W.qmax`. Define the run-dependent quantity

```
n(adv; s) = W.qmax + sum (length row.key) over runLog of adv against s.
```

The oracle and the prepared state matter because adversaries adapt to answers.
This is overhead relative to oracle input length, not a bound on evaluation
of arbitrary Lean continuations or the final adversary decision function.
The reached-query sum is certified equal to the sum over `runLog`.

## Stage 4: adaptive lazy ROM sampling

`SimCostLazyCoupling.lazyRun` runs the actual `GamesR1.OProg` with a partial
cache and fresh independent uniform 256-bit answers. It caches misses,
reuses hits, preserves repeated addresses and consumes at most q fresh
answers (`lazy_draws`). The LHS does not read or materialize a whole ROM.
`lazy_uniform` proves equality of every rational log-observer expectation
with a uniform finite random function overriding the same initial cache.
Its key map is arbitrary and can encode out-of-domain handling. Only the
fresh-answer count is charged here; the existing byte-replay certificate
is not automatically a cost certificate for this new cache implementation.
This is an actual source coupling, not just pointwise erasure.

## Stage 5: compiled remaining metadata example

`SimCostRelativeObstruction` fixes the protocol field, basis and one callback
`outputs x _ = replicate x.handle 0`, with `CommitHandle = Nat`. Its actual
`simE` public-output projection has exactly that byte length. A recursive
byte-emission loop has exact cost equal to this length. For the no-query
adversary and **every** proposed fixed c,K0,d,q, choosing the handle
`c*(q+K0)^d+1` exceeds `c*(n+K0)^d`, while keeping the public field component
and the callback fixed. This improves on choosing a different callback per
bound: it is one allowed statement family and one allowed callback.

Quantifier limitation: this refutes a uniform bound over the full current
statement/handle interface from adversary queries alone. It does not refute
an efficient implementation for one fixed statement, constants depending on
that statement, or a bound that also charges the public input/output length.
The existing protocol specialization has not fixed these encodings or
supplied their work contracts. This example is not offered as a reason to
reject the D116 relative-replay notion, which is now proved.

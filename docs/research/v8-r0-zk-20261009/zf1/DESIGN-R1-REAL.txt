§1  The phase-indexed prover and the real game  (PROVED defs, R1Z/GamesR1P)
  An attempt is one read program over Pos1 = TRead ⊕ CPos, CPos = 3 roots ⊕
  2 expander streams (E₁, E₂ blocks) ⊕ RIdx (2 bindings, 3 seeds, 3×2^18
  salts, 3×2^18 leaves, 3×37448 non-root 8-ary nodes).  Every address is
  computed from the answers read so far in the prover's order Pr.ord, so the
  C2 root (after rows 0–1), the folded root (after row 29), the challenges
  chOf W tr and the tape are all evaluated on partial vectors (runC).  The
  statement digest H(public_bytes) is read first.  realGameP accepts the
  first attempt with P ∧ V ∧ ¬exhausted and publishes (view, verifier log:
  115 transcript reads + opening reads, answers H(address)), then the
  adversary log.  fsR1P.ideal = fsR1.ideal; abR1P = abR1.
§2  Frozen lazy programming  (PROVED, R1Z/LazyFrozen)
  progF skips writes into a fixed frozen set (the digest address);
  mean_progF is exact when addresses depend on earlier answers and on the
  table only through the frozen set; runC_spec; run_eqF.

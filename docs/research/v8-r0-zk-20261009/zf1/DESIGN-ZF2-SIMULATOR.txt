§1  The current simulator and why it is not one
------------------------------------------------
(SOURCE.)  `privacy_R1` (R1Z/PrivacyR1.lean, host 3763) proves
`ZK_FSV h (VR1 h) B outputs fs x ε` with
  ε = M·q/Umin + (M²/Umin + εexh) + Mi²/Umin + N·4096/Q.
The ideal side is `idealTestV h V …`, i.e. `fs.ideal (simV h B outputs x hx V)`.
`simV` (R0Z/HvzkV.lean:120) is

  if hch : ∃ w, V ch w ∧ h.public w = x.1
  then view h B outputs x (Classical.choose hch) ch
  else simulator h B outputs x hx ch            -- JointView.simulator,
                                                -- itself view … (Classical.choose hx)

So at every challenge the simulator runs the honest view of a witness picked
by choice from the instances valid at that challenge. The statement it proves
is a statistical one: the two view families have equal laws. It says nothing
about computing the ideal view from the public statement. `Classical.choose`
is not an algorithm, and in this setting no algorithm could implement it: an
instance with `h.public w = x.1` is a spend witness (note, path, keys), and
finding one from x would break soundness. The spend-path note
PRIVACY-RANK-PATH.md ("Efficient simulation, beyond witness independence")
records the same gap and names the stronger target used below: place the
normalised honest offset in a publicly computable coset of the mask image,
then sample masks.

The proof uses the witness in two places, and only the first must go:
  (i)  the definition of the simulator (simV / JointView.simulator);
  (ii) the proofs of the law equalities, which may quantify over and use
       any valid w.  A simulator is efficient if its definition is
       witness-free and polynomial-time; its correctness proof may use w.

§2  The honest law and the public coset data
---------------------------------------------
§2.1 The law (SOURCE; every step is a landed theorem).
  Fix ch with P_R1 h.transport B hB ch and w with h.public w = x.1,
  BaseTyped F (h.build w), HonestValid x.1 B (h.build w) ch, PublicBase F x.1.
  Write T = M × N (Partition.lean), A_ch = D12.A h.transport B ch : T →ₗ[F] Payload,
  Ψ_ch = Shift.shift x.1 B ch (a bijection, inverse unshift).
  * payload_eq_shift (Shift.lean:445), any ch:
      D12.payload h B x w ch t = Ψ_ch (cTilde w + A_ch t + sRem w t.2).
  * clause (i′), clause_i_R1_all (R1Z/ClauseIR1, host 3695):
      sRem w n ∈ range (A_ch ∘ inlM) for every n.
  * payload_law_on (Shift.lean:489) with AbsorptionLaw.mixture:
      EqualLaws (D12.payload h B x w ch) (t ↦ Ψ_ch (cTilde w + A_ch t)).
  * JointView.payload w ch = D12.payload w ch ∘ Partition.equiv.symm, and
    JointView.view = (metadata outputs x ch, JointView.payload …).
  So on P_R1 ∧ HonestValid the honest view at ch has the law of
      t ↦ (metadata outputs x ch, Ψ_ch (cTilde w + A_ch t)),   t uniform on T.

§2.2 Which parts are public.
  * metadata outputs x ch = ⟨x, ch, (x.2, ·), outputs x ch⟩: public.
  * Ψ_ch: reads x.1, B and ch only (originalOf, Shift.lean:132).
  * A_ch: reads h.transport, B and ch.  `transport` is a field of the
    HonestProver structure, not of the instance (ZkStatement.lean:304); on R1
    it is the fixed D18 permutation. Public.
  * The uniform tape t: sampled by the simulator.
  The only witness-dependent object is the class [cTilde w] in
  Payload / range A_ch (an F-quotient). Clause (ii′) (iiPrime_R1, host 3750)
  says that this class is the same for all valid w, but that is a statement
  of existence. It does not say how to compute the class.

§2.3 The silent functionals that pin the class (SOURCE).
  These are linear functionals φ with φ ∘ A_ch = 0. For each, the value on
  cTilde w is listed:
    ι = p₀(0)+p₀(1) − maskSum       iota_A;  ι(cTilde w) = Σ_b fOrig(u_w)(b)
                                     (iota_cTilde), = 0 for valid w
                                     (iota_cTilde_zero)
    .inactiveSum                     inactive_A;  = γ₀^26·Σ_{inactive} u_w[26]
                                     (inactive_cTilde), = 0 for valid w
    Φ₀ = evalRound9 − claimMask      Phi0_A;  Φ₀(cTilde w) = 0 for EVERY w
                                     when α₉ ≠ ½ (Phi0_cTilde)
    ChainEqs (9 chain equalities)    A_mem_chainEqs; cTilde w ∈ ChainEqs for
                                     EVERY w (cTilde_mem_chainEqs)
  Here u_w = PayloadSplit.actual x.1 B (h.build w) ch 0, and γ₀ = ch.opening 0.
  The rest of the annihilator is the relR1 / B0R1′ relations on the batched
  cells and the K₄-typing of the round cells. These hold for any K₄-valued
  payload trace (bat_L_mem_B0R1, L_round_mem, originalRounds_mem).
  The own cells (point claims, extra claims, OOD values, openings) are not
  pinned. Under C1Lift and H1Lift the noise image reaches them
  (noise_lift_R1).
  Only ι and .inactiveSum separate valid from invalid traces (§1.4 of
  DESIGN-ii-prime, not_iiPrime_witness / not_iiPrime_inactive). The other
  silent values are the same, and public, for every base-typed trace.

  A linear-solve simulator would need a basis of this annihilator together
  with its public right-hand sides: a rank computation of the Z9b kind per
  challenge. §3 avoids that. The (ii′) residual argument already shows that
  the list above is complete under P_R1. So a single explicit point in the
  coset is enough, and no elimination happens at simulation time.

§3  Candidate public points
----------------------------
§3.1 The dummy witness through the honest builder fails (DERIVED from SOURCE).
  Take a public dummy trace d, for example the public columns with every
  private cell zero, and run the honest pipeline: u_d = actual x.1 B d ch 0
  (prepare computes the H1 helper lane from d, λ and χ). In general d is
  not HonestValid:
    * production lanes: laneOf u_d … ≠ 0 at rows where a constraint with
      public constants (Poseidon round constants, selectors, the copy
      residual) is not met by zero private cells;
    * the helper sums: Σ_r u_d[26] r ≠ 0 and Σ_{inactive} u_d[26] r ≠ 0 in
      general.  The LogUp helper of a non-witness is unbalanced, and at a
      pole (χ equal to one of d's tuple values) it has no valid value at
      all (not_honestValid_of_pole, D40.2).
  Then ι(cTilde_d) = Σ_b fOrig(u_d)(b) =: S_d ≠ 0 in general, and
  .inactiveSum(cTilde_d) = γ₀^26·Σ_{inactive} u_d[26] ≠ 0 in general.
  By not_iiPrime_witness / not_iiPrime_inactive (HonestValid.lean:410, 421),
  cTilde_d − cTilde_w ∉ range A_ch whenever either value is nonzero. The two
  laws Ψ_ch(cTilde_· + A_ch t) then sit on disjoint cosets, so the
  statistical distance is 1. The verifier itself tells them apart: its
  initial sumcheck test p₀(0)+p₀(1) = H (the published mask sum) fails on
  the dummy view with probability 1. So "run the honest prover on a dummy
  witness" is not a simulator. This is the check the task asked for.

§3.3 What exactly defines the coset (answer).
  Under P_R1, the class of cTilde w in Payload / range A_ch, for every valid
  base-typed w, is the class of refPayload x.1 B ch. That payload is an
  explicit function of (pub = x.1, B, ch), and through A_ch of
  π = h.transport. It does not depend on x.2 (the commit handle), on
  `outputs`, or on any instance. A canonical public point exists: the
  zero payload trace, with the single field element S₀ added to the mask-sum
  cell and the D14 direction removed. Under the D29 rejection rule nothing
  extra about the challenge is needed. The conditions Claim Z uses are the
  conjuncts of P_R1 (HalfOK, SemK4, QPrime_R1, BCondG_R1, C1Lift, H1Lift)
  plus PublicBase. No obstruction appeared.

§4  The simulator algorithm and its cost
-----------------------------------------
§4.1 Algorithm SimR1 (PROPOSED; the Lean definition is in §5).
  Input: the public statement x = (pub, handle), outputs, the fixed π = D18
  and basis B, a challenge vector ch, and a uniform tape t on
  JointView.Tape K F (affine mask tape plus eligible noise).
    1. s := Partition.equiv.symm t ∈ T = M × N. This is a coordinate
       permutation: the same tape bits, relabelled.
    2. τ := JointTrace.tapeLinear B s. This is the pure-tape trace: the
       mask-only lanes 16..25, H1 padding in lane 26, G in 27, D in 28, and
       eligible C1 noise in lanes 0..15 balanced at row 1023. No witness
       enters.
    3. a := PayloadSplit.L π B ch τ, the linear payload of τ: the
       mask-polynomial round coefficients, the mask sum, claims, extra
       claims, OOD values, openings and batched/folded cells.
    4. r := refPayload pub B ch (§3.2): the ten zerocheck round polynomials
       of the zero payload trace, i.e. the constraint polynomial with every
       trace opening zero and only the public data present, minus k₀·dir,
       with S₀ added at the mask-sum cell.
    5. Output (metadata outputs x ch, Ψ_ch(r + a)). Ψ_ch adds
       originalOf(·)·(α₉−½)⁻¹·dir, and originalOf is one terminalValue
       evaluation at the point claims.
  In the FS ideal game the challenges come from the same capped retry loop
  as the prover's: draw ch, evaluate the public P_R1, retry up to N = 8,
  and take the failure exit otherwise. ZF1 already models this
  (middleIdealAbortV, which calls the simulator only at an accepted
  attempt). SimR1 has no other input. It never reads an instance, never
  calls Classical.choose, and solves no linear system.

§4.2 Why the output has the honest law (DERIVED; the §5 theorem).
  r + A_ch s and cTilde w + A_ch s have equal laws for uniform s, because
  their offset lies in range A_ch (Claim Z, then
  AffineLaw.equal_laws_of_mask_image). Apply Ψ_ch (equalLaws_comp), then
  clause (i′) (payload_law_on), then the tape relabelling
  (AbsorptionLaw.equal_laws_of_equiv), then the constant metadata
  (AffineLaw.equal_laws_const_pair). This is the proof of hvzk_on_of, with
  cTilde w′ of the chosen witness replaced by refPayload.

§4.3 Cost (ESTIMATED by operation count; the P_R1 figure is MEASURED).
  Linear algebra at simulation time: none. The coset point is explicit, so
  no elimination, rank or preimage computation runs. The only eliminations
  in the whole simulator are inside the public predicate P_R1. It is the
  same check the honest prover runs (D38): QPrime_R1 over 12 lanes carrying
  1,084 limbs, and BCondG_R1 carrying 1,336 limbs plus the relR1 rank.
  MEASURED in D38.2 on the nuc: 22.6 s and 130 MB per attempt on the actual
  query sets, 16 s on coset sets. The expected number of attempts is
  1/Pr[P_R1], which is about 1 on all evidence so far.
  The remaining steps are polynomial and much smaller than one honest proof:
    * step 3, rounds: the mask polynomial is linear in τ. With the standard
      sumcheck table folding of state_only_zerocheck.rs, the cost is about
      29 lanes × 28 nodes × 2·1024 table entries ≈ 1.7·10⁶ K-operations.
      The naive Lean formula would take 28·1023 = 28,644 point evaluations ×
      3·29·1024-term dot products ≈ 2.5·10⁹, so an implementation must
      fold, as the prover does.
    * step 3, claims, extra claims and OOD: (3+1+2) points × 29 lanes ×
      1024 rows ≈ 1.8·10⁵.
    * step 3, openings at ≤ 22 queries × 4 positions × 29 lanes by direct
      evaluation of the 1024-coefficient lane polynomials ≈ 2.6·10⁶. The
      batched/folded cells are κ/γ-linear combinations of these. In the Lean
      model only FoldedOpen cells are non-zero (folded_unqueried_zero).
      The real view's final 64-coefficient message needs the full γ-batched
      fold, an O(n log n) FFT-sized job (n ≤ 2^18 folded cells), which the
      honest prover already performs.
    * step 4: one zerocheck of the public constraint polynomial (trace
      openings zero) over 1024 rows. That is the prover's own zerocheck
      with fewer terms, so it costs no more than the honest prover's
      zerocheck.
    * step 5: one terminalValue evaluation.
  So per accepted attempt the simulator costs at most one honest R1 proof's
  payload computation without witness generation, plus the 22.6 s P_R1
  check. A prototype timing was not run: with no linear algebra to
  prototype, z9b's elimination code does not apply. A timing of steps 3–5
  belongs to the Rust refinement item G-sim (§7).

§5.1 Generic in Bat (R0Z/RefPayload.lean).
  def msCell (s : K) : Payload K Bat := fun cell => match cell with
    | .maskSum => s
    | _ => 0
  def k0 (pub : Public K) (B : PackBasis F) (ch : Challenges K) : K :=
    fOrig pub B ch 0 (alpha ch) * (alpha ch 9 - 1/2)⁻¹
  def S0 (pub : Public K) (B : PackBasis F) (ch : Challenges K) : K :=

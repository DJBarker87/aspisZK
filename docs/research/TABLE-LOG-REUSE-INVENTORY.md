## First occurrence versus any occurrence

- `firstIdx` is the index of the first matching address, not an arbitrary matching read. `Before tr b a` compares first indices. `FS2.Duplex.traceFrom` starts at the first matching occurrence and retains the entire suffix (`FS2/Statement.lean:154-157`). `tableBefore` also stops at the first target occurrence, and the first point after that cut is absent from the preceding table.
- The standalone program equation `R0C.V3.DQ.eval_ask_trace` in `evidence/lean-semantic-prerequisites-20261013/sources/R0C.V3.DQDecodes.lean:90-91` is definitional: an `ask a` trace begins with `(a,H a)`. The separate `R0C.V3.R0Q.firstCell_mem` at `.../sources/R0C.V3.R0Q.lean:61-68` proves only that a sampler's firstCell address occurs somewhere in the evaluated trace. Generic `FS2.DuplexTrace.Read` likewise gives only membership. The old decoder theorem in `R0C.V3.DQDecodes.lean` uses chain-specific order/first-read lemmas when it needs `Before`; mere `Read` is not interchangeable with those.

# Canonical common pause for alpha extraction forks

Status: checked pairwise causal theorem; selected-matrix configuration producer
and alpha-transcript provenance remain open.

## What changed

The V7 start-only replay constructor already computes the first occurrence of
the requested transcript-driving input, reruns the exact frozen answer prefix
from the adversary start, pauses on the pending query, and only then programs
the fork output.  Its public operational predicate did not expose that exact
construction strongly enough to compare two forks.

The new V7 theorem
`map_success_exposes_driving_split_and_exact_prefix_run` adds no premise.  From
an actual successful `constructLegalReplay`, it recovers:

- the exact `splitAtDrivingQuery` result;
- the replay prefix, driving record and frozen first-run suffix; and
- the exact `runPrefix` execution which produced the pause.

Because `splitAtDrivingQuery` scans from the head, the exposed split is the
first occurrence of that input.  The theorem unfolds the private operational
constructor; it does not reconstruct a favourable split retrospectively.

`FSV8AlphaForkCommonPause.alpha_fork_outputs_share_exact_pause` instantiates
this result for two `alphaBoundaryConfiguration`s which have the same origin,
post-alpha-nonce transcript, resource controls and controller, and differ only
in `forkOutput`.  If both replay constructions succeed, it proves equality of:

- replay prefix;
- driving record;
- frozen first-run suffix after that record;
- exact prefix run;
- derived pause oracle; and
- residual adversary program.

The equality precedes programming.  It is not inferred from equal parsed
`kappa`, `tau` or `response0` values.

`ExtractionCollectorVerifiedSuccessfulMatrix.complete_constructs_successful_family`
also packages the previously proved cellwise bridge into a 29-by-4 family of
actual `SuccessfulReplay`s, preserving each submitted body, full accepted
record/digest, and the scheduled gamma/alpha labels.

## Hostile scope review

The review found the construction non-circular and confirmed that frozen
suffix equality means the suffix of the original first-run query list, not
equality of post-fork replay queries or returned bodies.

The following boundaries remain explicit:

1. `SameTapeExperimentOrigin` is a generic structure.  The final FS experiment
   must instantiate it through `makeSameTapeExperimentOrigin` (or prove the
   corresponding constructor facts).
2. `afterAlphaNonce` is still supplied.  A successful functional verifier run
   must construct this exact transcript and identify its candidate query with
   the adversary's first-run driving input, or charge the existing absent/late
   target alternatives.
3. The currently selected `CompleteMatrix` does not yet prove that every cell's
   configuration was generated by the relevant row's common
   `alphaBoundaryConfiguration`, nor that each programmed output represents the
   intended alpha label.
4. The theorem does not equate post-fork histories, bodies or responses.  Those
   are intentionally allowed to depend on alpha.

Accordingly this is the missing pairwise causal lemma, not yet the matrix-wide
producer or a probability result.

## Security implication and next gate

Fork-output variation itself no longer leaves common pre-alpha chronology as
an assumed equality: successful replays from the canonical configurations
provably share the exact pause.  No probability term is reduced yet.

The next gate is a configuration producer tying every selected matrix cell to
one row's source-derived `afterAlphaNonce` and intended fork output.  It must
retain the prior-query/absent/late-target cases instead of assuming the driving
query exists.  Global security bits remain unset; grinding contributes zero.

## The accepted-failure event stays total

Let `A` be actual complete repaired-verifier acceptance and `X` the specified
resource-bounded extractor returning a witness accepted by the authoritative
payment/context/settlement validator. Classify only **`A AND NOT X`**.
An accepted out-of-radius execution that extracts successfully is excluded
at the outset; absence of a 9,301-close anchor is never identified with
knowledge failure.

The following is the explicit accounting specification, not an already
proved source-to-probability partition. Rows use first-failure precedence.

| Accepted run / extractor outcome | Timing and treatment |
|---|---|
| Authentication, source or replay coupling unavailable | Retain failure mass: missing/late raw preimages, resource/fuel abort, restore mismatch, missing responses, cached/advance mismatch are not a single prequery event |
| Coupling available, but no early close C1 object | Defined at fixed C1 once the full authenticated-word interpretation is justified; retain arbitrary/far recovery contribution. `none` does not prove no valid witness exists |
| Early close C1 exists, private sampler exhausts | Later extractor event; charge the declared bounded private sampler, not honest nonce effort |
| Sampler completes, at least 129 sampled fibres bad | Common-sample tail event; the old exact conditional ledger applies only with its fixed-word/private-law premises |
| At most 128 sampled bad fibres but model/source decoder differs | Model decoder failure is excluded by the new theorem under its interfaces. Missing actual encoder/inverse/Rust refinement is a deterministic obligation, not an invented tiny probability |
| Coefficients recovered but validator returns no valid witness | Retain semantic/copy/point/ownership/path/positivity/public-context obligations; the amount leaf closes only its named residual slice |

Near-gamma good/small-Good, image validity, ordinary-row correctness and
pointwise query success remain separate classifiers inside this tree. The

The exact-invalid-image case reuses the existing joint game; it is not
treated as a post-hoc condition changing the remaining challenge law.
All scalar-acceptance/pointwise-failure and later relation-repair cases remain.

The completed tail constructor removes previously supplied boundary and

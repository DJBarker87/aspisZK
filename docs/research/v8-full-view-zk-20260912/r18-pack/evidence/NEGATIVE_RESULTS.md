1. Keep old source separators and failed original-row first271 design.
   This package does not delete or reinterpret those results.
2. A contiguous CODE-space first271 candidate reaches rank538, not601, in
   all four checked original-T models. Sparse placement cannot be accepted
   merely because the complete code-coordinate transform is invertible.
3. A bit-affine T with pivot13 reaches H1 rank517, not540, in all eight
   checked models. Its inverse, raw masks, cheap tensor and G checks pass.
   Do not adopt it. The23 missing dimensions are not a quantified attack,
   but they disqualify it from this packet's intended compatible-image gate.
4. The optional minimum-support T keeps pivot1023 and the exact89 initial
   pad images, and passes both H1/G screens. It is a DIFFERENT permutation
   from the rejected affine construction. It still requires actual source
   affine witness corrections and universal exceptional-prefix bounds.
5. R44's existing geometric compact-G implementation is slower on SBF than
   R43. This pack does not call it a win merely because it uses less memory
   or constructs fewer intermediate coefficients.

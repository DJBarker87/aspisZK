# R459–R462 indexed block/refill model components

R459 and R461 establish the accepted-coordinate indexed finite-tape/list count model. R463 shows that the prefix through `optionCount` contains one accepted entry iff any entry is accepted, and states the corresponding accepted-coordinate offset update. R460 relates the decoded eight-word block, initial acceptance result, and scan count to that model under position-sensitive accepted-value permutations. R462 relates the index-8 refill branch’s source-shaped calls, output, carry, transformed block, and stopping index under the block permutation; adaptive-prefix preservation assumes an explicit `Fresh` premise.

These results do not establish the actual four-coordinate execution/tape law or actual four-limb uniformity. See [the component bundle](evidence/r462-indexed-block-refill-permutation/README.md) for successful receipts and preserved rejected/module-identity history.

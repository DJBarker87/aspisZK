# R367: current ControlFlow execution lemmas

R367 stages the successful R364 generated `ControlFlow` types/functions and proves three direct execution equations over those emitted Lean definitions. The equations cover `branch` for either constructor, `from_output` for any `Unit`, and `from_residual` for any value of the emitted residual type `ControlFlow<(), Infallible>`. The residual proof eliminates the impossible `Continue` payload using the native empty `Infallible` type; the surviving `Break` case reduces the generated discriminant check and assertion.

The source modules are [Types.lean](lean/AspisR364ControlFlowPattern/Types.lean), [Funs.lean](lean/AspisR364ControlFlowPattern/Funs.lean), and [R367ControlFlowExecution.lean](lean/AspisV8R19/R367ControlFlowExecution.lean). Their execution boundary is exactly these three translated functions.

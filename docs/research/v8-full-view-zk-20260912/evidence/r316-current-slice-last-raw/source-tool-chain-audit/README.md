# R307–R316 saved source/tool chain audit

This is a read-only audit of saved LLBC, tool-source, translation, and Lean staging artifacts. It ran no build, translator, or Lean command. The executable audit checks only saved inputs and outputs; it makes no source-semantics or release-gate claim.

R294→R309 preserves the decoded R294 Type 9, Fun 5, and Fun 12 rows and all projected hash-cons values. R310 then failed on `Len` with no emitted output. R312 is an isolated one-file `PrePasses.ml` candidate: its saved tree checks show no shared regular-file inodes, the parent remained unchanged, and its optimized cached binary is retained on the host by hash. R314 used that binary and emitted `Slice.last` (Fun 12); no Lean compilation or template completion is reported.

R316 copied the original generated `Usize.sub` block and its failed raw compile into `artifacts/r316-slice-last-raw/rejected-old-subtraction-api/`. The saved raw compile failed at that identifier (`Unknown constant Aeneas.Std.Usize.sub`), exit 1, 0.91 s, peak RSS 2,518,168 KiB, swap 0. The dependent draft then failed because the raw module had no output, exit 1, 0.09 s, 184,772 KiB, swap 0. Both original logs are preserved. The lead-specified explicit adapter in the later staged raw file changes that one identifier to `UScalar.sub`; the saved binding audit says the remaining generated block is exact. This report records that decision without assessing its semantic adequacy.

The inspected pinned Std excerpt defines `UScalar.sub` as a `Result` operation that returns integer-overflow failure when the left value is smaller, and its existing `RangeIter` proof invokes `UScalar.sub_equiv` at `Usize` width. Their copied SHA-256 values are in `audit.json` and the `pinned-api/` files. The examined source clone was the pinned Aeneas candidate used for the campaign (recorded campaign revision 380c7d46c); it has no Git metadata. I did not locate an exact backend source line implementing LLBC `UncheckedSub` as Lean `Usize.sub`. Searches of the clone’s `src/symbolic`, `src/pure`, `src/extract`, `Translate.ml`, `TranslateCore.ml`, and `src/*.ml` found no `UncheckedSub`, `Usize.sub`, or `UScalar.sub` mapping. The saved source hashes for key inspected files are recorded in the JSON. Therefore this audit cannot substantiate the precise origin of the emitted name; the R314 generated body itself is the evidence of the emitted spelling.

R312 build resources are reported with their measurement boundaries: 5/7 GiB systemd and Docker caps, zero swap; container process RSS, Docker CLI RSS, sampled Docker cgroup peak, and systemd slice peak are separate fields. The 49 MB candidate binary is excluded from this copied audit bundle but retained on the host and identified by size/hash. `#print axioms` is not applicable because this audit compiled no Lean target.

This new diagnostic fixture contains a compiler-created mutable power capture and shared gamma capture, a higher-ranked FnMut generic caller, and a shared value argument. The caller returns the resulting power so that restoration cannot be discarded. It preserves source multiplication/addition operations and their possible overflow failures. It is not the actual selected verifier and proves no source-verifier execution theorem. The check is whether retained native binding metadata passes validation and allows the existing known-impl resolver to expose the callback as a direct call with all region arguments intact.

# R419 translation evidence index

This directory contains the pre-launch gate/runner history and the later approved translation result. `PRE-LAUNCH-README.md` and `pre-launch-plan.json` are preserved pre-run records whose prepared-only status was superseded by the approved launch saved under `output/` and `launch-history/`. Use `output/*/translate-command.json`, `translate.log`, `result.json`, and `translation-result.json` as the executed-run records. The translator exited 2 before generating any Lean output.

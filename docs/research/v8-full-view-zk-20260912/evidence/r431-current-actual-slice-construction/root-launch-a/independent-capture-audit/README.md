# Independent R431 saved-capture audit

This audit reads only the R431 saved LLBC and launch receipts. It does not run Charon, Cargo, Lean, or source tests. The standalone checker verifies the saved command against the R429 C snapshot, checks source/tool and metric receipts, and extracts complete unchanged declaration rows for the selected call/constructor chain.

The raw LLBC is `../saved-output/R431ActualSliceConstruction.llbc` (SHA-256 `df9180ee7c9959a7840d6edac0b756f007ef33ed0bd88bb36faf57a3e18f2358`), with `has_errors=false`. R429 C's command snapshot and LLBC match the predecessor hashes in the change receipt. Removing only the fresh destination and the two appended includes (`core::slice::_::iter`, `core::slice::iter::_::new`) makes the command equal to that snapshot. All frozen Rust source, Cargo files, baseline source, and four nightly stdlib hashes match their recorded before/after values.

# R804 literal selected-source rows

This package contains 213 green fixed-witness literal-row equalities in 54 focused modules, plus the previously green row-114 prototype. Each equality is proved by splitting only its listed nonzero selected columns, applying the corresponding R787 exact active cell theorem, and applying its R800 zero-outside-support theorem elsewhere.

All 54 generated modules have a matching green receipt and source snapshot. Every printed theorem reports only `propext`, `Classical.choice`, and `Quot.sound`. Five rejected attempts are retained: three Chunk00 renderer-plumbing attempts, one Chunk22 singleton-support renderer attempt, and one row1022 imported-name ambiguity.

The result binds these fixed matrix entries only. It does not establish rank, native execution, full source equality, or any privacy/security property.

## Existing type declaration representation and IDs

The generated Charon type AST provides a `type_decl` record, `Enum of variant list`, `variant` record, generic parameter and argument records, and `type_declaration_group` / `TypeGroup` / `NonRecGroup` constructors. `TypeDeclId` is generated by the `IdGen` functor. The source API exposes `TypeDeclId.fresh_stateful_generator`, `generator_from_id`, `of_int`, `fresh`, and a `Map.add` API. The inspected type declaration insertion examples in the source did not show an existing prepass that both allocates a fresh `TypeDeclId`, inserts a new type declaration into `crate.type_decls`, and inserts its ID into `crate.declarations`; the inventory therefore records the available data/API forms, not a complete insertion pattern.

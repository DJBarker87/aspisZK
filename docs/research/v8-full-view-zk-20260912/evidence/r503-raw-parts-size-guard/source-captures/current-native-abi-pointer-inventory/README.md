# Current R495 type and pointer source inventory

The two adjacent Markdown files are byte-for-byte copies of the current R495 inventory notes from `.r21-scratch/r495-parser-iterator-dependencies/`. They are the requested source revision for the current type-rendering and pointer-handling discussion. The older R430 inventory is intentionally not included here.

These files record source/type observations and implementation boundaries. They do not prove that an eight-byte native pointer or `usize` corresponds to fixed `U64`, do not supply memory semantics, and do not establish a source-to-Lean execution bridge for R501. They are inventory evidence only.

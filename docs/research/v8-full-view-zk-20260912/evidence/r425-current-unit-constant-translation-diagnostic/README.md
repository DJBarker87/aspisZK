# R425 selected diagnostic bundle draft

This bundle collects selected R425 source snapshots, API/source excerpts, LLBC input provenance, runner scripts, build and fixture receipts, complete logs, saved audits, and one failed translation. It excludes executable binaries and build caches. `R425_CURRENT_UNIT_CONSTANT_TRANSLATION_DIAGNOSTIC.md` describes the narrow evidence boundary. `verify_bundle.py` checks the immutable file inventory and principal run statuses without invoking tools or modifying artifacts.

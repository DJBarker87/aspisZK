## Avoiding exponential reduction

R37's `rootRun` is a function-valued recurrence. Direct concrete evaluation
could duplicate its 27-coordinate sum at each of 22 stages. R38 never
asks Lean to normalize that whole term.

`RootCertificate.lean` proves generic symbolic rules:

- `root_step`: a checked next vector plus the remaining run proves the
  corresponding cons-root run;
- `root_append`: compose two root lists through the intermediate vector;
- `shift_step`: a checked one-step product advances an already certified
  n-fold shift.

The literal data vectors are elements of `ZMod 2147483647`. This is the
same base ring as the retained R15 `ExactTowerBase.M31Exact`; no new field
or hiding assumption is introduced. Half is the canonical residue
1073741824. Ring operations suffice for these certificates; no assumed
primality or inverse theorem is needed for the step checks themselves.

The first concrete preflight checks one coefficient of the first root
step using ordinary kernel `decide`. The generator then emits 22 separate
root-step leaves and four shift-step leaves, each comparing 27 coordinates
of **one** operation on literal input data. No leaf unfolds `rootRun`.
The bridge applies the named symbolic rule 22 times instead of expanding
the recurrence. There is no `native_decide`, sorry, extra axiom, broad
`norm_num`, or giant recurrence reduction in the generated leaves.

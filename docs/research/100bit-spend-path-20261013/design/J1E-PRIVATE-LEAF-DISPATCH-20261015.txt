What this closes and what follows

This supplies an actual extracted-graph control-flow lemma, not a theorem about
all Rust executions. The executable JSON importer is pinned and tested but its
semantic preservation is unproved. Rust lowering, Charon preservation, the
release callback binding, callback-internal effects, all other runtime effects,
and the full source-prefix simulation remain OPEN. An arbitrary HashFn can do
many hashes, recurse, panic or diverge: <=1 dispatch never means <=1 SHA without
the separate actual callback binding/effect lemma. Pure Aeneas value equality
cannot distinguish duplicate identical hash calls and does not retain a trace
on failure; repairing arrow translation alone does not prove the cost bound.

Smallest next proof obligation: define dispatch-labelled small-step semantics
for the accepted ULLBC subset (storage, local assignment, dynamic call and its
two continuations), then prove this importer preserves every finite execution
prefix into the generated graph. Callback entry must precede completion, with
normal, abort and nonreturning prefixes retained. Separately connect the actual
admitted adapter's fixed hash callback to one designated SHA event, preserving
its runtime failures. Only then compose leaf callsite counts into merkle_path
and query_with_geometry. The latter's six-iteration paths require a checked
loop invariant, not multiplication of lexical occurrences. The 349/472
whole-source cap remains OPEN.

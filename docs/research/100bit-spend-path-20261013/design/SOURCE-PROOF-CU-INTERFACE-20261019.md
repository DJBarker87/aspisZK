# Proof-candidate and CU interface

The source/global-oracle full25 bridge (294bf719e) changes Lean only. The current composition array-copy proofs (6adb26fdc and successor two-fold result), separately named heap overwrite helper (9f17d03df), and circle explicit-match extraction are isolated source candidates; their correctness checks do not validate the CU bound for an adopted candidate artifact. Adoption must re-pin/rebuild and recheck the affected cost bound. The current production sources were not changed by these proof commits.

The separate CU review2c1f89896 reports a pre-registered conditional analytical result, not a Lean theorem about all adversarial executions. Its assumption5 (transcript-driven branches cannot be targeted without breaking Fiat–Shamir) must not be imported as a cryptographic fact. In a random oracle, an adversary can search distinct inputs for an ordinary output predicate without breaking Fiat–Shamir; if its probability is1/2, k independent trials give success probability1-2^(-k). Transcript causality does not itself make output-dependent execution cost constant. Any universal cost conclusion needs branch/iteration caps or a separately stated and justified probabilistic cost scope. This observation does not change the soundness ledger or the newly checked algebra/source-coupling theorems.

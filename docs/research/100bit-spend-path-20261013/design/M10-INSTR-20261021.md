## Stage 1: representation-sensitive parser work

`BinLeafLengthWork` instruments the list-cell visits made by the two length
checks in `BinMerkleLeafCodec.parse`. `parse_value` proves exact equality
with that parser, including failed parses. The charge excludes drop/take,
re-encoding equality and all surrounding extractor work: it is a partial
component, not a proposed full resource ledger.

`parse_replicate_work` proves symbolically that an input of `2+width+m`
zero bytes incurs `width+m` length visits. The packed-width check succeeds,
so the parser demands the salt suffix's full length even when it will reject
that length. `singleton_unbounded` constructs a one-entry log whose leaf-table
length component exceeds any prescribed bound. `no_entry_count_bound`
refutes **every** function of entry count as a uniform upper bound on this
component, hence also every polynomial of entry count.

The actual parser computes `data.2.length = 32` on the unrestricted suffix
`input.drop (2+width)`. `BinMerkleRecordedLog.leaves` applies the parser to
entries using `filterMap`. Failed parses are work too. A bound on stored
entry count does not bound stored byte count. The log type imposes no byte
length constraint. This is distinct from the previous repeated-entry issue.

Scope: this does not establish that a reachable accepting frozen run demands
this table, or a lower bound for every branch of the complete extractor.
In particular public-parser and private-bank abort branches must not be
silently treated as demanding recovery. A contradiction for the whole ledger
would require the corresponding demand/adequacy theorem. The proved result
blocks a standalone entry-count bound for the existing table component.

Receipts: `evidence/m10-instr-20261021/manifest.json`; exact commands, source
snapshots, dependency fingerprints, wall time, RSS, swaps and axiom reports
are retained per attempt. First attempt failed due to an ambiguous Byte alias;

## Stage 2: bounded replacement, with value refinement

An additive replacement avoids the unbounded traversal without changing the
parser's mathematical result. `BinLeafBoundedLength.test_value` identifies a
bounded recursive length test with `decide (xs.length = n)`.
`test_cost` bounds its constructor inspections by `n+1`. The replacement
`parse_value` proves equality with `BinMerkleLeafCodec.parse` on **all** inputs.
`parse_length_test_cost` gives `width+34` for its two length tests. It does not
count `drop`, `take`, equality or allocation; those are explicit remaining
components, rather than silently absorbed into a constant.

`BinLeafBoundedTable.leaves_value` proves the table's exact value equation.
`leaves_length_test_cost` bounds the length-test component by
`log.length*(width+34)`. It counts each occurrence, including duplicates and
failed parses. `leaves_bounded_log` specializes this to the single polynomial

```
p_width(Q) = (width + 34) * (Q + 1161).
```

For a fixed protocol width this polynomial has degree 1 and a fixed leading
constant `width+34`. This is **only** the table length-test component, not the
requested full-extractor polynomial. No full-extractor constant or degree has
been established. The initial packet stopped before extractor composition. The continuation
below completes that value-equivalence stage in new modules.
The initial bounded-parser attempt needed `dsimp only` before splitting its
let-bound conditional; the corrected source passes. No memory failure or
cap increase occurred.

Option A: actual-source interface, first a small feasibility pilot
Proposed new aspis_core::digest interface:
  pub trait Digest32: Copy {
      fn digest(&self, parts: &[&[u8]]) -> [u8; 32];
  }
Use a concrete zero-size release type SolanaDigest whose method executes
solana_program::hash::hashv(parts).to_bytes(). Native SHA, counted SHA, and
deterministic test backends get explicit types executing their existing bodies.
Do not implement the selected backend by storing/coercing a HashFn, blanket
Fn/FnMut adapter, dyn trait, or arbitrary opaque oracle. Callback effects are
still real method effects; this proposal adds no purity or one-SHA assumption.

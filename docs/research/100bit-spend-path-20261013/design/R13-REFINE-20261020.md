## Remaining premises and proof work

WIRE-TX2 boundaries used here are named Lean propositions:

- `R13WireToBin.DigestLaw` relates successful dictionary responses to one pure
  byte oracle after the concrete carrier conversion. It does not establish
  logged-call coverage, chronology, or common-oracle embedding (R10).
- `WireTx2.LeafDigestLaw` (`WireTx2LeafCalls.lean:12`) instantiates the opaque
  private-leaf backend. The source implementation is
  `crates/aspis-core/src/state_only_private_merkle.rs:46`.
- `ops.c1Tag = ok 113#u8` and `ops.c2Tag = ok 241#u8` instantiate the opaque
  source constants. The folded 114 tag is in the emitted body.
- `R13LeafSlices.SaltLaw` restores byte identity through the parameterized
  copy/unwrap conversion. WIRE-TX2 proves salt width from the array type;
  width alone cannot imply that conversion preserved those bytes.

The central source simulation is still **unproved**, and is not disguised
as a proved source theorem or a newly assumed axiom. Its required invariant
relates the occupied scratch-array prefix to `BinMultiproof.Active/Values`:

1. Refine the sorted u64 key construction and insertion-sort scan
   (`candidate.rs:92-113`, `:180-194`; `Funs:1443`). Preserve each original
   `(index,leaf)`, derive unique sorted in-range active indices and identify
   source duplicate conflict rejection with the Bin dedup postcondition.
   C1/C2 use `u`; folded uses `u/4` (`candidate.rs:96`). The Bin `run` function
   is not definitionally the source sort/scan and cannot replace this proof.
2. Refine the eighteen binary level loops (`Funs:1006,1111,1130,1173,1191`;
   `multiproof.rs:138-194`) to `BinMultiproof.Level/Accept`
   (`BinMultiproof.lean:39,46`). Prove overwrite isolation, ascending parents,
   occupied-adjacent pairing, parity-selected sibling order, source shifts
   versus natural division, checked counters, exact supplied-node order,
   and preservation of `Arity::Two`. Then establish terminal reachability and
   root-comparison soundness and apply the local terminal inversion.
3. Refine source `node_count` and six slot slices/capacities
   (`compact.rs:54-64`; `candidate.rs:196-202`; `Funs:1482-1512`). Prove the
   eight-byte padding scan covers the entire tail from its whole-word slot
   length. Derive `BinMultiproof.PaddedAccept` (`BinMultiproof.lean:132`)
   and the selected-prefix sibling reads. The padding theorem in this packet
   consumes model acceptance; it does not prove the source scan correct.
4. Lift the helper call equations through those loops and the three ordered
   trees, identify the source accepted-read set with `levelInputs` plus leaf
   reads, then use `accepted_family`. Its reverse containment does not by
   itself prove source trace coverage. Compose into actual accepted tx2.

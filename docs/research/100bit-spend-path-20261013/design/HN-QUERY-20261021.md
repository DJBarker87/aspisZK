## Stage 1: definitions and symbolic accounting

The adversary is `RawCutProverCompiler.Prover P`; `D` in the existing
endpoint is the literal protocol decoder, not the adversary. Define its
query budget by `∀ H, (eval H P).1.length ≤ Q`. This counts every issued
query, including memoized repeats, before honest verification. R19's
existing premise bounds total distinct first reads of the original
experiment by `Q+1161`; that premise alone does not identify Q with P's
own query count. The 1161 is the sum of the stage-1 and stage-2 fixed
verifier budgets. It stays in the collision term.

`DecoderQueryAccounting` proves by induction on arbitrary logs that starts
are bounded by issued queries, and by induction on lists of row traces that
one start per row implies at most 33 honest starts. The existing compiler
start-preservation theorem proves verifier replay adds zero. Together these
give recorded starts ≤ Q+33 under the explicit query budget and the local
`HonestRowStarts` contract. Discharging that contract is the next stage.

## Stage 2: proved honest constant and exact rational interval

`BinHonestStartFrames` rejects squeeze and advance addresses by frame shape
and strict initial parsing, and rejects row zero's extra absorb by the unified
decoder's initial component. `BinHonestQueryBudget` inducts on the query
sampler's tail and the list of verifier rows. Each ordinary row has at most
one start. The reseed row is conservatively charged two, so the proved
constant is **34**, uniform over all oracle answers, statements, proof tuples
and incoming tables, including malformed inputs. The compiler contributes
zero additional starts. No honest-sampler premise is needed for this bound.

This does not prove that 34 is necessary or that 33 is impossible. The extra
charge covers the 62-byte opening reseed call: a length argument alone does
not reject its generic absorb parser, whose tag is read at byte 32 inside the
trailing state. No assertion that this call actually creates an additional
recognised start is made; there is no compiled 34-start verifier counterexample.
The proved constant, rather than an unproved optimal constant, is used below.

`BinInitialQueryAccounting` defines distinct canonical initialisation inputs
using a filtered finite set. Its cardinality is bounded by issued adversarial
queries, hence by Q. The stronger requested initialisation-only charging is
exposed as exactly one named premise, `InitialisationCharging P`:

```lean
∀ (H : Bytes → State) (q : Bytes × State), q ∈ (eval H P).1 →
  ∀ T : Table Bytes State, dec q.1 T ≠ none → CanonicalInitial q.1
```

`DecoderFiniteStartSupport.starts_le_support` proves by induction over the
log that each fresh recognised address removes one member of a finite
residual support; cached repeats cannot spend it again. This gives the
adversary-start bound by distinct initial queries under the stated address
restriction. Under this premise the recorded count is at most distinct adversarial
initialisation queries +34. It is an explicit adversary restriction, not an
established protocol fact: the unchanged causal decoder also recognises
ordinary, reseed, opening, query and rho row starts; nothing in P's type or R19
charges those to distinct initialisation queries with coefficient one. This
work does not prove that stronger premise or an unconditional initial-only
bound. Crucially the endpoint below **does not use it**: charging all starts
to all issued queries is enough and is proved symbolically for arbitrary P.

`BinPerQueryNumeric.query_normalised` proves the full rational envelope

```
(Q+34)*15/2^109 + 6*(Q+1161)^2/2^256 + 2^-126 + 2^-454
  ≤ (Q+1)*2^-100
```

for every natural Q ≤
**14777960484892959601791002642008314224629686680** (above 2^153, hence
above 2^64). A generic convex-quadratic chord lemma transports the two exact
rational endpoint checks to the entire interval; no recurrence or large log
is evaluated. `maximal` proves failure of this envelope inequality at Qmax+1;
`largest_uniform_range` in the endpoint module proves no larger initial
segment can satisfy it. This is maximality for this conservative envelope,
not an assertion about actual adversarial failure probabilities.

## Stage 3: composed endpoint and release meaning

`R1FinalSoundnessBinPerQuery.final_soundness` retains every FirstReadBudget
source, transport, binary completion and M10 premise and all cost, returned
relation and abort conclusions. It adds only `AdversaryQueries P Q`, making
Q an actual bound on issued adversarial oracle queries rather than a free
slack variable in a total-read inequality. It removes no source obligations
and adds no assumption about the decoder's or honest verifier's start count.
The optional `InitialisationCharging` premise is absent from this theorem.

For release wording, **per oracle query** means that for an adversary issuing
at most Q queries to the shared random oracle, the conditional deployed
failure bound is at most (Q+1)·2^-100 over the stated range Q≤Qmax, with every
existing source-refinement, experiment-transport, binary-completion and cost
obligation still in force. Q counts the adversary's own queries, including
repeated inputs; it excludes honest verification and compiler replay. This
is a query-normalised Fiat–Shamir bound, not a constant 2^-100 bound per
transaction or per proof attempt. Honest reads contribute the proved
constant 34 in the linear term and the existing 1161 in the collision term.

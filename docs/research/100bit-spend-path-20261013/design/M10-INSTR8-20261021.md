## Stage 1: allocation-carrying interface

`AllocationStageSpecM10.StageSpec` extends the existing stage interface with
an allocation field indexed by that stage's exact work counter. Each annotation
carries separate `width_law : bits ≤ W*elements` and
`creation_work : elements ≤ work` obligations. The sequence constructor sums
executed allocations; failed prefixes keep their allocations and skip later
stages. Its one option-result cell is charged to bind's existing work unit.
Both allocation bounds are proved without axioms.

## New theorem interface

`RawSamplerSuffixCorrespondence` gives exact evaluation laws with an arbitrary
single oracle. `RawSamplerSuffixSourceFrames` identifies the actual source
reseed and length-prefixed opening preimages. `RawSamplerSuffixSourceBridge`
connects successful source block calls to those literal evaluation laws.
`RawDeployedTranscriptFormat` discharges the tag and parser/constructor format
for runs whose public is the selected parsed public statement.

htag shape for any run family whose public is
`SelectedTranscriptParams.publicStatement` on strictly parsed public bytes.

validities and the exact `CommitmentMessages` predicate

Checks, and public-statement mapping. The digest bytes are abstract and
independent of binary node arity. Transport of the binary compiler/recovered
words into the existing Checks interface is outside this parser-format
lemma and remains part of R12/R13/R16.

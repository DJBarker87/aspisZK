## Stage 1 — isolated Kani gates

All harnesses are cfg(kani)-only in the evidence crate. No whole stage is
invoked. `S2F_sourcecuts.py --check` reproduces four native metadata helpers,
recording every type/name substitution and the frozen checkpoint constant.
The helper's `try_data_len` is a cut reply projection, not a fabricated guard.
`S2F_Trusted.rs` is byte-identical to the three-cell, three-token, two-coordinate
spec checked by S2A kani-003; that contract is reused, not replayed. The four
SDK consumers use `stub_verified(sdk::step)` and call S2E's owned functions.
They cover success, conflict, saturation, aliases and an arbitrary cell's
counter frame; drop consumers start from an admitted live guard. Counter
consumers use empty owned vectors. The separate vector-frame consumers cover
all lengths 0–2 and arbitrary represented bytes in all three cells. They do
not establish a full-size payload/provenance relation by themselves.

Child-control gates deliberately use scalar Result/state carriers. They check
short-circuit/mapping control, not the concrete decoder, full statement,
Afterstate, verifier, digest or allocator implementations. S2G's concrete
contracts are not present in this branch. The S2E Children interface remains
a parameter; no arbitrary successful child implementation is adopted.

Excluded attempts: kani-001 failed during dependency linking because the linker
exhausted TasksMax64; a worker-private single-thread linker wrapper repairs the
environment without raising caps. Kani-002 timed out comparing checked-add
Results; replacement kani-003/004 splits value and overflow and projects the
numeric result/actual error arm. Kani-007 timed out on the scalar proof decision;
replacement kani-018 checks the selected exact error code with bounded control.
Kani-022's combined SDK/nonempty-Vec context was explicitly stopped at formula-
growth review (about 6.5 million KiB RSS); no memory cap was raised. Replacement
kani-023/024 isolates the owned byte frame from native primitive payload framing.
The latter remains the previously checked SDK contract. No timed-out or stopped
job was rerun unchanged. Raw failures and complete source snapshots are retained.

Every result has exact target, command, source revision/hash, dependency
fingerprint, exit, wall, RSS, swaps and cgroup/reservation receipts. Kani axioms
are N/A. Rust compilation reports an optimized profile. No shipped file, key,
other worktree, candidate or release artifact changed. No ELF rebuild ran.

## Stage 2 — checked sequence and stage2 reference composition

`S2F_Sequence.sequence_simulation` composes local step laws over one fixed
original input index, retaining error/abort states. `paired_success` constructs
all intermediate paired successful cuts by induction; it assumes neither
successful child observations nor a whole-stage equality. Its local StepLaw
premises are NOT instantiated for the concrete native caller. The labels and
stage lists are a proposed source-cut schedule, not an extracted native CFG.
Error states must already contain the actual cleanup/effects of their source
transition; this generic interpreter does not supply compiler unwinding.
No theorem equates its reference evaluator with S2E's E. That port remains open.

`S2F_Stage2Cuts` inverts the ACTUAL S2E extraction into clear/validate/proof-
acquire/checkpoint-acquire/tail/drop cuts. The tail yields checked_add and
Ops.op2 observations, the same proof cell/end, exact public encoding and
length, actual selected range and checkpoint cell, TX2 reply/state and emit
reply/state. `S2F_Stage2Certificate.stage2_certificate` composes these into one
reference certificate on fixed originals. The sole successful execution input
is extracted stage2 success. No child success is an independent premise.
This closes S2E's missing stage2 REFERENCE composition, not native acceptance.
Ops and Children remain parameters. In particular op12 is not silently
instantiated to 1880, and the generic op2 is not silently treated as ok_or.

`S2F_Rejections` proves actual extracted stage1 shape/CP-borrow and stage2
account-count/CP-borrow rejection equations. The CP error states are retained;
no suffix child or newly acquired guard is invented. These local laws do not
certify every native rejection in S2D's inventory. Its OOM/abort, syscall,
query-prefix, compiler Drop and rollback obligations remain unchanged.

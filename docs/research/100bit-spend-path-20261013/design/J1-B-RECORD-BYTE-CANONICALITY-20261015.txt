The fixed carrier is an Aeneas Array U8 32 with bounded Fin32 byte reads.
For each Fin8 index i, wordLE reads bytes4i..4i+3 through the same existing
core.num.U32.from_le_bytes primitive as the generated decoder. These are
exact primitive calls, not a newly asserted arithmetic decoding function.
The fixed-reads theorem connects all32 generated reads to the eight-word
array. The fixed-success iff gives canonical bounds on all eight words and
their unchanged packing. The arbitrary-slice success theorem additionally
proves length32 and exhibits an array whose to_slice equals the input.

There is no fallback byte in this representation. The equality is within
the extracted value model; it proves no Rust pointer/provenance property.
Existing candidate-parser proofs are only a source-inspection aid and are
not imported or silently transported to the actual generated namespace.

## Stage 1: definition audit and obstruction

`LiteralTranscript.Public` abbreviates `UnifiedSampler.Public`, whose fields
are `pubBytes`, the address-length proof `initFits`, and `tag : Byte`.
There is no tag-equals-2 invariant in this type. `LiteralTranscript.valid 0`
is `True` for every `.initial root word`; it does not inspect the public.

The row-zero sampler calls `PublicInitFrame.addr` with public bytes and the
root. Its input is the initialization domain, zero separator, four-byte
public length, public bytes, and root bytes. The separate `Public.tag` is
absent. The sampler uses that tag later, in the row-26 opening reseed; that
use does not reject another value. `D` is the protocol's recovery decoder,
not a tag-admission check in the verifier's final decision. The binary
selector instead reconstructs tag 2. `BinDecoderInitialStarts.recognizes_initial`
therefore **requires** `htag : pub.tag = 2`; its theorem does not derive it.

The new proof target `InitialTagDecision.protocol_counterexample` directly refutes unconditional
`RWireCompletion.InitialTag`, for every decoder D, using the actual clean,
accepted recorded execution of `badProver 0` and the arbitrary permitted
decision `fun _ _ => true`. The construction uses the previously compiled
symbolic collision-mass counterexample; it evaluates no oracle space.

The requested global decision rejection law is:

```lean
def RejectsOtherTags (d : ErasedPrefix → ErasedMessage → Bool) : Prop :=
  ∀ pre message, pre.statement.tag ≠ 2 → d pre message = false
```

It is sufficient, but the requested implication from the old premise is
false. `global_not_implied` proves that the same always-accepting decision,
with `badProver 2`, satisfies `InitialTag` but fails `RejectsOtherTags` at a
tag-0 prefix. The old premise quantifies only one prover's reachable runs;
the global law also constrains unreachable inputs. Substituting that law
would strengthen the signature and is not done.

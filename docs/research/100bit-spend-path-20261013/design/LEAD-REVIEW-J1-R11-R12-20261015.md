## J1.R16 Decision: runtime pin

With G_R1.8 there is no PDA search on admitted routes, so QV depends on the
runtime only through two syscall semantics: `sol_sha256` computes FIPS 180-4
SHA-256 of the concatenated slices, and `sol_create_program_address` computes
one SHA-256 of `seeds ‖ program_id ‖ "ProgramDerivedAddress"` (and rejects
on-curve results). The release premise is exactly these two statements. The
release record names the Agave version observed on the target cluster at
release time and its source references for the two syscalls; the proof does
not depend on a version number. Local 4.2.1 is used for tests only.

## J1.R17 Decision: one Lean toolchain

The final claim is one kernel. Port up, not down: rebuild the Aeneas Lean
library and the extracted modules on Lean 4.32 (the R1 tree's version) on the
build host in its own capped scope (MemorySwapMax=0, explicit MemoryMax, one
Lean job at a time, no outer flock). If the pinned Aeneas does not support
4.32, report the exact incompatibility before any downgrade; a downgrade of the
R1 tree is a lead decision, not a default. The 4.31 results stay as evidence
until re-checked.

## J1.R18 Decision: extraction blockers

1. **Prefix** (Aeneas exits 2 at the returned records array): a reviewed
   source change is allowed. Return the records in a form Aeneas translates
   (e.g. fill a caller-provided fixed array in an index loop, or a struct of
   fixed fields), keep the byte behaviour identical, prove it by the existing
   serializer/parser differential suite plus the saved-proof hash-counter
   regression, and record the CU delta on one replay. No change of format.
2. **Sampler** (unresolved array/iterator externals, unverified quotient
   write-back): replace iterator chains in the extracted path by index loops,
   and give the write-back an explicit postcondition proved in Lean. No
   external is admitted as an axiom; any remaining opaque helper is listed
   with its contract and counted in the obligation inventory.

release formats. Recorded as a release note.

## Stage 1: definition audit and symbolic foundations

`RecordedBinaryExperimentBin.BinaryCompletion` concerns the exact binary
compiler and binary table chooser. `LiteralByteProtocol.protocol` does not
hash Merkle paths: the verifier runs the 33 literal samplers and finally
calls `decisionOnBytes d`. Thus the suggested explanation that the verifier
itself writes every required Merkle node is not the definition of this model.
The relevant fact is instead total Option-valued recovery stability: a
missing recovery stays missing, and the compiler installs the same default
metadata that the causal decoder restores. No successful opening hypothesis
is needed merely to align this metadata.

New `RWireMerkle*` and `RWireRawByte*` modules instantiate log-membership
extensionality and table/cut recovery for binary nodes, eighteen slots and
the five-reader collision event. This is not a transport of the eleven-reader
event. Proofs are symbolic list/path inductions and use existing binary
recovery witnesses; no large finite coordinate domain is evaluated.

`RWireCheckedFormat.format_of_checks` derives all 33 message-constructor
validity facts and both strict commitment-root parses from the existing
`LiteralAcceptanceTerminal.Checks` readers. `format_of_enrich` transports
these facts back to the original prover. No recomputation/path premise is
added to `d` by this stage.

Public selection is separately significant: `RawPublicInitRecovery.recover`
constructs tag 2, and `FullPublicSelection` uses the fixed tag in its later
branches. Completion for arbitrary public tags cannot be presumed merely
from collision exclusion. The subsequent bridge isolates this condition.

Receipts, including failed drafts, are in `evidence/rwire-20261021/manifest.json`.
Every attempt records source revision/SHA, ordered LEAN_PATH, direct import
hashes/fingerprint, exact argv/target, exit, wall time, peak RSS, swaps and
complete axiom reports. Failed error-recovery reports are not accepted axioms.
This is focused cached-object evidence, not a coherent frozen release replay.

## Stage 2: binary causal decoder and exact residual

`RWireRawBoundedCollision` derives only the legacy duplex/tail exclusions
needed by transcript decoding from the binary five-reader event. The
`RWireLiteralLegacyDecoderCompletion` / `RWireRawLiteralDecoderCompletion`
bridge then reconstructs erased transcripts. The existing decoder, sampler
and public selector definitions are reused unchanged.

`RWireRawCutLiteral*` proves chronological order of adjacent first frames for
the five-reader event. `RWireRawCutLaterTableLiteralWords` recovers each
already-committed binary map from the one current table. Log extensionality
removes order/duplication of the table representative; binary recovery
witnesses and append stability include both `some` and `none`. The three
root readers are the unchanged trailing/trailing/offset-38 readers, explicitly
bridged to binary indices 2/2/3. All coordinates are handled simultaneously.

`RWireRawAdaptiveCompiledCompletion.actual_compiled_transcript` composes
public selection, erased decoding, component-wise word restoration and
compiler replay, returning the exact literal prefix/message/challenge.
`RWireCompletion.completion_of_format` packages this as the exact
`RecordedBinaryExperimentBin.BinaryCompletion`, not a sibling experiment.
It assumes only the already-budgeted first-read bound, checked syntax/parser
facts, and the following residual:

```lean
def InitialTag (D : LiteralByteProtocol.Decoder)
    (d : ErasedPrefix → ErasedMessage → Bool) (P : Prover) (Q : Nat) : Prop :=
  ∀ H : Bytes → State, ¬ binaryCollision Q (eval H (recorded D d P)) →
    FS2.accepts (eval H (recorded D d P)) →
    LiteralTranscript.valid 0 ((eval H (recorded D d P)).2.1.2 0) →
    (eval H (recorded D d P)).2.1.1.tag = 2
```

The initial-row guard makes the law no stronger than required on arbitrary
malformed provers. Existing `Checks` supply that guard whenever it is used
by the endpoint. A concrete decision rejecting non-2 public tags discharges
this residual without any oracle-log, path, recovery or decoder-follow law.

`RWireInitialTag.initial_follow_tag` proves every successful initial decoder
follow returns a prefix whose statement tag is 2. Consequently
`initialTag_of_completion` proves the old premise implies this residual.
`completion_iff_initialTag` proves it is the exact remaining condition once
the other existing checked format and budget facts hold. This is not a
claim that arbitrary d enforces tag 2, nor reinstatement of the old
unconditional h_R18 law on all oracles/runs.

## Question and definition audit

The exact former premise in `R1FinalSoundnessBin.final_soundness` is:

```lean
(hN : ∀ H : Bytes → State, DecodedFirstReadUnionBound.decoderFirstReads dec
  emptyTable (eval H (recorded D d P)).1 ≤ 33)
```

`dec` is `RawAdaptiveLiteralDecoder.decode RawFullPublicSelection.select
LiteralTableWordChoiceBin.choose`. Its inputs are the current address and
pre-read table, with no consumed-row state. The selector recovers a public
statement independently at each address. `UnifiedDecoder.decode_sound`
proves each recognized address belongs to one of 33 row kinds; it does not
prove at most one address per kind. `decoderFirstReads` traverses the entire
chronological experiment log, including arbitrary adversarial queries, and
counts fresh recognized addresses. It does not project onto the final proof's
33 selected sampler invocations.

The compiler retains the original prover log and verifier log, then appends
a verifier replay. It does not discard unused, competing or abandoned starts.
Thus a finite number of row kinds is not a cardinality bound on recognized
fresh starts. This agrees with the explicit restrictions documented in
C3-SKELETON and the hN row of C3-BIN.

## Symbolic counterexample

`BinDecoderInitialStarts.recognizes_initial` shows every canonical
initialization frame for any tag-2 public bytes is recognized, for every
current table. `DecoderStartCounting.all_fresh` counts a nodup list of such
queries by induction; `append_lower` shows subsequent reads cannot erase
that count. Neither proof evaluates a concrete log.

`BinDecoderStartCounterexample.adversary P` queries 34 distinct canonical
initialization frames, using the one-byte public strings indexed by `Fin 34`,
and then executes P. It is one fixed oracle program, not a program chosen
after seeing H. These public strings need not parse as a semantic spend:
there is no such test in the causal initial-frame decoder. The adversary may
query unused competing public statements. Recognition holds independently
of answers and of whether the continuation selects any of these statements.

`prefix_count` proves the prefix has exactly 34 starts using injectivity of
the public selector and nodup finite indices. `recorded_more_than_33` proves
that the exact binary recorded experiment has more than 33 starts, for every
D, d, P and H. `original_output` preserves the original proof/public and
acceptance; `recorded_acceptance` preserves that acceptance in the binary
compiled experiment. Thus an accepting continuation remains accepting.
These are definition-level counterexamples, not a claim that every remaining
frozen-source boundary hypothesis has been instantiated for this prover.

## Correct replacement

`R1FinalSoundnessBinFirstReadBudget.final_soundness` copies the C3 source
contracts and retains its cost, returned-relation and abort conclusions.
It removes hN and derives the following fact inside the proof:

```lean
have hN : ∀ H : Bytes → State, DecodedFirstReadUnionBound.decoderFirstReads dec
    emptyTable (eval H (recorded D d P)).1 ≤ Q + 1161 := by
  intro H
  exact (DecodedFirstReadUnionBound.decoderFirstReads_le_firstReads dec _ _).trans (hqc H)
```

Here `hqc` is R19 transported through the compiler's proved first-read
preservation. This is the conservative bound justified by the existing
quantity Q+1161; it is not claimed to be an optimal protocol-specific bound.
The already-existing arbitrary-N M9 theorem keeps the sharper recognized
start count available whenever an independently justified N is known.

The verbatim former probability conclusions are:

```lean
(deployedFailure ≤ R1FinalSoundnessNumeric.totalBound Q) ∧
(Q ≤ R1FinalSoundnessNumeric.maxAdversaryQueries → deployedFailure < 1 / (2 : ℚ)^100)
```

The replacement probability conclusion is:

```lean
(deployedFailure ≤ totalBound Q)
```

with the exact definition:

```lean
def totalBound (Q : Nat) : ℚ :=
  (BinCombinedMerkleCollision.kappa (Q + 1161) +
    ((Q + 1161 : Nat) : ℚ) * PerAttemptEnvelope.B + 1 / (2 : ℚ)^126) +
      1 / (2 : ℚ)^454
```

Equivalently, the guaranteed bound is
`6*(Q+1161)^2/2^256 + (Q+1161)*15/2^109 + 2^-126 + 2^-454`.
`replacement_not_100_bits` proves `1/2^100 ≤ totalBound Q` for every Q.
This concerns the conservative upper bound, not the adversary's actual
failure probability, and establishes no attack on soundness.

## What remains

hN genuinely restricts the adversary in the present experiment. There is no
unconditional restatement with the original 33 coefficient established here.
To recover that endpoint, one needs either an explicit justified bound on
all adversarial recognized starts, a stronger probability argument charging
only suitably relevant starts without anticipatory conditioning, or a new
causal decoder together with density and BinaryCompletion proofs. Merely
filtering to the ultimately accepted proof uses future information; the
existing causal union-bound theorem cannot silently be applied to it.
A verifier's final 33-row transcript alone does not enforce an oracle-query
budget against offline competing starts. No decoder modification is made.

All other source, transport, binary completion, ledger and stored-log-length
premises remain as in C3-BIN. This work does not discharge them or revisit
M10 instrumentation. Focused compile receipts are under
`evidence/hn-starts-20261021/`; final audits are recorded below.

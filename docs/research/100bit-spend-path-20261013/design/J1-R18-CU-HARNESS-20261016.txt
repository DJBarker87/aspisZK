New binary: tools/r1-cost-probe/src/bin/r18_replay.rs. Its scope and fixed
fixture are in J1-R18-DIRECT-VERIFIER-CU-PROPOSAL-20261016.txt. No existing

only the separate verifier checkpoint writable. Every supplied key is distinct

output directory, mode0600, retained for both independent local VM runs.

Source checks against pinned LiteSVM0.16
new() invokes into_basic(), which selects mainnet_feature_set(), builtins,
sysvars, signature verification and blockhash verification. The harness records
its sorted active feature IDs/activation slots. warp_to_slot(150) precedes
add_program; add_program_internal obtains current_slot from cached Clock and
serializes it in ProgramData. add_program selects the upgradeable loader.
The harness decodes both loaded Program and ProgramData, checks canonical PDA,
loader owners, executable flags, slot150, absent upgrade authority, and exact
ELF suffix. Preloaded registry hash descriptors stay fixed across the two
runs; no registry registration/history or descriptor-to-ELF certificate is
claimed. Input state equality excludes the intentionally different executable.

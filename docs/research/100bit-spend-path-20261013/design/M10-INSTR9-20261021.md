## Stage 1: executed public-parser allocation counters

`ListConstructorAllocationM10` counts constructor/result groups at take,
drop, append and equality recursion sites. `PublicCursorAllocationM10`
counts prefix copying, suffix traversal, bounded scalar decoding and
`Fin.cons` captures in the repeated fixed-width decoder. Scalar constructor
budgets are independent of decoded values (64 groups for M31, 128 for index).
`PublicParserAllocationM10` composes those counters through every public
parser branch, including failed prefixes. Its erasure theorem preserves both
the old value AND the old work, and its allocation-carrying StageSpec proves
`bits ≤ 1024 * parser work`. Counters are attached to operations and branches,
not to the parser's numerical upper work bound.

These are logical fixed-slot constructor groups, not macOS/Lean allocator
bytes. Instrumentation/proof bookkeeping is erased from the cost model.
Source allocation adequacy outside these described operations is not inferred
from returned-value equality.

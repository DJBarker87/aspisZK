Scope and limits

The output is a lexical call/loop inventory, NOT a generated CFG, type-resolved
call graph, feature-resolution certificate, or Rust refinement theorem.
It retains cfg alternatives and records attributes. Every captured invocation
and loop needs an explicit classification and multiplicity. Changed source
hashes, unclassified calls/loops, changed multiplicities, unknown expanded
targets and SDK/archive mismatches reject. Default output exposes 319 opaque
call obligations, 28 opaque loop obligations, and preservation obligations;
--require-closed-effects deliberately exits2. No opaque call receives cost0.
Constructor/pattern occurrences are labelled, not counted as execution events.
Eight negative/lexer tests check this audit mechanism, not Rust semantics.

The older exact-public extraction kit provides verbatim spans and provenance,
not this missing semantic bridge. Local Charon exists at
external/aeneas/charon-cb50-metadata/bin/charon and Aeneas at
external/aeneas/aeneas-verif-workspace/aeneas/bin/aeneas. Their equivalence to the
previous host-pinned extraction pair is not assumed. Worker A coordinates
their focused extraction and provenance; this audit launches neither tool.
Inspection by worker B found that this Aeneas version rejects TFnPtr/Arrow
types and has no stateful/cost flag. The first tiny HashFn extraction must
record that actual diagnostic; successful callback translation is not assumed.

Runtime boundary

The candidate totals remain349/472 until source simulation is proved. SDK
create_program_address and the pinned runtime create syscall perform one
derivation, while the SHA syscall finalizes one digest after streaming slices.
Their exact source ranges are in policy/sdk_pins. Package/archive equality does
not attest the executed validator, compiler, SBF binary, panic behavior or
absence of extra runtime SHA. Those remain explicit runtime obligations.
An LLBC theorem alone proves the extracted representation; source-to-LLBC
preservation needs a stated compiler/extractor trust boundary or a proved
translation checker. Hash pinning cannot discharge it, and no axiom asserts it.

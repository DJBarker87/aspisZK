# Remaining obligations for the 100-bit private-spend proof

Current integrated proof frontier includes `506224f37` and source checkpoint `99263bea0`, with the checked conditional canonical-input adapter also available as a focused worker result. This checklist supersedes older documents where raw-byte decoder recovery, adaptive public selection or the generic Fiat-Shamir reduction are still described as unproved. Each numbered item is an obligation group, not one missing lemma; the groups overlap where source correspondence supplies several theorem premises.

The actual all-33-round raw-byte background decoder and the conditional adaptive membership reduction are checked. `RawAdaptiveMembershipBound.membership_bound` still takes `hformat`, `hterminal` and `hQ`. `LiteralFreshAttemptBound.thirty_three_rows_lt` proves the concrete fresh-attempt classifier-hit bound below `2^-100`; it does not by itself bound accepted false spends in the deployed program.

Lift these through the real begin/verify callers, opening-phase methods, preparation/checkpoint/resume and authenticated tx2, covering all 33 rows, reseeding and selected query state. Complete the concrete Solana backend refinement: exact hash-input bytes, call order, returned errors, state updates and acceptance behavior for the admitted entrypoints. Source-to-model sampler correspondence remains part of this work.

2. **Actual decoded inputs and strict formats.** Connect actual source decoding to the canonical decoded-wire prover. Constructor validity and tag 2 are now proved for that adapter, but its input has not been identified with the actual accepted caller's input. Connect the isolated extracted row-2 parser theorem to the exact consumed bytes. Resolve the source opening-section to logical row-30 `.second` record correspondence, including exact consumed values and transcript/hash bytes: the current P3 source parser is not itself the handwritten model's row-30 record parser. An assumed matching decode would not close this gap. Complete the relevant canonical M31/QM31/WideExact/public-byte representation links at their actual use sites.

3. **Public statement and Pool binding.** Both decoded variants now have a checked fixed public/transition map, and actual preparation success supplies a new serializer witness. The fields-loop transport is checked. Finish twenty-node frontier transport, complete public-serializer transport and decoder-to-preparation equality so that this success supplies the old serializer witness without an assumption. Derive actual decoding from caller reachability and identify the separately supplied public input with that same statement. The pure metadata helpers and wrapper split are implemented and checked, but `R16ReadonlyMetadataProjection` remains an explicit runtime premise; actual account/caller identification and custody remain open.

4. **Authenticated two-phase checkpoint.** Prove tx1's strict parsing/canonicality checks and checkpoint writes authenticate every byte and value trusted by tx2. Prove proof/public/checkpoint identity, finalization and immutability across the admitted lifecycle, including safe provisioning. In particular, derive canonicality of every wide-field value used by the shortened tx2 path from the checked tx1 data and authenticated binding.

5. **Source openings to commitment-time words.** The mathematical raw-log recovery and stability results are checked. Instantiate them with the actual source's C1, C2 and folded Merkle verification: exact leaf bytes, salts, domains, roots, indices, path geometry, padding, consumed values and trace inclusion. Prove accepted source openings equal the typed recovered words at their commitment cuts; default completion alone does not supply those equalities.

6. **Complete accepted-source terminal implication (`hterminal` / D3).** Prove acceptance supplies every field of `LiteralAcceptanceTerminal.Checks`. Compose them with the existing model theorem yielding `Rspend`, including input membership, secret/nullifier relations, bounded conservation, output commitments and public-option shape. Existing joint-list, second-fold lift and algebraic binding theorems are reused; their correspondence to actual source payloads remains necessary.

   The current terminal source subwork still includes the newly emitted indexed reconstruction and 33-cell loops, preprocessing/tail-write composition, the full `add_value_lanes` caller, `add_preweighted`/copy/24 semantic lanes, Poseidon/full-state residual production, claim-array producers and enclosing terminal validation. Small reconstruction and canonicality components are checked; complete source composition remains open. Extraction success is not a source correctness theorem.

7. **Concrete sampler execution correspondence.** The selected mathematical sampler densities are proved. Connect the actual source challenge construction, reduction, nonzero-gamma handling and state carry to those selected samplers at every row. This is covered by neither a field identity nor an isolated sampler component alone.

8. **Universal query bound (`hQ`).** Prove the verifier's distinct-query bound for every admitted input, including rejected inputs, both transactions, terminal/checkpoint hashes and relevant SDK/PDA calls. Keep the adversary's query budget symbolic and compose it with this verifier bound. Fixture measurements and the candidate `QV = 2250` are not a universal source/runtime proof.

## Knowledge and zero knowledge

9. **Efficient knowledge extractor.** Replace specification-level witness choice/log representatives with an explicit uniform full-log algorithm. Prove complete list decoding and exact list refinements for the initial code, first fold and repeated-lift second fold; deduplication/joint candidate combination; recovery of a witness checked by `Rspend`; expected polynomial field/hash-log/bit cost; and extractor failure `deltaE <= 2^-120`. Membership soundness does not establish knowledge of an existing note's secret.

10. **Zero knowledge for the actual published protocol.** Connect the exact source mask distribution and all disclosed payloads, salts, commitments and openings to the privacy model. Prove the needed mask-image/rank statements and dual-pad/chain corrections, with explicit exceptional-challenge bounds. Construct an efficient public-statement-only simulator. Prove commitment hiding and the adaptive random-oracle real/simulated-view reduction. If publication uses rank rejection/retries, implement and prove the accepted/aborted transcript law, fresh-entropy/nonce discipline and bounded-abort/completeness contract. Finite rank experiments and a Classical.choose simulator do not close these obligations.

## Final composition and the requested spend

11. **Final quantitative theorem.** Instantiate the source-facing premises and combine the exact per-attempt soundness terms, the single shared collision charge and the extractor failure budget under the clarified security experiment. State privacy error separately with its justified terms. Retain the query-dependent repeated/adaptive-attempt statement; no work/grinding credit or claim that arbitrarily many oracle attempts preserve absolute `2^-100` error. Explicitly state the random-oracle and trusted Solana-runtime preconditions.

12. **One coherent checked source/artifact closure.** Integrate the proved candidate source changes into the admitted verifier, resolve cached/maintained interface differences and declaration aliases, and perform the final pinned Lean 4.32 manifest replay once. The theorem closure must contain no `sorry` or unproved external contracts. Re-pin every affected extracted declaration to the final Rust source or prove its body unchanged; the Digest32 migration's whole-cone inventory is not complete. Pin features, compiler/toolchain and one final SBF artifact to the theorem's actual scope. The admitted artifact is `r1-cost-probe` with `pool_route`; the V7 guard copy is outside this scope. Prior component receipts do not prove the whole final closure.

13. **Full private-spend release gates.** For the original goal, also prove/check Pool settlement binding, nullifier uniqueness, custody/authorities, output handling and rejection/rollback behavior; settle provisioning after lifecycle-route restrictions; and verify the final proved artifact completes verification plus settlement in at most two transactions within the CU limits using fresh full masks. Run the metadata mutation harness against that same artifact. The reused transfer1023 baseline is stage1 1,343,603 CU and stage2 1,229,578 CU: stage1 exceeds the project's 1.3M target. The Digest32 candidate has no completed CU replay or final SBF pin. These settlement/deployment gates are distinguished from the algebraic soundness theorem in the lead decisions. Earlier measurements remain evidence for their pinned artifacts, not automatically for new source candidates.

Smallest proposed production/extraction split
Introduce primitive-only qm31_div_pass([u32;8])->([u32;8],u32) and
qm31_digits(&[u8;32])->[u32;4], names/interfaces proposed. Use value-owned
rank arrays: initialize eight words with an explicit increasing index loop
and four checked byte indices, avoiding from_fn/try_into/unwrap. For each pass,
start j=8, decrement before indexing, compute the same shifted-or dividend,
write rank[j]=quotient, update remainder. Four increasing passes explicitly
assign both returned rank and digit. qm31_sample retains the ordered final
CM31::new(M31(d0),M31(d1)), CM31::new(M31(d2),M31(d3)) construction.
Only extract the primitive helper cone initially; it emits no QM31 type or
operation. Pin actual post-refactor declarations and all primitive models;
retain the old implementation for focused differential vectors, not as an axiom.

Explicit write-back target, to prove on emitted declarations
For a : Aeneas.Std.Array U32 8#usize, define
  view(a) := (a.val.map (fun u => UInt32.ofNat u.val)).reverse.
Required: for every a, there exist a',d with pass a = .ok (a',d),
  d.val = (SamplerWordPass.machineProcess 0 (view a)).1.toNat,
  view a' = (SamplerWordPass.machineProcess 0 (view a)).2, and d.val<P.
This specifies the entire updated array, not just a remainder or final rank.
The index invariant identifies processed high words and unchanged low words;
index bounds, terminating counters, casts, division and modulo success are
proved, not supplied as no-panic premises. SamplerMachineBounds.dividend_lt_two63,
dividend_quotient_lt_B and dividend_remainder_lt_P supply arithmetic bounds.
SamplerWord uses native UInt32/UInt64, so the emitted Aeneas U32/U64 operations
still need a val-preserving bridge; these types are not silently identified.

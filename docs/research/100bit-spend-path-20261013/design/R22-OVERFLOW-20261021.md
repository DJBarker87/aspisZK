## Inventory

The packet is evidence/r22-overflow-20261021/ (relative to this research
folder). tools/r22-overflow-kit/inventory.py reads frozen git blobs and
produces operation-census.json, with every lexical arithmetic, integer-method,
cast and index expression in a conservative source superset, qualified owner,
line/column, expression hash and source hash. It explicitly does not perform
Rust type inference, cfg resolution or whole-program reachability. Thus it
includes field-method overloads, tests, prover and retired code. SDK,
allocator and hash internals are external boundaries, not silently certified.

The existing inventories remain necessary:

- design/OVERFLOW-FREEDOM-INVENTORY-20261019.md: stage-1 field, strict decoder,
  rho accumulator, semantic rounds, weights, sampler and fast kernels.
- design/OVERFLOW-FREEDOM-S2-20261020.md and its operation-census.json:
  stage-2 compact framing, multiproof, checkpoint reader, geometry and finish.
- evidence/freeze-20261020/: linked-ELF strict-stack and declaration evidence.
  Stack safety alone supplies no arithmetic-overflow theorem.

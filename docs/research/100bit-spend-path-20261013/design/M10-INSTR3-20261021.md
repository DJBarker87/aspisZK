## Fixed-protocol polynomial and coordinate specialisation

`RawExtractorFixedProtocolPolynomial.family p Q` keeps every protocol
coordinate fixed except `logSize=Q+1161`, with overhead degree one. For this
family, `coordinates` proves the existing CoordinateBound with

```

```

Its directly constructed budget polynomial evaluates to the exact existing
attemptBudget and has degree at most one. This avoids the higher-degree
polynomial obtained by allowing every coordinate to vary diagonally.
It does not prove that actual GS array sizes, retry schedules and costs fit
any fixed p; those remain implementation obligations.

`RawExtractorFixedProtocolEnvelope` gives an explicit coefficient. Write
`H=p.overheadConstant`, `N=p.n`, `R=(p.b+1)^2`,
`E=p.n+p.listSize+p.b+1`, and

```
F = p.count*gcdBudget p.n + p.count*divisionBudget p.n
      + (p.count*(2*p.b))*p.mulBudget
A = H+7*N+(2*H+7*N)*R
D = F+H*E+(F+2*H*E)*R
C(p) = A+D.
```

Then `attemptBudget(family p Q)=A*(Q+1161)+D` and is at most
`C(p)*(Q+1161)`. These are symbolic algebra proofs; no concrete large
protocol array, finite universe or recurrence is reduced. The coefficient
is fixed once p is fixed. The corresponding mean-cost theorem **retains
the actual implementation ledger premise**.

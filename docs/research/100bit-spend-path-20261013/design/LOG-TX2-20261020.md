## Remaining named premises

1. **SuccessfulResume / ResumeOpsCorrespondence**: the successful emitted
   resume equation used here must follow from the successful frozen caller;
   the typed ResumeOps must match the actual implementations. This job uses
   the existing complete-body adapter and does not prove whole-caller refinement.
2. **ResumeComparisonSoundness (`ne_sound`)**: successful false byte-slice
   comparison means equal byte lists. Needed to derive stored-field equality;
   all later decoding operations remain arbitrary typed operations.
3. **Tx2InventoryComplete** (`RawTx2DigestLog.lean:55`): every reached tx2
   digest pair belongs to the supplied inventory. This includes binary-parent
   iterations, external leaf calls, any legacy-parent branch, and runtime/backend
   calls. Syntactic site enumeration does not discharge dynamic coverage.
   Supplied `Call.success` fields are the named remaining-call witnesses.
4. **Tx1InventoryComplete / Tx1Actualness**: inherited tx1 coverage and
   successful-call witnesses, including sampler suffix, compact Merkle and
   writer calls. The existing tx1 assembly discharges actualness given its
   suffix/rest witnesses, not coverage. Frozen re-pins remain owed.
5. **SharedByteOracleBackend**: tx1 and tx2 successful calls implement the
   SAME total Hbytes, independent of backend values and slice segmentation.
   These are `Tx1DigestLog.ByteOracleBackend` and
   `Tx2DigestLog.ByteOracleBackend`; the latter yields **Tx2Certificate** in
   the final consumer. A fixed Rust trait signature supplies neither law.
   Checkpoint equality alone does not establish this law for other calls.
6. **WriterStoredDigestFields / CheckpointProvenance**: the checkpoint input
   really carries the tx1 writer's proof/public digests at their two offsets.
   Frozen writer preservation, account ownership/write guards and intertransaction
   provenance remain R15/P2 obligations. This is stronger than the parked
   proof-call theorem and is not claimed discharged by it.
7. **ParkedWriterResumeProofAgreement**: if that alternative linkage is used,
   the same dictionary/hash and singleton compact proof input give tx1's writer
   proof digest. Only a named premise here; frozen-source extraction/refinement
   is still owed. Public writer-call agreement is not supplied by that theorem.
8. **SameBuffers / CollisionEvent**: deterministic same-input agreement is
   proved; digest equality does not by itself prove proof/public byte identity.
   The converse needs the separately charged collision event and authenticated
   provenance. No buffer identity or R9 closure is claimed.
9. **OrderedROMExecution / FirstReadAccounting / AllInputCoverage**: these
   inventory lists do not prove ordering, lazy memoized execution, first-read
   bounds, or rejected-prefix coverage before resume success. They do not close
   R19 or the privacy execution-law correspondence. Concrete backend/source,
   adapter/Pool runtime, canonicality and coherent release re-pins remain open.

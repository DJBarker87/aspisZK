## Lean obligation and checked scope

```lean

```

`Covered` requires inventory membership at each `invoke`, coverage of **every**
return continuation (including errors and unrealized interface values), and
coverage of every oracle-answer continuation. It is not itself a source-tree
construction, source pin check, call-graph theorem or implementation join.
`SourceInventoryCompleteness` in the new module states this independent
obligation without asserting a witness for the incomplete source JSON.

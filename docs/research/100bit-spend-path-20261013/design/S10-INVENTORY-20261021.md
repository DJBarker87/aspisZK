## Lean obligation and checked scope

The actual core obligation is:

```lean
S10Join inventory sourceTree := ∀ i, Covered inventory (sourceTree i)
```

`Covered` requires inventory membership at each `invoke`, coverage of **every**
return continuation (including errors and unrealized interface values), and
coverage of every oracle-answer continuation. It is not itself a source-tree
construction, source pin check, call-graph theorem or implementation join.
`SourceInventoryCompleteness` in the new module states this independent
obligation without asserting a witness for the incomplete source JSON.

The new `OraclePortS10ModelInventory.lean` supplies an actual inhabitant for
its explicitly narrower decision-stage tree. `model-stage-inventory.json`
is generated from the five checked site definitions/list and pins the exact
source and successful receipt:

`covered` proves all-continuation coverage; `inventory_nodup` proves distinct
sites. `model_S10Join traceOf` specializes the actual core predicate to
`stageTree traceOf : Input → Calls signature Bool`, universally over stored
inputs and the supplied erased-prefix projection. `interpret_eq_frozen`

Bool equality. It preserves the short-circuited slot program and its oracle

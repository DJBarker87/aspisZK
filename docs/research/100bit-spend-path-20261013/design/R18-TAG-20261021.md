## Stage 1: dependency inspection

The Row31 endpoint passes `h_R18` to
`R1FinalSoundnessBinPerQuery.final_soundness`. In that theorem, `h_R18`
occurs only in its binder, never in its proof body. The binary adaptive
injection sets `decodes := h_Rwire evidence`; its clean-model step calls
`binaryClean_of_checked_acceptance` with the first-read bound, Checks and
that same completion. None of these steps requires a tag premise.

This agrees with C3-BIN's R18 row: “Same tag=2 source interface retained.
The conditional clean proof needs no tag once completion is supplied”.
C3-SKELETON's R18 quantifies over every oracle, including rejection. We do
not prove that universal deployed tag fact, infer it from accepting-only
R16, or claim a frozen Rust/model decoding join is discharged. Instead we
remove the unused direct premise. Existing public parsing in R16 and full
binary causal completion in R-wire remain unchanged, with their deployed
source obligations and all nested BoundaryEvidence meanings intact.

The new endpoint will inline the existing per-query proof and Row31's
R16-derived sampler fact, deleting only the R18 binder. It will add no
replacement premise and retain the complete cost, validity, abort and
query-normalised probability conclusion. No existing endpoint is edited.

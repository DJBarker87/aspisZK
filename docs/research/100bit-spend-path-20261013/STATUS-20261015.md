# Transparent two-transaction spend research: 15 October checkpoint

The research branch now adopts the unrolled WideExact parser whose isolated
extracted Lean model has an all-input strict-decoding proof. Five local
verification-and-settlement cases pass using retained fully random-masked
proofs. This is an implementation and evidence checkpoint; the complete
100-bit non-work-normalized private-spend theorem remains open. The later
shared-point contraction is also adopted after its corrected differential
and five matched settlement cases passed. The measured 10/12 query split is
now adopted too, with the old 11/11 instruction retained for compatibility.

The user has clarified the target as **100-bit per-attempt soundness, without
grinding credit**. The current numerical parameters meet that target
conditionally; they do not need to meet an absolute `2^-100` failure bound
after `2^64` hash queries. See [the recorded clarification and arithmetic](TARGET-CLARIFICATION-20261015.md).

- Reused the existing M31/QM31 byte decoders, byte order, canonicality,
  exact field-coordinate maps, and successful-decode reconstruction proofs.
  The new unrolled parser model equals the checked two-half parser for every
  slice, rejects wrong lengths, is total, and returns only eight canonical

  [12-item Lean audit](evidence/lean-unrolled-wide-checkpoint-20261015/source-manifest.json)

- Optimized native differential: 30,055 byte vectors / 60,110 parser calls;
  13,607 exact-length vectors / 27,214 direct limb-constructor calls. Every

  v1.52, and adopted unchanged. [Adoption and root validation](evidence/wide-parser-adoption-20261015/README.md)
  distinguish this source matching from an unproved compiler-correctness claim.
- The more direct two-half implementation and forced-inline variant exceeded
  the stage-one compute budget. Their failures are retained. The unrolled
  version passes; [per-phase costs](WIDE-PARSER-COSTS.md) reconcile the variants.

## Remaining security work

The current conditional Fiat–Shamir bound is
`Q * max_row + 3 * Q^2 / 2^256`. Its approximately 105-bit raw coefficient
does not imply absolute 100-bit failure probability for arbitrary `Q`.
The current arithmetic meets `2^-100` only through `Q = 35`; this is a
limitation of that stronger whole-experiment bound, not an attack,
impossibility result, or blocker for the clarified per-attempt target.
Concrete classifier/extractor and round-density premises, full-experiment
query accounting, source correspondence, and privacy obligations remain.
See [the exact remaining interfaces](FS-REUSE-REMAINING-20261015.md) and
[query-dependent arithmetic](FS-BUDGET-PROFILE.md).

Adding queries alone makes the semantic challenge bound the largest term,
but stronger parameters are no longer required for the clarified target.
The next security work connects the existing deterministic and sampler
theorems to the concrete classifier, extractor, source and privacy experiment.
The [generic query/list inventory](NEXT-QUERY-REUSE-20261015.md) and
[older arithmetic optimizations](NEXT-COST-REUSE-20261015.md) remain reusable.
The older V8 measurements use a different protocol and cannot be treated as
portable savings or as a completed security certificate.

The [checkpoint authentication audit](AUTHENTICATED-PARSER-AUDIT.md),
[current source map](WIDE-CHECKPOINT-SOURCE-MAP.md), and
[adversarial evidence inventory](CHECKPOINT-ADVERSARIAL-REUSE.md) keep the
strict tx1 parsing, digest binding, and checkpoint-provenance requirements
separate. The primitive parser proof does not prove the complete caller path.

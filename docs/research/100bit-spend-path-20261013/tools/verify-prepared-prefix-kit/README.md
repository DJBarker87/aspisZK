# Caller source-cut diagnostic kit

Review-only extraction inputs. This directory does not change production sources. See `../../evidence/verify-prepared-proposals-20261016/README.md` for exact failures, successful Prepared proposal, all metrics, tool pins and remaining proof boundaries.

`prepare.py --base-kit <pinned current52-cut kit> --out input [--check]` builds complete actual caller cuts from git revision c16. All extra boundaries are explicitly opaque, nonsemantic staging bodies, to be bound with parameters or checked definitions before any Lean claim. The base is the shared canonical QM31 universe.

`propose.py` produces separate review-only while/straight/owned/helper alternatives. `propose-round.py` produces the checked one-round helper plus ten sequential calls, optionally with a pure selected-mask boundary. They never edit a production file. Failed input snapshots, including every exact source version and runner used, are frozen in the evidence archive; their patches also remain under `failed-proposals`.

`proposal-prepared-helper-fields/proposal.patch` is the only successful complete caller-emission proposal. Its input snapshot here is exactly the tested proposal, and the archived receipt pins it. Do not regenerate it with a changed generator and confuse it with the original receipt. No production adoption or new Lean theorem is implied. `run-host.py` refuses uncapped scopes, pins both tool binaries, snapshots inputs, accepts only valid LLBC, and performs one focused extraction attempt without Lean.

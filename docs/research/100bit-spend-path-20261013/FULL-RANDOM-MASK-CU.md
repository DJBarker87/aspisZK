# Complete random-mask tape — selected d18 CU

The selected d18 ELF accepts both complete-mask proofs in all five capped runs of tx1 and tx2. The CU deltas from the partial fixture are small for this recorded seed. Tx1 still exceeds 1,300,000 CU, so these measurements do not establish G_R1.1's headroom requirement.

## Inputs and complete tape

The 32-byte seed was drawn from the local OS random source and recorded before proof generation:

`b00dbfdb0ef5cb2a4a4fc3a762331c04c6f1d3187fa58442263bac5a4bec6780`

The existing frozen `prove_masked_fixture` API expands this seed with its explicit domain labels and operation-specific public bytes. Its function name denotes a reproducible test API; this run uses a fresh recorded random seed and the **complete** mask-material path, not `prove`'s deterministic partial columns/K-tail fixture. The seed is intentionally public cost-test data and is not production entropy.

For each operation, the tape audit checks 3,803 eligible semantic noise cells, all 10,240 mask-only cells, all 1,024 G rows, all 1,024 D rows, and H1 padding on all 810 inactive rows (809 free samples and one balancing row). Active H1 padding remains zero. All eligible semantic cells changed and all permitted full-word/padding cells were nonzero for this seed. Inactive balances hold for all 16 semantic columns, ten mask-only columns, D, G and H1 padding; the resulting total H1 balance also holds. Balancing determines the dependent cells, so these counts are not claims of independent entropy in every stored cell.

[mask-tape.json](../../../results/gr1-cost-20261013/mask-tape.json) records SHA-256 for the applied eligible-cell deltas, mask-only words, G, D and H1 padding. [gr1/mask_tape.rs](gr1/mask_tape.rs) reproduces exactly the frozen prover's context, binding and domain derivations. The proof-generation path consumes those same complete words.

## Receipts and equivalence

The native gate checks strict/authenticated tx2 equality (9,253 trace entries), native/dense equality (10,699 entries), and 5,675 rejected mutations per operation on these exact random-mask proofs. [AUTHENTICATED-TX2.md](AUTHENTICATED-TX2.md) gives corpus coverage. Proof/public binary inputs remain on the NUC; metadata, trace digests and corpus results are copied read-only.

[Transfer receipt](../../../results/gr1-cost-20261013/d18-full-random-transfer.json) and [withdrawal receipt](../../../results/gr1-cost-20261013/d18-full-random-withdrawal.json) cover the two five-run commands, each in its own 4G/6G/swap-0 systemd scope. Each transaction/run has an individual [measurement JSON](../../../results/gr1-cost-20261013/full-random/measurements/transfer-acceptance-k10-tx1-run1.json) with CU, runtime, input/ELF hashes, checkpoint origin/hash, logs and wall time. [Evidence audit](../../../results/gr1-cost-20261013/evidence-audit.json) lists every receipt, caps, exits, timing, RSS and zero swap; the mask-tape audit and native compilation/generation have separate receipts.

Five repetitions test runtime repeatability for one random tape per operation; they do not sample five independent tapes or establish a worst-case CU bound. No security claim follows from full masking or the recorded seed.

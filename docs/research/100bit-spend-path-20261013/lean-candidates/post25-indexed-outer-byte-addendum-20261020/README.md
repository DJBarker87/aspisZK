`IndexedCandidateOuterByteBridgeV13.low_base_p_digits_candidate` ties the generated byte-assembly and eight-pass indexed loop to `byteWords`, the `ordinaryDigits` list, and the remaining quotient. `IndexedCandidateOuterByteOutputSuccessV5.low_base_p_digits_success` proves the generated outer index operation succeeds and returns the first word of that quotient. This packet makes no production-equivalence or adoption claim, and does not yet prove `ordinary_sample`, `gamma_sample`, or their distribution laws. Object files are intentionally excluded; see `manifest.json` for object hashes, exact native paths, import pins, and resource measurements.

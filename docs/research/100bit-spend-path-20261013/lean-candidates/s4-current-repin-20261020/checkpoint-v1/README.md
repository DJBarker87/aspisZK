This packet freezes the current-source `four_dots` extraction and the green Lean owners that make its outer StepBy control flow usable. The selected generated body is adapted to explicit operation parameters; the separate M31 and Wide bindings identify concrete helper behavior. The body-advance theorem recovers the actual StepBy cursor transition from successful generated body execution, and the body-done theorem recovers exhaustion.

The packet includes source/evidence metadata only, not OLean or LLBC binaries.

# Query reader provenance supplement v1

This is a source-and-text-evidence supplement to the previously frozen query-reader proof packet. It adds the omitted compiled `Types.lean` owner, the exact source cut and Charon/Aeneas evidence that generated the unrolled reader, the raw generated sources, and the mechanically checked validator-parameterized Lean source used by the successful proof.

The formal result is a checked theorem about the generated unrolled reader with an explicit `validate_queries` function parameter. The parameterization is a deliberate external-call boundary. `check_in_place_parameterization.py` checks that after reverting only the added parameter and the callee rename, the reader declaration is byte-identical to the raw generated reader declaration (hash `ef3f7c237aefc7ca8884446b32d745513a679a8455bfd08098b4db1ddfcdde2a`). The transformed full Funs source hash is `cc3fface9af21e868851e6fe66dc812ae2fd44eb005589399ca213cf8336c658`; the adapted declaration is not claimed to establish the actual validator implementation.

The successful v13 proof receipt records source `a41e089e1429b423a3bd0f55e0d7a84f4582b4074a807368789be073abac462c`, object `df6a1731b72282872303cf91b6d064d443597639dcd237ed1aea4737f3e80687`, exit 0, 2.306 seconds, peak process RSS 2,759,396 KiB, scope peak 426,893,312 bytes, and scope swap peak 0. Its `#print axioms` output is retained in `attempt/proof-evidence/lean.log`; it uses only `propext`, `Classical.choice`, and `Quot.sound`. The compiled Funs and FunsExternal owners and exact receipts are retained alongside it. The `Types.lean` owner was compiled separately from source hash `af8698e60c33177cde42faec7ccbbc743fff3ba8af8aac833828e4a8ef3bab28`, object hash `1f07df02e029b210e987b475cfb975ed4bf96c49a3c7f41e72b513eca8a92da5`, exit 0, 2.106 seconds, peak process RSS 2,629,396 KiB, scope peak 317,304,832 bytes, swap 0.

The reader source is a candidate source cut. This supplement does not prove the cut is reachable from the complete production resume function, does not prove the opaque validator parameter equals the production validator, and does not claim production adoption. The generated query reader reads 22 four-byte values in order, constructs the fixed array, invokes the supplied validator, and returns the cursor after the last read on success. The separate Aeneas shared-borrow replay issue and query validation remain open.

The remote extraction kit's LLBC and compiled binaries/objects are intentionally omitted. Inputs, lock/manifests, generated Lean source, tool commands/configuration, admission/reservation data, and textual receipts/logs are included. All files in this directory are covered by `MANIFEST.sha256` except the manifest itself and the archive. Run `python3 check_in_place_parameterization.py` to reproduce the source-cut comparison.

# EbyKDot.push control proof packet v1

This packet records an exact extraction of the current Rust `EbyKDot::push` body and a Lean adapter theorem for its outer success control. It does not prove the `Dot::push` arithmetic, Wide-to-Q conversion, checked scalar validation, checked Usize addition, or the R22 no-overflow bound.

The Rust source snapshot is pinned to revision `6140050b8345e771b5057fff75b7cc387ca032c3`; `rust-input/source-pins.json` records the source file hashes. Charon emitted the actual EbyKDot.push body as structured LLBC while making only `canonical::Dot::push` opaque. Aeneas emitted `generated/Funs.lean`. The external template contains external axioms and is retained only as evidence; the accepted Lean proof does not import it.

`proof/AspisR1EbyKPushExplicitOpsV1.lean` copies the emitted body into `pushWithOps` and makes four operations explicit: `fromWide`, `checkedQ`, `pushDot`, and checked `addUsize`. The source also substitutes the literal `MAX_TERMS` constant with a locally pinned `4096#usize` definition. `proof/check-eby-k-push-adapter-v1.py` extracts both definitions and exact-compares their normalized bodies after exactly those substitutions. Its passing output is in `proof/check-result.json`. The cleaned Types file removes only generated `maxHeartbeats` and `maxRecDepth` option directives; no proof resource options are set in the adapter.

The checked success theorem derives from the actual adapter result `.ok (.Ok (), out)` that the count is below 4096; `fromWide` and both array reads succeed; `checkedQ` takes the `Continue` branch; both `pushDot` calls and checked count addition succeed; and `out` contains exactly those two Dot results and the incremented count. Its `#print axioms` output is standard Lean axioms only: `propext`, `Classical.choice`, and `Quot.sound`.

Extraction attempts and resource receipts are under `sessions/`. The original Dot.push extraction attempt (v2) failed in Aeneas lowering of its mutable four-element array loop and is preserved by the originating v2 kit; this v3 packet is the changed extraction that isolates Dot.push as the explicit operation boundary. No patched Aeneas binary was used. The selected v3 extraction succeeded under explicit 512 MiB high / 2 GiB max / swap 0 caps. The Lean owner compiled under 1 GiB high / 2 GiB max / swap 0. Its receipt records 1.405 s wall time, process maximum RSS 2,377,708 KiB, cgroup peak 295,419,904 bytes, and zero swap. The object is intentionally omitted from this source-only packet; its SHA-256 is `2be6e77a8fea797a7607afdadfebd629afc911adb6ac0a90b72e7b23976add62`.

The next proof step is a sound source/refinement for the actual Dot.push loop and the caller's checked arithmetic. `pushDot` remains an explicit operation boundary here; this is not a complete EbyKDot arithmetic proof.

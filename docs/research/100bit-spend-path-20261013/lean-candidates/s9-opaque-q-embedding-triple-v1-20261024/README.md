# Concrete opaque QM embedding triple

Proved on the existing concrete ExactQM and WideExact carriers: embedQ(x*y*z)=(embedQ x*embedQ y)*embedQ z for arbitrary opaque scalars. The proof first isolates one concrete multiplication operator on each carrier, then applies existing ring-hom multiplication through a generic helper. This avoids converting an entire source row or sum through generic typeclass projections.

All four public targets passed the first focused check with standard axioms. No field value, source row, 64-element sum or recurrence was normalized. This is model algebra for the subsequent PointRow bridge, not implementation or security closure. Sources and receipts only; no binaries.

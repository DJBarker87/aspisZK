Before a downstream canonicality transport could require an assumed equality between a selected alpha slice and the full two-element alpha array. The source operation theorem now proves that equality from the exact emitted RangeTo2 indexing call itself, and transports successful reads at the same index.

The array-length2 condition is in the input type. No independent successful read, canonicality or output/slice-equivalence assumption is added. The accepted source operation success is retained in the inversion corollaries so caller traces can supply it directly. Full finish/Pair/caller installation remains a separate binding obligation.

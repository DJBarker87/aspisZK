## Remaining boundaries

Actual global log containment and oracle consistency remain premises: this does not establish Rust/syscall logging or instantiate the global random-oracle execution law. Public bytes/root representation links remain explicit. The full25 theorem takes the chosen actual SourceFull25.Trace, typed-decode result and frame bounds; existing actual-run trace extraction provides these witnesses, but the complete verifier caller still needs integration. The positive prefix remains a sampler-prefix with plain payload constructors; row2 still needs word-bearing decoration and binding to actual recovered commitments to prove literal validity. C1/folded commitment cuts, source rows25–32, opening verification, complete acceptance-to-Checks, universal query/attempt accounting and efficient witness extraction remain open. No production Rust, artifact, CU or privacy-composition claim is made.

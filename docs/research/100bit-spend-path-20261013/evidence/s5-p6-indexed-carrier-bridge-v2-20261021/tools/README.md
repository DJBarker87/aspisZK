This config-driven local runner is a reusable template for later focused Lean leaf checks. It is not the launcher used for this packet's accepted compile; the exact executed launcher is `run-focused.py` in this directory and is included separately. Future target configs must pin their own direct-import objects, warm roots, source and output paths. The template captures Git HEAD after lock acquisition immediately before launch and records source/compiler/import pins, argv, RSS, swap, timeout, and receipt. It does not create cgroups, so it is only for focused local targets within the repository's under-8-GiB policy.

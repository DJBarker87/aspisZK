# P3 private-leaf-salts evidence bundle

This folder preserves bounded native and local LiteSVM evidence for the optional P3 `private-leaf-salts` prototype. It is feasibility evidence for the exact source and artifacts named below. It does not decide or establish cryptographic privacy, zero knowledge, production readiness, or constant-time behavior.

`RESULTS.json` is the compact index. The curated outer archive is `curated-p3-evidence.tar.gz` (SHA-256 `83832925cbcf0484281ca9b0501219430be0e6f080e2c6a05e40856a1642ad5a`). Its payload contains native run logs, P3 build and runtime receipts/logs, stack-audit JSON, the original build manifest, and proof/public sidecars. The local `source-driverfix.tar.gz` is the verified source-only archive (571 files; SHA-256 `64d9da26beda801de373180a94ee2ffbea3cf4e8cd04ab083748b5fe7f1d7604`), with matching `source-only-manifest.sha256` (SHA-256 `a72db26cbb51322499374741dafc13c7681394aa55a6666f156bd068ff25ea1c`). The original build archive remains on the NUC with SHA-256 `8eb67c5d6f535cbfefcf6e964f89c273475dc2fd860afdef85d3293e5bcaf220`; it matched the original 751-file manifest `p3-native-gates/source-manifest-driverfix.sha256` (manifest-file SHA-256 `e7e4e20dd01e899965ee6286b2adcdb424e6fa9ba0e033449af7090ba6a03199`). The source derivation record `source-only-derivation.json` lists all 180 removed `tools/r1-cost-probe/target/` paths (14,405,382 bytes) and records that every retained file matched the original manifest before exclusion and again in the source-only archive. The program and driver revisions and ELF hashes are recorded in `RESULTS.json`. The final read-only cross-check is summarized in `provenance-validation.json`; it validates the archive, all 13 modified P3 Rust sources, the 11 runtime receipts and proof/public sidecars, plus the remote program and driver hashes.

The program was built with `pool-adapter,private-leaf-salts`; the release `pool_gate` driver was built with `private-leaf-salts`. The stripped SBF ELF SHA-256 is `c94675d0f0682170ed9288e31feb31c76669f9698c554c36e9978c9a98835ab5`; the driver SHA-256 is `6510a90ccd2e29989d65be43ba842ad5b95c77b652a4e7eb2f555b8a00285224`. The stack audit passed with no reachable diagnostic stack frames. See `p3-pool-13/sbf-build.json`, `p3-pool-13/driver-build-fix1.json`, and `p3-pool-13/stack/stack-audit.json`.

## Runtime measurements

The six base cases are fresh OS-generated full-mask attempts for transfer and withdrawal at 13, 255, and 1,023 populated lane pairs. All succeeded under LiteSVM 0.16.0 in v0 transactions with a 1.4M CU limit. The four same-public transfer/13 comparisons add one deterministic fixture case and two more fresh OS draws to the initial OS draw. All four use the same public ASF8 SHA-256 (`f6bcd49446f1077d2c5ed4be940e91f0be444efc5ae83024ec0700b8c205c331`) and have four distinct proof hashes. Their observed stage-1 CU span is 1,390,049–1,390,333 (284 CU); terminal CU span is 1,293,584–1,293,755 (171 CU). This records run-to-run variation and is not a constant-time claim.

Across successful cases, the tightest stage-1 headroom is 9,667 CU (1,390,333 of 1,400,000); the tightest terminal headroom is 24,080 CU (1,375,920 of 1,400,000). Every run used a separate scope capped at `MemoryHigh=4 GiB`, `MemoryMax=6 GiB`, `MemorySwapMax=0`; receipts retain actual sampled RSS, cgroup peak, wall time, and exit status.

The transfer/13 proof-rejection run reuses the retained OS proof/public sidecars and mutates the submitted proof; the terminal rejects with `InstructionError(3, InvalidInstructionData)`, and all accounts remain byte-exact. The withdrawal/255 CPI rollback run reuses its matching OS proof/public sidecars, reaches the expected synthetic CPI failure, and confirms byte-exact rollback, with destination amount 17 and vault amount 10,000 unchanged. These are expected negative controls, not successful spends.

## Native checks and corrections

Optimized native S1 and S2 gates passed for transfer and withdrawal with exact native/dense acceptance; mutation counts rejected were 1,209 per operation for S1 and 899 for S2. The deterministic full-mask fixture passed S1/S2 transfer and withdrawal. The secure OS-attempt API gate passed strict, authenticated-checkpoint, and dense verification and rejected both same-statement and cross-statement durable nonce reuse. A default P2 authenticated-TX2 regression also passed.

Two early native compile attempts failed and are kept for traceability: `p3-native-gates/runs/secure-attempt/run.log` records a `[u8;1880]`/`Vec<u8>` mismatch in the new gate helper; `p3-native-gates/runs/default-p2/run.log` records P3-only salt references leaking into the default no-feature build. The helper conversion and feature gating were corrected; successful replacement logs are `secure-attempt-final/run.log` and `default-p2/run-fixed.log`. SBF and driver build receipts correspond to the later fixed source snapshots listed in `RESULTS.json`.

## Contents and exclusions

The outer archive includes only receipts/logs/manifest/stack-audit data and `r1-s2-proof.bin` plus `r1-s2-public-asf8.bin` sidecars from task directories. It excludes keypairs, nonce ledgers, payer/authority material, SBF and driver binaries, large disassemblies, and task-directory state. The source-only archive contains source files only; its adjacent manifest and derivation record document the verified source subset and removed build outputs. It includes no task secrets or nonce-ledger data. Source-side proof/public SHA-256 values are repeated in `RESULTS.json` and the per-case evidence receipts.

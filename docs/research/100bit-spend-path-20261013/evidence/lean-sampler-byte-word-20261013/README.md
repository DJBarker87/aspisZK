# Sampler byte-word bridge evidence

This focused target proves `AspisR1.SamplerByteWord.decodedArray_word_toNat` for every `Array U8 32#usize` and `j : Fin 8`. It connects the actual four-byte little-endian `U32.from_le_bytes` decoder, after the `encodeState`/`decodeState` array roundtrip, to the Nat word in `SamplerWords`, then converts that word to Lean `UInt32` using its proved 32-bit bound. It does not prove sampler-loop order, rejection behavior, field encoding, or Rust refinement.

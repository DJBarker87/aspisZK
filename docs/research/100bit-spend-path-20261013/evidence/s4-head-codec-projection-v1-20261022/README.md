# S4 C1 head codec projection

The main result is `AspisR1S4HeadCodecProjectionV1.c1_m31_head_term`: given the explicit same-opening byte identity, a selected `g` coordinate, and that coordinate's same-g power meaning, it identifies the actual source slice/parser term with the matching embedded C1 lane times the power. `S4C1M31SourceSliceV1` proves the per-lane four-byte slice identity used by that theorem.

Both audited theorems depend only on `propext`, `Classical.choice`, and `Quot.sound`. The C1 producer was compiled once for a missing-receipt repair under its exact module name, with only two `#print axioms` commands appended after unchanged declarations. The head theorem's original v13 run lacked its command/LEAN_PATH and axioms output; this packet retains its original exit/time/object pins, and an import-only audit wrapper records its axioms using the exact object and selected profile.

The original v13 command/profile were not available, and the manifest labels that limitation. The theorem's opening bytes, selected g value, and power premises remain explicit; no whole-query or end-to-end verifier claim is made. No `.olean` files are included.

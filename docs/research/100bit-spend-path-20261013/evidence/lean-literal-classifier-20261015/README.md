# Literal classifier and byte protocol evidence

`LiteralClassifier` combines the checked per-row independent-answer density statements over the 33-row literal schedule. `LiteralByteProtocol.d1` and `.d2` state the corresponding D1/D2 facts for unrestricted byte inputs and a decoder supplied as a parameter. The protocol uses the specification-level `GenericNoHit.chooseWitness` extractor.

The bundle does not provide D3, a concrete decoder injection theorem, a Merkle compiler, source refinement, or an efficient extractor. These density/protocol facts do not establish terminal acceptance or shared-oracle closure.

Classifier attempt a failed; b is final. ByteProtocol attempt a is green. All three attempt snapshots, receipts, logs, time records and source sidecars are retained. The archive stores the two final objects and their unique direct-import objects only.

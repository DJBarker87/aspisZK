# Lean append-tree focused evidence

This directory preserves the focused Lean compile evidence for the append-tree certificate work at source revision `3a73ee4bb67558ffbc608abfea81d74b4d2fa2a4` (worktree branch `codex/100bit-spend-path-20261013`). It contains 25 attempts: 10 successful final targets and 15 failed/superseded attempts. Every successful target's checked-in final source hash matches its successful receipt; see `source-manifest.json`.

The 25 exact receipts retain target, attempt, exit status, source SHA-256, elapsed wall time, peak RSS, swap, cgroup limits, Lean memory threshold, and references to raw log/time files. All runs used the pinned NUC workspace runner `compile-one.sh`, `MemoryHigh=4G`, `MemoryMax=6G`, `MemorySwapMax=0`, `TasksMax=128`, and Lean threshold 5000 MiB. Toolchain: Lean 4.32.0, x86_64-unknown-linux-gnu, commit `8c9756b28d64dab099da31a4c09229a9e6a2ef35`, Release.

There are 14 retained failed-source snapshots for 15 failed attempts. The failed `R1PoseidonMap-a` source snapshot is unavailable; its receipt, raw log, time log, sidecar, and source hash `de78174e8f974616c7f0fee03676ea655b71f0b4cca4dcdf71f7baa006646c45` are retained. It is superseded and is not used as a successful source artifact. All 10 final successful sources are included under `final-sources/` and have exact hash-matching copies checked against successful receipts. `runner/` contains byte-captured `compile-one.sh`, `run2.py`, and `environment-base.json` from the pinned NUC workspace.

`lean-append-tree-final-objects.tar` is the deterministic archive of the ten final compiled `.olean` objects. Its exact members are listed in `compiled-objects-members.txt`; `source-manifest.json` records the archive SHA-256, each member SHA-256 and size, and the archived uid/gid/mtime/mode. Each member digest was compared with the corresponding final object on the remote NUC; the comparison digests are retained in `remote-object-sha256.txt`. No loose `.olean` object checksums are included. `SHA256SUMS` covers the archive, manifests, this README, captured runner/environment files, remote-object comparison, final source snapshots, and captured run evidence (receipts, sidecars, logs, and available failed source snapshots).

Two dependency files received import-only changes to make the focused compilation work with targeted imports: `AspisFormal/AspisFormal/Pool/FormatV1.lean` replaces `import Mathlib` with `import Mathlib.Tactic`; `AspisFormal/AspisFormal/Pool/IncrementalMerkleV1.lean` replaces `import Mathlib` with `import Mathlib.Tactic` and adds `import Mathlib.Data.List.GetD`. Their theorem and proof bodies were preserved. The `*-before.lean` files retain their pre-change source snapshots.

This directory records compilation artifacts and provenance only. It makes no security, theorem-coverage, or proof-closure claim.

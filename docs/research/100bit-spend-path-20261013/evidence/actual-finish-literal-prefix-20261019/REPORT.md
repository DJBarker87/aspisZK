# Actual finish reaches a coupled literal first25 prefix

`RawBeginAnnotatedLiteralPrefix.actual_begin_and_rounds_coupled` derives one source/literal coupling from actual begin success and the same annotated polynomial rounds. Its challenge list is exactly the returned begin challenge list followed by those rounds' actual q values. `RawActualParsedFinishLiteralPrefix.parsed_finish_literal_prefix` then obtains those rounds from successful execution of the existing finish model and retains both this coupling (with `out.alpha`) and the existing R0P arithmetic chain. No independent source-trace existence premise is required.

The begin/round bridge passes in 2.176 s and the finish bridge in 2.938 s, exit0, standard axioms only, zero sampled cgroup swap. Both use native Lean4.32 on the NUC, 4 GiB high/6 GiB max/SwapMax=0, with exact source/object/import pins and fresh global admission. GNU time reports per-process RSS and swaps separately in the preserved logs. Earlier parse/import/name diagnostics are retained and do not count as proved targets. An admission denial occurred before any Lean process launched; the eventual launch used a fresh passing gate after reservation changes.

Remaining premises include strict-parse/public-byte/oracle-input/root correspondence, the finish boundary implementation refinements (`claims`, array fromFn, public terminal, circle mapper and other caller effects), and the four canonicality premises for the arithmetic chain. The result covers the first25 calls only; later challenges, commitments/openings, acceptance-to-Checks and complete quantitative/extractor composition remain open. The source model has not become a complete production verifier proof.

The coupled prefix is a sampler-prefix statement. Its positive-row constructor currently uses plain payload messages, including row2; `LiteralTranscript.valid` requires a C2-word-bearing message there. Erasure-preserving word decoration and binding that word to the actual commitment remain open even within these first25 calls. The theorem does not establish a valid commitment-bearing literal transcript.

They do not yet prove that the Rust prover’s extracted serializers instantiate these functions or satisfy the prefix law. `R1ProgOracleHonestLogV11` proves accepted programmed-log hits agree with the shared oracle under the explicit honest-log premise; it does not establish that premise for the concrete real prover log.

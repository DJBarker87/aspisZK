# Literal q22 read facts

This bundle records the successful deterministic bridge from a decoded ordered 22-query list to the legacy set-valued challenge set: it is the image of the Fin 22 coordinate function and has cardinality 22. It does not show that an execution produces a valid decoded list.

Attempt a failed and emitted two reports containing `sorryAx`; attempt b is final and emits two standard reports. The archive contains only the final module and its two direct-import objects. Exact snapshots, logs, resource receipts, source pins and runner pins are listed in `source-manifest.json`.

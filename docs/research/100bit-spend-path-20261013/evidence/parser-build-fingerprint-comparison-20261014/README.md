# Parser build fingerprint comparison

This bundle records a read-only comparison of the preserved P3 SBF build cache and the 2026-10-14 parser-candidate build. It contains selected Cargo fingerprint JSON, the two source-workspace `Cargo.lock` files, matching platform-tools metadata, and the separately produced mechanical ELF comparison. No builds were run for this comparison.

The old P3 source tree was `/home/dombarker/project-offloads/aspis-100bit-path-20261013/results/100bit-path-20261013/p3-native-gates/source`; the candidate source tree was `/home/dombarker/project-offloads/aspis-100bit-field-parser-candidate-20261014/source`. Exact remote fingerprint and lockfile paths, with their captured hashes, are recorded in `fingerprint-comparison.json`. Old and new `Cargo.lock` files are byte-identical (SHA-256 `f93f8f524fdd707c7a3b7feade31d015c891264b6c8fbd8bff885249e19600ea`). Probe/program feature arrays match, and both fingerprints record `-Zremap-cwd-prefix=`. Their opaque compiler, profile, target, path, config, compile-kind, and dependency fingerprints differ; the profile record does not expose textual LTO or codegen-unit settings.

The historical P3 **unstripped** SBF ELF is `/home/dombarker/project-offloads/aspis-100bit-path-20261013/results/100bit-path-20261013/p3-pool-13/bin/aspis_r1_cost_probe_program.unstripped.so`, SHA-256 `58235db5d3c94dc7fd20eec72152e2470246ce535061949621360a25b98b34e6`. It is byte-identical to the artifact in the old shared SBF target cache. Its `.comment` identifies LLD 20.1.7 commit `78496716176191b2dfb728e5e38501812e7467db`, matching the retained v1.52 platform-tools cache. The installed Solana `cargo-build-sbf` 3.1.13 binary reports platform-tools v1.52 and rustc 1.89.0, consistent with the ELF comment and cached v1.52 toolchain. The P3 SBF receipt records the generic `cargo build-sbf` command but not its executable version. The current root `.rustc_info.json` in the old shared target has since been overwritten by host rustc 1.94.1 / LLVM 21.1.8; it is included only as an explicitly overwritten, non-historical record. Taken together, the old ELF and matching cached toolchain identify the old toolchain with strong evidence; the ELF comment alone pins the linker, not the Rust compiler.

These old/new toolchains differ.

# Sequential finite root sampler: one correctness and probability contract

Five focused Lean modules join the successful-output certificate, actual sample consumption and adaptive abort probability for the same root-finder program. This advances the efficient extractor; it is not a completed spend soundness proof.

`SequentialProgramInvariants` proves branchwise invariant composition, exact sequential bind refinement, and that the final cursor equals the initial cursor plus the actual `eval` query-trace length. The invariant ranges over all answer branches, without imposing consistency at the factorizer's former heap addresses.

`CompPolySequentialFactorInvariant` proves, simultaneously on every branch, final cursor <= initial cursor + degree(f)-1 and successful returned linear-factor product = f. It reuses actual retry/divisor/complement correctness and distributes the query budget across the two positive-degree children. Aborted left children skip the right child; fuel exhaustion and all abort paths are included. It neither assumes sufficient fuel for its conditional certificate nor ignores abort consumption.

`CompPolySequentialRootsContract` specializes to the normalized squarefree root factor. Successful output contains exactly every input root, has no duplicates and has length at most the input degree. Every execution, including abort, has actual query-trace length at most degree(p)-1. Its combined contract includes the previously proved adaptive abort bound (degree(p)-1)*2^-t under the independent uniform field-tape law, in odd characteristic with q=card K and monic positive-degree input.

`SequentialFiniteTapeLaw` reuses `AspisV8R19.OracleFiniteSupport` rather than reproving finite oracle semantics. A bound on every terminal cursor implies all potential query addresses lie in the same finite initial interval. The existing finite-support theorem transports the lazy law exactly to a finite uniformly distributed table. Potential-support enumeration occurs only in the proof, not the root-finding algorithm.

`CompPolyFiniteRootSampler.runFromFiniteTape` is an executable definition (not declared noncomputable). Its input is exactly degree(p)-1 tape entries, each containing t field pairs. The correctness and abort bound are proved for that definition, without a distribution on infinitely many addresses or an enumeration fallback. The out-of-range default is unreachable by the proved support bound. This closes the earlier missing transfer from fixed-heap correctness to the sequential sampler. The block/trace budget is not a full arithmetic/bit operation bound.

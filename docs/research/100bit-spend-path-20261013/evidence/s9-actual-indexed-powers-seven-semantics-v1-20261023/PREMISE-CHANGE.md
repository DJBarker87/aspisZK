The previous four-entry theorem established decoded powers for powers(4,x). The new theorem concerns the actual SAME generic source function instantiated as powers(7,x); it does not assert equality between four- and seven-entry outputs. The prefix/output invariant is strengthened to canonicality AND decoded power. Its local write helper therefore adds canonicality of the written value, supplied by the existing source carry invariant. The final seven-power theorem retains only canonicality of x and that same source powers success. No independent output canonicality, output meaning or child success is assumed. Native arithmetic/read-write/frame and the existing generic loop invariant are reused unchanged.

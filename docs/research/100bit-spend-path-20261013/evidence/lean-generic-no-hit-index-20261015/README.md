# Generic no-hit index evidence

This focused target proves list-only consequences of `hitFrom`: if no bad round occurs in the full sequence, the indexed round is not bad under its exact accumulated prefix; and a no-hit sequence remains no-hit after truncation. It does not make a protocol, probability, acceptance, or security claim.

Both exact precompile sources, receipts, sidecars, logs, and time records are retained. The green run used Lean 4.32.0 with 4G high / 6G max / 0 swap.

# Premise removal

Before: the existing bounded-reader theorem required i<n relative to the actual successful length quotient, and this caller-domain fact was explicit.

After: the actual source Range.next success identifies j=iter.start and j<iter.end. Actual source successful continuation preserves the iterator end. Every prefix in Reached therefore supplies j<n internally. Field, scratch and push successes are inverted from the SAME successful source body, rather than added as desired child-success assumptions.

Retained: successful division and actual prefix/body execution. Reached is an operational prefix relation, not a bundle of desired output predicates. No canonical input data, exact byte length, arbitrary safe-index assertion, whole-loop success or abstract accumulator semantics is added. The done/error paths are explicitly separated from iteration exhaustion.

# EbyK constructor and first push

This packet proves that the installed typed EbyK constructor maps to the explicit zero source state and that a first push succeeds from that state. The first-push theorem derives the count-indexed sum invariants and exact source product update; it assumes canonicality of the pushed Wide value and coordinate bounds for the scalar. It is a source-model operation result, not an enclosing `Weights::pair` loop proof or a complete Rust Std refinement.

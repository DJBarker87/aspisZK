# Paired byte sampler, exact tape layout and actual decoder-bank adapter

The concrete paired sampler runs two maintained eight-limb samplers and rejects if either rejects. Exact product-fiber and success counts prove conditional uniformity of Fin n paired tapes with mass 1/P31^(16*n) per output. The output carrier has exactly P31^(16*n) elements. The executable tape Option collector succeeds iff every position returns the requested field pair and rejects iff at least one position rejects. Its implementation checks Option tags and reads successful values; it does not enumerate field values.

`GSDecoderTapeReindex.flatBank` is a computable finite equivalence from the flat paired tape to the exact nested range-indexed initial/final tapes. It preserves the uniform finite mean by the existing mean_equiv theorem. At the maintained public bounds and 149 retries it uses 21,377,328 field pairs, shared within the fixed-input groups rather than multiplied by the number of calls.

`GSRejectingSamplerDecoderBank.sampleAndRun` maps a successful flat sample through this exact reindexing into the actual 29-initial/5-final decoder bank. Its `failed_iff_output` identifies the probability event with actual output rejection or a failed bank output. `failure_small` proves total failure <2^-126 from two explicit sampler premises: unconditional output mass no greater than uniform and rejection mass at most2^-467. Those premises are not discharged in this packet; their concrete count/abort transport is the next target. The downstream uniform-bank bound is the already-checked <2^-127 theorem.

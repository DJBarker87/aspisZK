# Append-dependent witness chain evidence

This bundle records six focused green targets compiled from source base `1aca98e95c815befa58ed61e65cccd21c7bf10b9`: `R1SpendBaseDescent`, `R1TraceSpendWitness`, `R1ComputableTraceWitness`, `R1ConcreteSpendExtraction`, `R1TraceWitnessExtract`, and `R1ListWitnessExtract`. Their final `append-chain-a` snapshots match the current local files. Every target ran under MemoryHigh 4G, MemoryMax 6G, MemorySwapMax 0, TasksMax 128, with zero swap. Per-target time, peak RSS, exit status, source hashes, printed axioms, import pins, and runner hashes are in `source-manifest.json`.

The relation provenance matters: earlier `lean-spend-relation-20261015` and `lean-spend-relation-extraction-20261015` bundles captured a five-conjunct `Rspend` at source base `57edab99fe104f23b3d3c881d1e87c1abb0975c0`. The refreshed six-conjunct relation, including `AppendBinding`, was compiled in `lean-spend-append-binding-20261015` at base `94281d6fb07be39b7f70c0b8de115a092b86c4e2`. This bundle compiles the witness chain against that refreshed relation. Earlier green and failed receipts are preserved as historical attempts; they are not presented as recompiles of the six-conjunct source. In particular, the failed `R1ListWitnessExtract/list-witness-extract-a` receipt belongs to the earlier relation attempt and is retained as such. The current object archive and direct-import object pins apply only to the six final `append-chain-a` targets; they are not linked to the historical attempts.

The chain includes data selection, base descent, the concrete spend extraction theorem, single-trace executable checking, and the list wrapper. These are formal model results. This bundle does not establish Rust/source correspondence, proof acceptance implying production facts, or an efficient full-log decoder. `R1TraceValueDecode` is an unmodified dependency whose source/object pin is included; this does not assert a separate rebuild of it in this bundle.

`SHA256SUMS` covers the manifest, README, all preserved attempt artifacts, sources, runner pins, loose object files, and deterministic object archive.

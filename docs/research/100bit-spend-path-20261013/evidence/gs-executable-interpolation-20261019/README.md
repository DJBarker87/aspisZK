# Executable GS interpolation for both selected parameter sets

For arbitrary point-value arrays of the selected lengths, the two checked theorems prove that the actual CompPoly dense interpolation call returns some Q and that Q satisfies ValidInterpolationWitness. The initial parameters are messageDegree1025, multiplicity3, weighted degree114689, outer-Y limit112, points1048576; final parameters are messageDegree256, multiplicity3, weighted degree28673, outer-Y limit112, points262144. No assumed interpolation oracle, finite-field enumeration or supplied kernel vector occurs in these witness theorems.

The custom executable monomial basis enumerates outer-Y rows and inner-X exponents. Structural proofs establish ordering/no duplicates, weighted bounds and size. The initial basis has6,480,098 columns and6,291,456 constraints; the final basis has1,626,522 columns and1,572,864 constraints. The constraint count is proved for the actual imperative constraint builder, with6 constraints per point. A symbolic triangular-sum closed form computes both basis sizes without materializing millions of monomials or normalizing an unfolded recurrence.

The proof reuses CompPoly's verified built-in dense linear-kernel backend and its dimension-slack existence and bounded-basis soundness theorems, pinned to revision4165a87dd9a9ede48ee4dc5b4fe825604b8bb932 and the Lean4.32 cache release. The backend theorem is about the return value of that executable call; no full dense computation was run. The previous legacy113-term arithmetic proof informed the parameters, but importing the full legacy module exceeded the narrow consumer memory guard, so the count was factored into a small symbolic lemma.

Exact sources/imports/object hashes, commands, base revisions, status/time/RSS/zero process swap and printed axioms are retained. The top backend target passed in12.48s at2.12GB with standard axioms only; its transitive axiom audit covers the used basis correctness lemmas. RowBasis has no independent print-axioms lines; the consumer supplies that coverage. No full package replay was run.

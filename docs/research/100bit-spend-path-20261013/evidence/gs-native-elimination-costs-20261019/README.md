# Counted refinement of actual dense elimination and kernel extraction

Five native NUC targets connect explicit counters to the actual CompPoly implementation, proving exact output preservation and polynomial iteration bounds. Row updates count scaling, swaps and add-scaled loops. Normalization/elimination costs at most (rows+1)*cols cell iterations. The full RREF loop additionally counts pivot candidates and bounds total work by fuel*(rows+cols+(rows+1)*cols). Kernel extraction counts free-column detection, pivot-row search, basis-vector construction and the complete kernel-basis/witness selection; extraction work is bounded by cols*(pivots+1)*(cols+1), with one further witness-selection step.

These bounds count the named loop iterations. They do not count field operations, array copy/mutation overhead, memory accesses, or bit complexity, and are not a complete polynomial-time extractor theorem. Source and oracle algorithms are unchanged. The counted companions are formal proof instrumentation.

All five native object hashes were independently checked over SSH against the actual NUC objects. The raw packet preserves exact source snapshots, commands, resource cgroup caps and admission checks, import closures, source revisions, exit status, GNU time/RSS, swap, logs and printed axioms. All 28 axiom reports contain only standard axioms. GNU time maximum RSS (1.65--3.40 GB across these targets) is recorded separately from sampled cgroup memory. Objects are not committed. The worker manifest is retained unchanged. Earlier failed proof attempts remain at their pinned NUC attempt paths; they were repaired before new checks, with no larger-cap unchanged rerun. No full manifest replay was run.

Still open: field-operation/bit complexity, complete interpolation/constraint builder and recovery costs, joint list and spend-witness extraction, finite-bit sampler/caller composition, full protocol/ROM/source/runtime and privacy proofs, and the two-transaction release gates.

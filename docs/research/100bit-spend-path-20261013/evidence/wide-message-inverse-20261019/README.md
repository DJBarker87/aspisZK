The selected initial encoder has a 1024-dimensional image inside degree-at-most-1024 polynomials. It is not surjective onto that ambient 1025-dimensional polynomial space. An extractor needs inversion on the actual image plus a forward-image check for arbitrary candidates.

`WideExactInitialCirclePairInverseV5` separates the even and odd coefficients of the circle numerator and applies the finite-node fractional-lift inverse to recover both input polynomials. It reuses the maintained generic encoder identities. `WideExactInitialMessageInverseV10` then recovers the two natural-basis coefficient vectors and interleaves them into an actual 1024-entry message. Its theorem proves exact message roundtrip on encoded messages; the output is an explicit coefficient function rather than an existentially chosen witness.

Important boundary: the message-level decoder remains mathematical/noncomputable. It uses Mathlib Lagrange interpolation and the existing matrix-based `monomialToNatural`. No efficient executable whole-message inverse is claimed. The current continuation is a CPolynomial natural-basis construction plus triangular back-substitution, reusing the existing basis degree and injectivity theorems; a computable arbitrary-candidate image check is also still required.

It passed on the NUC using Linux-native builds of both exact pinned predecessors. This is an executable interpolation ingredient, not yet the whole message inverse. Native predecessor evidence is retained separately.

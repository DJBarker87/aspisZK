# Square-path U64 wrapping and checked primitive bridge

This focused proof provides value-level compatibility for `Std.U64` wrapping subtraction and bounded agreement of wrapping add/sub/mul with the checked `UScalar` operations. The bounds are explicit theorem hypotheses. The Lean run took 15.161 seconds, with peak aggregate RSS 2,165,899,264 bytes, peak process RSS 2,184,036,352 bytes, and zero swaps. Its transitive axiom report is retained. Compiled objects are referenced by hash but omitted. This is a source-level arithmetic lemma, not a Rust binary or runtime refinement claim.

# Aborting randomized RR traversal: recovery and adaptive failure probability

Eight focused modules supply one executable candidate-traversal program, successful-output soundness/completeness, and an adaptive abort bound. They reuse the earlier root-finder and actual RR algebra; this is not yet the fully instantiated spend extractor or the final soundness theorem.

`RRProgramTraversal.collectProgram` performs bounded-depth prefix recovery with randomized child/root enumeration. It visits reached children in order, prepends each root coefficient to its child's candidates, concatenates the outputs, and propagates any abort immediately. All program definitions are axiom-free. It never substitutes an empty complete list for root-finder failure.

`RRProgramMeanTools` proves expectation monotonicity only on actually reachable answer branches and short-circuiting union bounds. This lets adaptive returned child lists supply their own degree/multiplicity budget without imposing a contract on impossible outputs. Existing independent-answer semantics, bind, uniform mean monotonicity and scalar linearity are reused.

`RRProgramAbortBound.collectProgram_abort_le` proves abort probability at most depth * initial_mass * delta. Its explicit local premises are: each child-enumeration call aborts with probability at most mass(state)*delta, and every actually returned child list has total child mass at most parent mass. Child states, root order and later inputs may depend on earlier answers. All local and recursive aborts are counted; no global good-tape event or work/grinding credit is assumed. The base theorem is in the independent-answer interpreter. The checked `RRProgramSequentialContract` now transfers it to a fresh lazy sampler by sequentializing the whole traversal with one monotonically increasing cursor, so separate local root calls cannot reuse an address. Successful-output soundness/completeness transfers to that same sequential program. The finite-bit implementation and concrete caller instantiation remain open.

`RRReturnedRootMass.finite_sampler_child_mass_le` connects the already proved actual general finite-tape root finder to the preserved multiplicity budget. Returned roots are sound and duplicate-free; if each selected child's degree is at most the corresponding parent-root multiplicity, their total degree is at most parent degree. It reuses the old sum-of-root-multiplicities theorem and permits any returned ordering. The pointwise actual child-degree inequality is the existing RR normalization theorem's role and remains to be attached to the concrete all-branch child program.

`RRProgramWalkRelation` records actual successful child outputs in occurrence order, including repeated states with independently randomized ordering. Its generic propagation theorem is axiom-free. `RRProgramRecoveryContracts.collectProgram_correct` proves both candidate soundness and completeness for degree-bounded polynomial roots on every successful execution of that SAME randomized traversal. It reuses the existing prefix collector's polynomial head/tail reconstruction and tail-degree theorem. Its exact local zero test, root-preservation and root-descent/coverage contracts remain explicit and apply only to actual successful returned child lists. It does not assume a universal fixed root order or a globally successful root oracle.

Concrete normalized-row/scanner-to-CPolynomial/root coverage is checked in the separate actual-row bridge packet. Still open: construct the complete concrete randomized child program and discharge all local contracts, including full normalized-state model reconstruction and invariant preservation; compose global sequential tape freshness/finite uniform input and an efficient bit-to-WideExact sampler; prove whole-extractor arithmetic/bit costs and selected GS/list/message/image-check integration; instantiate joint recovery, source/runtime, hash/sampler and protocol premises and finish per-attempt probability composition. No numerical global extractor bound is claimed merely from the generic traversal theorem. No production source, runtime artifact or protocol parameter changed.

Evidence records exact target, source/object/import pins, source revision, commands, wall time, peak process RSS, process swaps and axioms. All eight accepted targets passed under pinned Lean4.32, cached imports, -j1/-M2048 and a 4GiB aggregate local Lean guard; process swaps were zero and only standard axioms occur. Failed local elaboration/rewrite attempts are kept under history. No unchanged full regression was run.

`CompPolyGeneralRootIndependentLaw` proves the general root program is fresh from an empty table and derives its abort bound in the independent-answer interpreter used for local child-call composition. This closes a law mismatch between the local lazy-sampler bound and the new adaptive RR theorem; it does not assume independence for a reused-address oracle.

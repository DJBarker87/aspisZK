# Program sampler and literal byte sampler

This bundle preserves the focused evidence for `ProgramSamplerMap` and `LiteralByteSampler`. `ProgramSamplerMap` converts done/ask programs into sequential samplers and transports independent-answer mean under address renaming. `LiteralByteSampler` gives the literal transcript sampler an all-byte address view, with exact evaluation-trace/output and independent-mass transport.

The evidence does not establish overlength fallback, a first-read decoder, first-read injection, shared-oracle INJ, or a Rust/source refinement.

See `source-manifest.json` for exact source/import/object pins, attempt classifications, resource receipts, and runner hashes. The two green targets emitted two standard axiom reports each; failed attempt evidence is retained.

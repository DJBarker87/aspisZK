CANDIDATE SOURCE ONLY. This kit does not change or extract the unchanged
production interface. prepare.py cuts the full sample_block_validated method,
Error and transcript fields from pinned b2ad source, then applies only the
documented type/call substitutions. --check verifies the inverse exactly.

Digest32 is a proposed real Rust trait declaration; no implementation, HashFn,
Fn adapter, dyn object, oracle axiom, constructor or source caller is supplied.
The experiment asks whether the existing translator supports this generic
method and its borrowed slice arguments. Successful emission alone would not
establish Rust semantics preservation, actual hash effects or release backend
behavior. It does not discharge hbytes/htyped/ha or all33-row provenance.

run-host.py requires verified matching b59/cb50 Linux tools and exact cgroup
high6G/max8G/swap0; one dependency-free crate, offline, jobs1, 180 seconds per
tool. MIR is built with checked overflow, as in earlier extraction kits. No
claim is made about release-profile overflow behavior on arbitrary rows.
No Lean, SBF, native differential or replay is part of this pilot.

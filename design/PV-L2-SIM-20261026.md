## Observable and target

For an execution, retain its complete ordered observation: public bytes and
adversary oracle history, the `SideChannelL1AttemptRecord.Run` record (including
all rejected/stopping attempt prefixes), and an L2 event list. L2 events carry
source site and invocation ordinal, branch outcome, comparison position,
array/collection address or comparison key, loop visit, allocation request,
and operands of division/remainder/inversion and other variable-latency
operations. Record returns, failures, caught panics and exhaustion at their
actual positions. Do not include fixed-latency field operands merely because
they are operands; their F1/F2 trace refinements remain separate dependencies.
Including variable-latency operands follows the assigned observation contract.
Allocator/std/hash/environment state must be carried or explicitly related;
deterministic function output does not specify those components' traces.

Use the actual headline's `W`, `Pr`, eight-attempt real experiment, owned
decoder and `ProverCommitReencode16.experiment ... encode`, with the unchanged
`simE`, not a replacement experiment. The desired result is equality of the
**joint** real and simulator observation laws off the existing bad events.
Concretely, on the existing measure-preserving coupling, establish pointwise
equality of `(view, oracleHistory, L1, L2)` outside that union. This gives the
same event-test bound as the headline, without an additional copy per row:

```
modelError W Pr L₁ L₂ + 16 / 2^486
  + QueryScanFreshUnion.freshBudget (8 * n1 W Pr + 1)
  + 2 * ProverCommitSeedEvent19.budget (2^64)
  + 2 * ProverCommitFuelMass22.charge
```

Here `L₁/L₂` are the headline's decoder bounds, not leakage levels. Existing
events include the model's bad events (pole/other model failures), QueryScan
parser failure, honest-read ROM collision/public-address collision
(`QueryScanRealLazyBound.lazyBad`), adversary seed-address hits, and fuel
failure. Charge them through their existing proofs; do not assert that an
unmodelled trace mismatch is one of those events. Exact equality of the
unconditional laws is not promised when those events have nonzero mass.

The concrete deployed premise is `PrivacyR1HeadlineDeployedReal.RustRealRefinement`:
its `ProverCommitFuelJoin22.RunJoin` currently joins views/observer decisions,
QueryScan failures and seed-query histories. It does **not** join an arbitrary
new event list. A new trace-preservation assumption would not discharge L2.
Likewise postprocessing the full real ROM vector on the lazy coupling does
not by itself transport it through witness-hiding tape absorption to `simE`.

## Proof order and acceptance tests

1. F5 first: define observations on the actual raw vectors, parser states and
   challenge coordinates. Start with preservation of the complete QueryScan
   comparison/stop history under `real_vector_toRP`, using its existing
   `lazyBad`, `RAddrIn`, and `RCausal` hypotheses. This is a real-to-lazy bridge,
   not yet real-to-`simE`. Then prove raw sampler/circle and sparse point
   factorizations, with source joins for control absent from Lean. Transport
   the joint history through the existing tape/view coupling before calling
   any row simulatable. Do not replace that step with an assumption asserting
   the desired joint agreement.
2. F3 next: retain the actual public-nonce two-seed E1 schedule and L1 attempt
   owner erasure. Prove a seed/expander-history-preserving coupling jointly
   with the view; count-history preservation alone is insufficient. Account
   for refill boundaries, scalar cap 16, qm31 partial failure and ROM addresses.
3. F6 last: first opening-address factoring into `PhaseWireLog2Bin` and the
   ordered challenges recovered by `ProverCommitReencode16`; then actual
   sort/dedup/sharing/Vec cost semantics; then P_R1 generation/checking and
   certificate work on every reached attempt, including failures.

For Rust-only control, use bounded, stub-free two-run cfg(kani) harnesses
against actual shipped bodies. Same-input determinism alone does not show
that those inputs have the right joint law. Split a timeout into smaller
source functions or use an owned reference with source equivalence and a Lean
join, per P6. Existing leaf checks are reused only at their stated scope:
seven bounded source-expression checks, partial reference observations and
generic finite-count transport; none closes a complete row.

Smallest changed module first, then dependent bridge and axioms audit. Every
new top theorem must print only standard axioms. No full manifest replay
before focused targets are green and the source/coupling cone is complete.
One host scope at a time, 6G high/8G maximum, swap zero, TasksMax 64, Lean
`-M7000`; no cold local dependency build. Compiler attempts and Kani runs
are separately charged. Record source/dependency fingerprints, target,
exit/wall/peak RSS/swap and full axioms lines in committed evidence.

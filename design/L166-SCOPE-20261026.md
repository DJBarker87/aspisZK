## Exact remaining statements

There is **no pre-existing Lean proposition named L166**. It is a deployment
ledger row outside the actual theorem's binders. Its natural-language label
cannot be treated as a hidden proved theorem. The following is a checked,
explicit local specification of the adopted ruling (BEh_Scope.lean). It is
not a new hypothesis installed in the top theorem.

```lean
abbrev Outcome (S A E : Type) :=
  Result (core.result.Result A E) × S × SdkC_Source.Log

def AcceptedPath {S A E F : Type}
    (native : Outcome S A E) (source : Outcome S A F) : Prop :=
  (∀ a, native.1 = .ok (.Ok a) ↔ source.1 = .ok (.Ok a)) ∧
  (∀ a, native.1 = .ok (.Ok a) → native.2 = source.2)

def RejectedPrefix {S A E F : Type}
    (native : Outcome S A E) (source : Outcome S A F) : Prop :=
  (BEg_Observation.accepted native.1 = none ↔
    BEg_Observation.accepted source.1 = none) ∧
  (BEg_Observation.accepted native.1 = none → native.2.2 = source.2.2)

def BothSlots {I S A E F : Type}
    (admitted : I → Fin 2 → S → Prop)
    (native : I → Fin 2 → S → SdkC_Source.Log → Outcome S A E)
    (source : I → Fin 2 → S → SdkC_Source.Log → Outcome S A F) : Prop :=
  ∀ input slot state before, admitted input slot state →
    AcceptedPath (native input slot state before) (source input slot state before) ∧
    RejectedPrefix (native input slot state before) (source input slot state before)
```

All type parameters are universally quantified. `I` must be instantiated with
ONE actual reached cut: proof bytes/slices, Prepared query/root arrays, folded
root, batch ordinal, allocation/borrow geometry and initial native state.
`S` denotes a **common observable projection** of the two representations;
it does not require equal machine pointers or preservation of dead private
scratch. Scratch still live between the three tree calls must be related at
those intermediate cuts. `before` is the SAME attempted history, and contains
occurrences, not deduplicated addresses. `admitted` must follow from the
actual enclosing runtime/cut, never be a premise containing this conclusion.

`source` is to be the stateful interpretation of
`SdkC_BatchSource.currentCode` / `stageCode` on that cut. `native` must be an
instrumented interpretation of the shipped body. No such concrete state/log
interpreter is supplied by D188's value-only function type. The generic
quantification above therefore specifies the missing instance; it does not
pretend that an arbitrary function denotes shipped execution.

This local exact-log requirement is a sufficient literal formulation of the
ruling at the batch boundary. The separate global requirement is to associate
these physical prefixes with the SAME original-account/headline recorder and
failure event. A proved event/probability transport could weaken full global
trace equality. Neither result equality nor a separate recorder budget does
that. No stronger global equality is imposed here as an unapproved new game.

`BEh_Scope.of_observe` proves BEg observation equality sufficient;
`BEh_Scope.logs` derives exact all-outcome local logs from this law.
`BEh_Countermodels.rejected_state_not_required` proves the ruling is strictly
weaker than requiring BEg's complete rejected-state equality: inner Err and

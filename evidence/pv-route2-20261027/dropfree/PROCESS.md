# Invocation and admission notes

All measurements use the unchanged pinned extractor with preflight on. No local Lean compilation. The fresh budget is separate from the historical 52100-series budget.

The first two admission scans encountered vanished unrelated cgroups (charon-252-01 and aeneas-252-02); each refused scan started no scope. They were followed by fresh receipt names after the required 30-second wait. Aeneas-252-03 consumed the already generated LLBC, avoiding an unchanged Charon rerun. Its loop version passed preflight but failed internally. The next source expands the known fixed loops; it is a changed input, not an unchanged failed rerun.

53300–53302 are admission-only IDs. The aggregate gate reported 51,405,389,824 reserved bytes and 59,995,324,416 projected bytes against a 59,055,800,320-byte safe limit. No Lean compile was charged. 53302 was requested less than three minutes after 53301: this was a retry-cadence deviation; admission still refused and no scope started. The subsequent invocation wrapper waits the full three minutes and advances to the next unused ID after every refusal. Shared reservation/launcher files were not modified.

The per-job invocation wrapper records transient scanner errors and wait/retry actions; it does not bypass the gate or increase caps. Each scope has MemoryHigh=6G, MemoryMax=8G, MemorySwapMax=0, TasksMax=64. The accepted shared Lean launcher setting remains TasksMax=128. Only one scope in this job is allowed at a time.

Sampler successor notes: the scalar-byte/index variant initially still includes `canonical_qm31`'s generated FnOnce call wrapper, whose structured Drop triggers preflight. `sampler-drop-shape.json` records that exact function and dropped place. This is a conservative Drop syntax refusal, not proof that the closure owns heap storage. A direct-field draft then fails Rust E0451 because WideExact fields are private. The final probe calls the public rejecting `from_limbs(...).unwrap()` constructor; every limb is produced by a remainder modulo P. That removes the closure dependency without unsafe/private-field access. A formal always-Some/canonicality/source bridge is still required.

Public-bytes iterations: 226-01 passes Drop preflight, then fails `PrePasses.ml:840` (`Nested-loop returns require exactly one Option language item`). 226-02 expresses the same canonicality rejection through a named Option-returning helper; it clears that pass and fails in `InterpBorrows.ml:2731` at the final frontier loop. The next variant expands the fixed frontier/byte loops, retaining the field loop, error branch and output order. All failed inputs and exact errors are retained. The first combined phase driver returned exit0 when its inner extractor failed; only the extractor's own exit2 is used for classification. Later driver invocations propagate the inner exit. Caps, admission and extractor binaries are unchanged.

226-03's expanded fixed frontier loops timed out at180 seconds (extractor exit124), peak6,429,808KiB, swap0. It is not rerun and the cap is not raised. The old phase process had already loaded its driver before exit propagation was fixed, so its outer scope exit0 is disregarded in favour of inner exit124.

The current native flush returns a deferred enumerator back function; retained
S8 returns an already applied enumerator. Its enumerate closure also has a
different ABI. This is a carrier/lowering proof obligation, not definitional
equality. We will prove the deferred application invariant symbolically.
Finish consumes the materialized returned query state, rather than the old
pre-flush Vec. Physical dot=rhs and next22 already hold; Frozen2 also needs
same-reader checks and session-A S3/S4/S5/S9 arithmetic interpretations.

All host compiles use admitted isolated scopes, 6G high/8G max/swap0/tasks64,
Lean -j1 -M4400. No source/ELF rebuild is triggered by proof-only additions.
Inherited historical ELF pins are not newly reproduced. No keys are touched.

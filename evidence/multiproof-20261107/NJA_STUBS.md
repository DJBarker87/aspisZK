# NJA field and runtime stubs

No Kani stub is admitted yet. Required M31 multiplication row: actual frozen
M31::mul, canonical operands (<2147483647), exact natural modular product; pair
with emitted/probe equality and a named Lean ok/value theorem. pow5 has three
calls: x*x, square*square, fourth*x; each returned canonical result establishes
the next call's domain. No field multiplication is verified in Kani.

Digest callbacks certify tag 0x12, exact left/right slices, chronological call
and unchanged reply. Digest value remains accepted runtime trust. No SHA unwind.
No writable static, Option<fn> observations or replacement copy stub is permitted.
Copy-dependent native evidence requires the exact KMX patch hash and a matched
failing control in the same configuration.

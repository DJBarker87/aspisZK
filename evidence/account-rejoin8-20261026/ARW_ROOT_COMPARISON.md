## What changed, and what was proved

`P` is no longer independently universally quantified. It is defined as `ARW_Induced.program native1 copy allocator CPH_Program.verifier a`. Its first native wrapper is evaluated as a pure model computation; only a.first and the reached a.second issue queries in P. `ARW_Induced.evaluation/queries/output` prove the exact complete log and unchanged submission. This is a query metric identity, not a claim of free concrete native computation. The universal adversary binder still ranges over every `SCE_Experiment.Adversary A`: no adaptive second choice, duplicate, ignored query or rejected native prefix is restricted.

`queries` bounds that native execution's total reached adversary-issued calls in every world. On each supported admitted world, `ARW_AdmittedQueries.admitted` identifies this cost with the partial account's work. `ARW_AdmittedBudget.issued` gives the same run Q0+Q1+1921 total issued calls. `ARW_QueryAgreement.exact` extends the identity to rejected source-compatible first-wrapper outcomes. `ARW_Carrier.exact` gives the induced P's original proof/public bytes and the SAME saved checkpoint on the selected source cuts.

The independent runtime and binding binder are absent in Requested, as in ARV's proposal. All other binders and conclusion expressions are literal Rc10, including the source-recorder account collision event at Q0+Q1+2965, Q+34 model starts, exact failure functional, decoder, carrier, native tuple, global finish owners, range and zero-query margin. No replacement account event, probability conditioning, extra support hypothesis or runtime trust item is installed. `ARW_Observations.observations` proves all those native/source conjuncts except the three runtime probability assertions, without a binding, independent runtime or substituted numerical premise. `ARW_Residual.characterization` proves Requested iff its exact remaining numerical runtime bound. This is NOT a proof of either side.

## Checked obstruction to the claimed admitted world range

The literal `ART_Runtime.runtime` has no L, admissions, bank game or persistence parameter. Its `eval_runtime` always returns some RunView for every partial-account world; acceptance comes solely from the two partial wrapper Results. Its failure functional `F3T_RuntimeBound.failureModel` is still a global lazyMean plus scan failure. Rc10's admission1/admission2 concern independently bound e1/e2 at a supplied tuple. They do not filter the worlds of runtime a, nor associate e1/e2 to arbitrary a's selected entries.

`ARW_DisconnectedAdmissions.obstruction` strengthens the old one-tuple diagnosis: the SAME supplied native supported tuple remains fixed, but a constant b has both native induced issued cost and full ART work ZERO in every world; in that SAME native world the partial account accepts b and no At representative exists. `ARW_RuntimeDomain.obstruction` expresses this directly as an accepted RunView satisfying the requested induced P budget for EVERY Q0/Q1. The malformed TX2 aliases its data/lamports handles; `ARV_Poison.no_admission` proves it cannot satisfy any runtime admission. It is OUTSIDE the approved game and is NOT a deployed attack. This is not a numerical failure-bound counterexample and does not refute a correctly defined admitted experiment. It refutes the claim that the literal runtime term already has that admitted domain, even after fixing the work binder.

`ARW_AdmittedSupport.original` proves the correct own-tuple cylinder result by ARU_OriginalFactory.original. Its SupportedEntry input explicitly contains the native successes, admissions, approved game and RuntimePersistence on a's OWN world-selected entries. Those are exactly the data an admitted experiment must supply. The factory cannot create them from the independent original e1/e2 fields. Likewise ART_FullCharge.charged still requires a global partial-account work bound; the admitted-only native identity does not establish that hypothesis for unsupported worlds. Neither gap is hidden in a new top hypothesis.

Interpreting the approved world-range change as an admitted observer/law would be a specialisation to the approved game, not a restriction of the adversary. But that observer/law must be defined and its cost/outcome equivalence proved. It is not implemented by keeping the present ART_Runtime term literal and changing prose. I asked the lead whether change (ii) authorises that actual term/law change; no answer is assumed. No support filter or stopped-source interpreter has been adopted here. The global numerical bound for the literal Requested term remains open, not proved false.

## Conservativity and non-vacuity

`ARW_Conservativity.program_on_old_class` gives literal P=submission a when a.second is a pure response-independent choice; `queries_on_old_class` preserves the old bound. `ARW_OldRoot.conservativity` proves that Requested, if established, yields the full old Rc10 conclusion on that class with identical constants. This implication openly assumes Requested; it does not install it as a security assumption or claim ARW_Root.deployed.

`ARW_Nonvacuity.conditional` preserves the SAME JFx_NativeBytes proof/public bytes on a supplied complete native tuple's cylinder in the original ART runtime. It does not construct the still missing joint extracted accepted1/accepted2 pair. The exact partial JFm/JFn/JFr/JFs/JFu/JFv predecessors are checked in ARW_FixtureAudit and pinned separately. In particular JFu_Installation's extraction uses its own seeded configuration; JFv_RuntimeWitness.compatible supplies SDK/std/admissions/game/persistence but not the complete installed native successes. No nonexistent complete-pair theorem is named.

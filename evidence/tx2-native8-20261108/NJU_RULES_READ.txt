### Lead ruling (y), 2026-10-29: assume-guarantee composition for non-scalar native interfaces

Finding (NED_, slice S composition, budget exhausted, 0/97 rows): every root stopped at the same point. The caller was proved natively with ARBITRARY child replies (K034/K035: frozen validator control, Result and ordered call log under arbitrary cached replies). The worker held that each reply still needed "the selected callee bridge instantiated on the identical carrier and state" natively, and found no medium for Box, large-array, account or effect interfaces. Kani 0.67 stub_verified does not cover slice or Vec returns (ruling w). That is a missing composition principle, not a missing proof, and the shared obstruction is resolved here as a method decision under the 2026-10-28 delegation.

Ruling (y): a call edge caller -> child with a non-scalar interface is DISCHARGED by assume-guarantee composition when all three of the following hold.
(1) Caller certificate (Kani, frozen caller, deployed features, KMX copy stubs where copies are reached). Each call to child is replaced by an oracle that records its exact arguments, including borrowed windows and the pre-state of every account or buffer the child may touch, and returns an UNCONSTRAINED value of the child's full return type (Result including every error variant). The oracle applies an UNCONSTRAINED mutation, limited to the child's declared modifies set. The harness proves the caller's Result, final state and ordered effects equal an explicit function G(args, oracle log), and that every logged argument lies in the child's PacketDomain. A matched failing control is required: corrupt one reply or one argument, and the assertion must fail.
(2) Child certificate: the child's existing bridge (four-part, CLOSED-CONDITIONAL in NDT_) gives reply = f_ref_child(args) and effects = declared effects on its PacketDomain. Its proof_for_contract must include a modifies clause covering exactly those effects; a missing frame is a finding, not a pass.
(3) Lean certificate: G(args, log with each reply and mutation := the child model on the logged arguments) = the caller's cohort model, including Result, state and ordered effects.
Substituting the child's real execution for the unconstrained oracle is the standard assume-guarantee step. Its soundness rests on Kani's handling of the oracle and modifies set. That is the native-contract semantic transport already classified under amendment five, option A, as P6/D188 tool trust. Each use is reported as reclassification, never removal, and no new trust row is added. Model-only equalities never substitute for (1) or (2).
Loops (scan_proof_buffer) keep ruling B: one native iteration from an arbitrary pre-state, with the same oracle treatment for calls inside the body.

Also binding from now on: finish ONE root end to end before spreading. Slice S starts with validate_pool_v1_pair_forest_terminal_statement_v1, whose subtree is fully bridged and whose K034/K035 already supply part (1).

### Lead ruling (y'), 2026-11-01: borrowed-return interfaces under ruling (y)

NEJ_ (slice-s-compose3, merged) reached 14/97 slice-S composed rows CLOSED and proved the common-encoder write frame. The validator root is blocked because Kani 0.67 cannot generate Arbitrary<&Common> for stub_verified of a getter that returns a borrowed reference (NEE_K039). Ruling (y) does not depend on stub_verified. Clarification, binding:
(1) For a child whose return type borrows from the caller's state, such as a getter returning &self.field, the caller certificate uses kani::stub (not stub_verified). The oracle's return value is fixed by the child's frame contract, not arbitrary: a reference to the place the child's contract designates (for a field getter, the actual field of the actual receiver), so the borrow's provenance and lifetime are preserved. Where the contract allows any value, the oracle returns a reference to a harness-owned arbitrary value of that type, with the same mutability, that does not alias anything the caller can see. The pointee may then be any value, and the reference is the only thing introduced.
(2) Child certificate for a pure field getter: a source-level identity check (the frozen body is exactly `&self.f` or an equivalent projection, checked by a script with mutation tests), plus the extracted-body Lean identity. For any other borrowed-return child, use the child's four-part bridge with a contract stating which place is returned.
(3) A matched failing control is required: the oracle returns a reference to a different field or place, and the caller assertion must fail.
This is a clarification of ruling (y) (option A reclassification), not new trust.

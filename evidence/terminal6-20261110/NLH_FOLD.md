# Fold-first construction

NLH_FoldCore is a local analogue of NHZ_DRIVER.events_from_cuts: field-helper events carry structured values rather than hash syscall parts. It carries one state through source-order events, appends no suffix after fail/div, and retains the attempted event as part of the prefix. This generic algebra is SUPPORT only; it has no native-cut existence claim. Each owned function will instantiate its own state/event type and actual step function, with row-packet hypotheses allowed only in intermediate lemmas.

A successful compilation, a synthetically constructed observation, or a generic fold theorem earns no row credit. Native window association and every child domain at SAME arguments remain mandatory.

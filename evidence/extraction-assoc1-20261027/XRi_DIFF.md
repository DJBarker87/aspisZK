# Release / cohort declaration comparison

XRi_declaration_diff.json inventories every explicit declaration in the selected
historical producer pair and both emitted release files plus their templates.
It maps all 1,599 PublicPreparation-prefixed constants in the adopted-top audit
RPz8_657 to the longest selected producer declaration prefix, or explicitly
marks them outside that pair. Generated constructors, fields and helper constants
are mapped to their containing source declaration; no such mapping is an
identity proof. The complete reused audit is hash-pinned. It is the ARX audit,
not Rc7 and not a new successful release replay. Model/proof declarations owned
by other modules are not misleadingly called emitted Rust declarations.

The 132 explicit cohort declarations yield 32 same normalized texts, 22 different
texts, 5 template-only candidates and 73 without an exact named release match.
Of 81 source declarations reached by ARX: 29 same texts, 21 different, 5 template
only and 26 without a match. Each compared changed declaration has its own
XRi_diffs/XRi_*.diff. Missing names are a comparison result, not a claim that no
possible association exists. Known WideExact/Digest32 path moves are recorded
as candidate name mappings, not substitutions. Comments, attributes and whitespace
are removed for comparison; carrier/body identifiers are NOT normalized away.

## Association boundary findings

- Prepared.new adds scratch29 and returns (inner Result Prepared Error, scratch).
  Query errors retain input scratch. Only after queries and scalar_k succeed
  does powers29 run; prepared_claim errors then return the new powers array.
  Outer Aeneas failure/divergence and inner verifier errors remain distinct.
- WideExact is external in release output, whereas the cohort has an inlined
  two-QM31 structure. The release Digest32 dictionary uses the digest submodule.
  Carrier relations, dictionary laws and ordered digest effects remain open.
- prepared_claim is opaque in the release FunsExternal template. Its signature
  takes powers29, not gamma. Complete Funs emission is not a body proof.
- QueryGeometry includes line_z; for_range emits collection/map closures.
  Successful cache equality alone omits failed construction and all index bounds.
- canonical.Dot drops count, and its release push is opaque. No-wrap must be
  joined to reached caller counts; the old check cannot simply be deleted.
- candidate.tx1 replaces the retired dispatch; no universally quantified
  old/new acceptance equality is claimed. SPLIT, physical compact bytes,
  binary multiproofs, deferred weights, checkpoint and chronological oracle
  transport remain part of the required same-execution association.

This is declaration-level evidence only. No class of different declarations is
asserted equivalent, and matching normalized text does not prove carrier identity.
No D188-P2 row is removed by this stage.

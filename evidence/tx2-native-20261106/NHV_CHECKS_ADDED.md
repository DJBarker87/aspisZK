# Additive validation and retained admission

NHV does not replace any NDT/NFK/NFQ/NHO admission check, remove any rejection,
or change a baseline status. No new composed row is admitted. Its validator
checks the unchanged baseline evidence pins, exact source snapshots, complete
per-crate deployed features, frozen dependency graph before EVERY native run,
offline optimized settings, unchanged lock after, exact KMX patch, reservation
exit0 AND allowed:true, actual limits, scope budget and file-size hygiene.

A local cut pass is not a callee law, not a producer-domain proof and not a
native slot installation. Packet selection must name all three, with SAME
arguments and returned values. Corruption controls must semantically FAIL;
compile errors and timeouts are not accepted as controls. Under (ae)/(al) the
rename partner must also semantically PASS. Raw standard-only ax2 and zero-defect
coherence scan remain mandatory. Failed sources are never selected. No credit
from quarantined function-pointer values, writable statics or weakened domains.

No native contract/stub_verified route is used, so no uncaptured Result carrier
is havoced. Explicit constructors cover every deployed verifier Error variant.
The generic native hash parameter is specialized to the deployed call shape;
the hash VALUE is never invented or unrolled by these driver probes. The actual
Merkle packet is OPEN and cannot be replaced by RootLog or an H-value premise.

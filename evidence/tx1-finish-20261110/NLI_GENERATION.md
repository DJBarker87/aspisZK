# Source proof generation and splits

NLI_generate_suffixes.py drafts the readless source ladder using explicit per-occurrence actions and backward live-slot sets. NLI_split_windows.py isolates each still-uncompiled concrete normalization as an abstract-fuel head and a chain theorem. NLI_FoldPhase/NLI_FoldTicks replace the administrative phase/no-op occurrences. Chain applications pass only the dead slots into the successor base record, and qualified successor names avoid local-variable shadowing. Checked source modules are not regenerated or rewritten; per-attempt source snapshots are authoritative.

L029 and L033 are the two retired concrete-normalization memory shapes. Their generic head and chain replacements compile at the original caps. This is source algebra, not native P6 credit. No child arithmetic implementation is unfolded.

The native rounds files are uncompiled drafts until native receipts explicitly say otherwise. Their prefix records range over27 independent offset/length windows in the13831-byte backing; no short-record restriction or all-records-alias assumption is intended. Digest carrier is the program's actual private SolanaDigest via a cfg-only program module, not the old Hash(u64) constructor specialization.

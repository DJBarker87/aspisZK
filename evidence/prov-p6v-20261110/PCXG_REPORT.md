The Stream A lead fixed the release universe as the L187 replayed closure. Every credited file was recompiled there: the 22 bundles PRVCmb_C01 to C22 (the 293 credited files of PCXF_CREDITED_FILES.json, including P1k in C22), PRVH_WrapAdd, and the 28 deployed-body modules of the P3m to P3r chains (PCVN, PCVQ, PCVS tx2 chain; PCVP NOC stage1, stage2, prepare, tx1 chain). Every scope has a receipt (PCXG_Lnnn/receipt.json) and a line in PCXG_ATTEMPTS.jsonl with exit, wall time, process peak RSS (at most 6.74 GiB) and swaps (0). Source revision recorded in every receipt is the worktree HEAD at launch.

All 22 bundles, PRVH_WrapAdd and the 28 deployed modules exit 0 against the L187 objects with no changed proof. The root PRVCmb_L187_ROOTB (PCXG_L020, 44 s, 6.08 GiB) imports PRVH_WrapAdd and the 22 bundles and audits 13,206 constants: 4,867 theorems one by one, none skipped by the time guard, axiom union propext, Quot.sound, Classical.choice, no local axiom declaration (#print axioms lines in PCXG_L020/PRVCmb_L187_ROOTB/stdout.log.xz). All 1,058 credited theorem records are found by name (PCXG_AUDIT.json, PCXG_RENAMES.json). Four separate audit modules (PCXG_L021: PCXG_AUD_L1, L2A, L2B, L2C, 16 to 38 s, at most 6.74 GiB) audit a further 227 theorems of the deployed modules, standard axioms only, and find all 70 credited deployed-body names (PCXG_AUDIT_L.json). All set_option maxHeartbeats values in the compiled sources are at or below the Aeneas file default 1,000,000; no sorry, native_decide or axiom declaration occurs.

This is not one import. Two shapes did not work and were changed, not rerun (PCXG_UNIVERSE_FINDINGS.json):

* F1. PRVCmb_C18 hit the 180 s timeout (PCXG_L012, exit 124; 60 s in PCXE_L001). The host is throttled and shared; this is speed, not a version difference. It was split at file boundaries into C18A to C18D with the file texts unchanged; all four exit 0 (PCXG_L014, L015).
* F2. The single all-in-one root importing the bundles and the deployed modules failed at import (PCXG_L019): PCVH.dec_qm is declared in both PRVCmb_C19 and PRVEq_PCVH_R1CandidateWideParserSource_k1. The shape is retired. The release-universe provenance root is therefore PRVCmb_L187_ROOTB for the 22 bundles plus four audit modules for the deployed bodies, all built in the L187 closure; the brief's single root PRVCmb_L187_ROOT does not exist.

# Exact scope of the SLICE models

The f32/f33 models are bounded reifications of the CLOSED provider's supplied
original-machine execution, not new source-semantics facts. The machine,
handler/backend, explicit entry store/world, caller context and prior events
are arguments. `run n` is literally the provider interpreter at that entry.
The fixed eligibility predicate is the provider's own boundary, frame and
event-prefix clauses on THAT run; it never quantifies over an independent
output or a different backend answer. The chosen natural number is the least
eligible fuel within the provider's bound. Off-domain absence falls back to0;
the CLOSED contract establishes eligibility on its unchanged domain.

`law` is equality with ONE public observation of this function. It is not the
provider's existential Post or an image of a native Cut/reply relation.
`certified` connects the selected run to the provider's literal Post clauses;
`functional` rejects two different observations at the same entry/environment.
Only activation-counter abstraction and event-only abort observation come
from the existing PLIB observation adapter. No arbitrary store delta is used.

This proves a qualified provider-model graph. It does not prove that the
least *certified* boundary is the first syntactic source boundary, that the
actual f21 caller establishes the unchanged provider Pre/MachineSpec, or that
the full frozen source specification follows. No such strengthening is
claimed or silently inserted into the frozen specifications. Those are
separate caller/composition/adequacy obligations, as with the base adapters.

The typed Drop model uses W2's `AfterDrop.finish` and the full actual handler
reply. Its execution equality is supplied by `RuntimeDrop.run`, whose source
projection is DERIVED from the actual typed f22 body and frame. Selection of
Regular22 is reused from `DestructorBinding.selected`. It closes no full f7
contract, whose f6 source/frame dependency remains unproved.

The entry header model reuses `Source7EntrySelection.header` and
`Source7EntryReferenceValid.column` BY NAME for all columns, including empty
ones. It retains `FoundationConstructionEntryObligation` as the named caller
obligation. It does not prove that the Foundation builder satisfies it.

No new native/operator/representation fact, T field, endpoint premise,
implementation edit, ledger status, row consumer, or package-branch change.
Target not yet established.

# Adopted root versus fixed terminal installation

ARX_Root.deployed quantifies arbitrary c and uses FIp_Install.configuration.
FIp_Install.slots says its terminal is c.boundaries.terminal. FIp_Blockers already
proves arbitrary_terminal: a caller-supplied constant terminal survives this
configuration. FIq_Install.configuration explicitly replaces that slot; FIr uses
FIq, whereas ARX uses FIp. FJn_InstallationBoundary records these exact identities.

This is an installation distinction, not a counterexample to the cryptographic
bound or a constructed accepted malicious proof. Proving the actual fixed FIq
body cannot identify an arbitrary supplied callback. Specializing c with FIq.seed
would change the literal installation in the ARX statement and all source/native
associations that depend on it; it must not be misreported as byte-identical
premise removal against the universally quantified original root. No adoption
change is made here. Independent same-execution terminal proof work continues.

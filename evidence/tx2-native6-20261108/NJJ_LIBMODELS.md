# Rule-3 external library models

No new trust row. This is a rule-3 library interpretation under (au)(3), not extraction of a replacement shipped implementation. Models are reusable only on the domains stated here. Native copy mitigation is the exact KMX patch recorded in NJJ_STUBS.md.

| External | Documented semantics and hand model | ONE differential and matched control | Domain / limitations |
|---|---|---|---|
| Iterator::any, resume nonzero-byte predicate | [Rust Iterator::any](https://doc.rust-lang.org/std/iter/trait.Iterator.html#method.any): visits items in order, stops on first true predicate, returns false on exhaustion, and leaves the receiver after the consumed element. NJJ_Any.run models precisely those next/predicate branches using the pinned Aeneas next. NJJ_Any.loop/source/installed identifies the full Bool × iterator with the existing resume external; next_frame/frame retains complete backing bytes. | NJJ_K005 PASS; NJJ_K006 matched inverted Boolean FAIL. Same harness name NJJ_lib::any_step; arbitrary byte window/cursor/end, at most ONE item, empty/hit/miss and entire suffix/frame. | Header's pure byte!=0 predicate, Unit callback state, valid slice iterator. Not a claim for arbitrary effectful FnMut or arbitrary iterator implementations. General iteration is the Lean structural induction, not a whole-buffer native run. |
| slice::ChunksExact next/remainder | [Rust ChunksExact](https://doc.rust-lang.org/std/slice/struct.ChunksExact.html): disjoint full-width chunks in input order, trailing incomplete suffix retained separately. NJJ_Chunks.State/next/remainder retains all remaining bytes; step/end_frame/window/frame give complete next and disjoint suffix composition. | NJJ_K007 PASS; NJJ_K008 matched inverted entered-branch FAIL. Same harness NJJ_lib::chunks_step; arbitrary backing/offset/end/width in1..8, chunk bytes, remaining count, original incomplete suffix, and one following window. | Model proof is generic in byte type, remaining length and positive width; native differential is a small diagnostic against documented semantics, not an exhaustive claim for all slice sizes. Zero chunk width is Rust panic and is outside positive-width model. Caller must prove its actual width positive. |

The documentation was checked 2026-11-08 (rendered version1.99.1); it is a semantic citation, not a claim that Kani's pinned compiler is1.99.1.

## Residual data and exact constructor

`IDa_Deployed.Uninstalled CoreError` has exactly adapter, currentBase, stageBase, reserved, query, geometry. These six fields have **NO complete installed component** in this constructor's imported installation chain; the three Ops records and query/geometry records retain their unfilled slots as supplied data. No whole free Configuration, finish callback or Boundaries callback is an input. `indexError : CoreError` is the original error-value data parameter; `reservation` retains both success/error alternatives.

`seed missing reservation` fills all nine Configuration fields explicitly. `deployedConfiguration missing indexError reservation` then applies `FIq_Install.configuration indexError (seed missing reservation) reservation`, which is FIp on the FIq seed, then Rc5/Rc3/Rc2 and release selection. ARX's own FIp selection is left visible in the theorem statement; `selected_fields` checks its finish/boundary/std projections. No full configuration equality is claimed.

The actual consumer chain is DrvC_Installation.sdk → DrvI_Installation.sdk → ClaimsUnrolledSdk.sdkOps, with Uni current/TX2 stage installations, RowShape_InstalledSlots/NativeBuffers and Claims. These paths fix additional leaves but do not supply a globally closed native extraction or a fully concrete runtime dictionary.

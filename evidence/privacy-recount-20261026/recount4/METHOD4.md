# Recount 4 method and scope

Mechanical audit only. No proofs, Rust, Kani, extraction or release replay is run.
All branch reads use immutable git revisions from pins.json; no sibling is checked
out or edited. Recount 1–3 and original rows remain intact. Current classifications
and statuses are additional fields, never replacements of historical fields.

Each original definition is read at every available pinned branch: its path,
git blob, SHA-256 and declaration are recorded in definition-audit4.json. For
unchanged scoped facts, the previous exact statement/guards and original evidence
remain applicable; a changed LOG file is not a changed mathematical definition.
New source evidence is captured content-addressably by capture4.py. A declaration
name, selected callback, source-reference equation or successful import alone is
not native or deployed closure. rows4.json records the individual derivation,
residual, definition witnesses, closure route and import paths for every row.

OPEN buckets are exclusive: (d) exact shared extraction failure first; (c)
unresolved owner action; (b) actual native interpretation/RunJoin/selected Records
identification/model instance; (a) otherwise independent proof/evidence work.
Native allocation effects (op32) belong in (b), not a pure library gate. Only
DOITM firmware/kernel configuration remains owner-first after D248. All other
native facts are proof obligations under the capped trust decision.

D248 classification is applied without adding rows: V329 is entropy_law; V406
records the adopted aggregate of exactly entropy_law, entropy_kernel, observation
(with entropy_law overlapping V329). V371 is the explicitly retained L3 hardware
trust exception pending DOITM. Former native T rows become P, retaining their
unproved residuals; they are not silently admitted as extra TrustItems fields.
Classical ROM/P1 (V391) is a C experiment/model boundary, not a new OS trust field
or a claim of a computational SHA proof. REDUCED still means unresolved, not
proved. T row counts must not be read as counts of independent trust fields.
V400 becomes P: option B is adopted, reached-failure witness independence is not.

Closure labels distinguish CLOSED-ON-CANDIDATE (extraction), (P6 gate),
(extraction bridge) and (axiom diagnostic), with a normalized candidate total.
P6 credit is explicitly candidate/reference-scoped, with the native harness
bounds and selected carrier retained. It never asserts unbounded native equality
or deployment. V179's later length-two String gate is disclosed separately.

Import labels use the research headline and actual candidate consumer roots,
including the wire caller's defining module and the applied op223 V164 bridge.
The graph uses pinned imports; a closing law must have the identical theorem
body in its consumer revision (import-only differences allowed). Every wire path
is independently checked against IMPORT-CHAIN.md. An imported definition for an
OPEN/REDUCED row is membership only, not premise discharge. CBL publication
modules and arbitrary audit modules are not invented consumer roots. Missing
objects or source-resolution gaps remain explicit; rebuild authority is (h'),
not the superseded 2026-10-15 pin table. No shared source is overwritten.

The 20 helper invocations are #check/#print only, Env-J44500 onward, capped
6G/8G/no swap/-M7000, one at a time. Their complete receipts include failures.
Original branch proof receipts are reused, and are kept distinct from these
new statement checks. A missing object is not a row counterexample or a passing
check. Endpoint premises removed/added/weakened by this recount: 0/0/0.

## Method registered before measurements

Scope: v2 canonical M31/CM31/QM31/WideExact arithmetic, CT full-width
reducers and eager zero tests; raw pole equality/folding and the fixed
1024-row/4096-comparison scan; tagged 16-limb compression; actual linked
witness row-reader/no-pole call sites, TLS omission and retry callers.
Canonical/nonzero operands and valid fixed public geometry are preconditions;
public exponents/lengths are held fixed. Inversion validity and the final
retry decision are separate boundaries, never silently classified CT.

Build the unmodified host libraries with `optimized-terminal,ct-host-prover`
in release mode, four Cargo jobs, default native x86_64 target, no target-cpu
override. An evidence-only executable under this directory retains named
non-inlined wrappers for individual kernel entry points and also links and
can execute the actual fixture prover. Wrapper lowering is supplementary:
a wrapper audit alone does not certify an inlined copy in the prover. Audit
the linked actual call sites separately. No shipped source patch is permitted.
Record SHA-256/size for every executable; do not commit binaries or keys.

Disassembly: GNU objdump Intel syntax and nm symbol sizes. For each retained
kernel record symbol/start/end/instruction count, branch/operand-index/latency
findings and callees. Review conditional branches with operand provenance,
not a grep-based assertion. DIV/IDIV on secret operands or a secret-derived
branch/address is STOP for that kernel, with instruction retained. CPU
instruction-latency coverage that cannot be justified stays unresolved.

Timing pre-registration: one primary run per kernel, 100,000 observations
per class (200,000 total), after 10,000 untimed warmup calls. Balanced class
labels are shuffled with a reproducible PRNG before measurement. Class 0
uses all-zero canonical operands (one for nonzero inversion); class 1 uses
uniform pseudorandom canonical operands (reject zero for inversion).
Reducers use fixed zero vs full-width pseudorandom integers. Public exponents
are fixed at 31. Pole scan classes are no pole vs one pole at the last active
slot, identical public masks and array lengths; equality/fold use unequal vs
equal secrets. Scan data are prepared outside the timed interval. Tagged
compression uses fixed vs random 16-limb tuples with fixed nonzero lambda.
One call per observation; compiler black_box barriers retain inputs/outputs.
Use serialized x86 RDTSC/RDTSCP with LFENCE and record TSC ticks; bind to one
allowed logical CPU, record sibling topology/governor/current frequency/turbo
state, and retain raw class/tick samples. No outlier trimming or post-hoc
choice of sample size/classes. Welch two-sided t statistic on raw ticks is
the primary statistic: |t| >= 4.5 is DETECTED; |t| < 4.5 is NO DETECTION IN
THIS EXPERIMENT, never proof of no leakage. Zero pooled variance is reported
explicitly. Multiple kernels and first-order sensitivity are limitations;
no claim of an experiment-wide false-positive bound is made.

Quiet-host prerequisite: record uptime/load and populated scopes immediately
before and after. Launch timing only with no competing compute scopes and
1-minute load <= 1.0; no changing this threshold after seeing timings.
MemoryHigh=6G, MemoryMax=8G, MemorySwapMax=0, TasksMax=64; one scope at a time,
reservation against 55 GiB; never raise caps. CPU policy is observed, not
modified globally. A contended/interrupted run is INVALID, retain it and
report why rather than accepting its statistic.

Whole-proof comparison: require two distinct valid witnesses for the exact
same serialized public statement, checked before timing. Different public
statements or merely changing masking coins does not satisfy this test.
If such a pair is available, randomized balanced order, 100 proofs per class,
fresh reproducible fixture coins per proof, proof generation timed separately
from preparation/verification; verify every resulting proof. Report means,
standard deviations, medians, range, Welch t and empirical CDF maximum gap.
Use the same |t|=4.5 threshold as a distribution diagnostic, not a privacy
proof. If no valid pair is available, report NOT RUN with the exact missing
fixture; never substitute transfer versus withdrawal. If the shared host
cannot become quiet, leave timing open and retain the preflight evidence.

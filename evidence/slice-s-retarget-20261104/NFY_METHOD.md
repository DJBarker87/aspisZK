# Reusable canonical forest retarget procedure

1. Start from the exact selected occurrence certificates, not function-name resemblance. Recursively enumerate EVERY Lean theorem record in each selected certificate, including auxiliary domain/frame/receiver/alignment proofs absent from the old aggregate import. Resolve names before consulting a graph filtered to already-loaded modules; that filtered graph is not a complete certificate inventory. NFX_S_PACKET_PATHS.json gives measured paths to defects; NFY_diagnose.py computes their 289-module union and records source declarations and certificate-qualified tokens. Follow actual import edges beyond these shortest paths before copying.
2. Reuse canonical RPz7/RPt/RPu/SInt2 objects already admitted by the headline forest, and NFN/NFS prefix proofs. Record the exact module/namespace mapping. Copy cached inputs into an owned cache; never mutate a predecessor or session A worktree. Preserve canonical export precedence, then SInt2 root/objects, then fallback. NFY_seed.py and NFY_PRIORITY_PINS.json document this job's selection; per-attempt dependency fingerprints additionally pin resolved Aeneas and direct-import bytes.
3. Store immutable source text once in NFY_SOURCE_GRAPH.json. NFY_collect.py resolves committed inputs with git show for sparse paths. Generate prefix-owned modules bottom-up. NFY_generate.py records source path/hash/line range and exact before/after bodies; `--check` verifies deterministic regeneration. Replace only imports and qualified proof/owner names, including names embedded as meta-tactic string prefixes. Never copy a shared type owner into a new module.
4. Drop an unrelated aggregate import only when the copied body is unchanged and every used declaration is provided by its actual canonical owner. The compiler checks sufficiency; the full scanner checks the loaded forest. NFY's two explicit import cuts are scalar serialization and the wide serializer window. Do not infer irrelevance from a name or from a passing source validator.
5. Compile the smallest generic transport and focused dependent module first. Fully qualify emitted helpers where a canonical standard-library helper shadows the original short name. NFY_OwnerTransport.map_err_transport proves exact full-Result equality, including callback failure/divergence, with no axioms. A heartbeat/memory failure is isolated and split before another attempt; never raise a limit. L029's terminal validator is split into a predecessor module, the validator alone, and its consumers. Record every changed identifier and statement.
6. Use the unchanged S2W launcher, admission exit0 AND allowed:true, and one own scope at a time (6G high / 8G max / swap0 / tasks64, Lean -M7000). NFY_run.py is a worker-owned client, with an exclusive local marker. It records target/command, source revision/hash, dependencies/Aeneas, exit/time/RSS/swap and full axiom lines. Recover submitted transport failures read-only. Never resubmit an uncertain attempt.
7. Compose with the actual headline and all NFX admitted forest in ONE import. Adapt only the admitted driver's module/root lists and runtime filenames. Preserve the NEP walker bytes, retain the driver diff, and run the eight fixtures with the exact compiled binary. Audit raw roots and perform the full scanner: zero dangling constants, incompatible owners and import mismatches, including metadata/recursors. Derive import baselines from committed sources, never the candidate scan being tested. Compatible cached theorem replicas are reported separately, never mistaken for incompatible owners.
8. Replay unchanged source validators and the NFX ledger builder in a private output sandbox. Add checks; waive none. Preserve source-validator history and emit an additive per-row delta only if canonical theorem statements/provenance, combined audit, fixtures and coherence scan all pass. Propagate denied selected-callee claims; no qualification disappears by renaming alone.
9. Commit each stage without attribution or push. Store every evidence input, compress files over20MB with uncompressed SHA-256, exclude only transient locks/caches, remove Python bytecode, and retain owned cache and task keys. No shipped-file change means no ELF rebuild trigger; inherited ELF hashes must be labelled inherited.

Successors must choose their own module prefix and evidence directory, consume committed NFY results by copying with provenance, and run their own combined audit for any additional closure. Do not duplicate a proved NFN/NFS/NFY proof or import an unvalidated WIP as credit.

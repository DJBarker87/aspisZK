## Event interpretation

NIA_EventInterpretation.eventCode enumerates all twelve NFP kinds: opening, dots, trace, geometry, circle, fields, line, product, double, one, subtract, accumulate. It uses NFS_CallerDomains.ops on the SAME base, rather than retaining arbitrary callback slots. event_seed_independent uses the existing no_seed law; every slot is selected concretely. The interpreter contains no read constructors; its empty-query Trace and arbitrary-context frame are proved structurally. There is no digest-bearing constructor in this alphabet.

**Remaining:** equality between this explicit interpreter and the *native* effects of the cuts. pureCall is a proposed pure effect boundary, not a theorem that a native call has no hidden syscall. Replaying the marked calls is not a proof of native root execution: unmarked indexing, equality, from_fn and observer operations must also be installed. Existing NFS Result/mark-trace certificates do not identify SdkC_Source.Query effects. The native cut-to-effect interpretation remains OPEN. No arbitrary events have been added to repair it.

## Scalar stopped packets

BlockStop retains primitive SAME-input partial-dictionary edges, exact Aeneas Error or div, all earlier replies and no suffix. It assumes no complete block/scalar Result equation. BlockCoverage.complete proves every partial-dictionary block is either the existing NGT successful Block or a BlockStop, without a success hypothesis. Coverage's failed/diverged corollaries classify returned block failures. ScalarFailures then propagates the packet through the actual PreparedModel.scalar/scalar_k and provides full-log frames. No payload-length precondition is introduced.

**Remaining:** a physical producer for partial dictionary edges. Rust Digest32 returns [u8;32]; the partial model's Error/div are not Rust Err variants. A constructor logger returning Err at that boundary would change its signature. Native syscall/abort/partial-semantics correspondence needs its exact source boundary specified. No finite Kani run is advertised as proving divergence. No short-payload scalar rejection exists in the inspected frozen source.

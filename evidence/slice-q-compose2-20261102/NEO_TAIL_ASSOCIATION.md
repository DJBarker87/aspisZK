# Complete constructor and borrowed opening association

The checked constructor packet uses the actual frozen FibreIndex::new, not the
unchecked Usize alias used by an old draft. K067/K068 quantify over every native
usize, compare both Ok payload and precisely IndexOutOfRange, and reject every
other Err. E010 extracts the independent branch reference. L052.checked maps its
single error code to the actual cohort op12 token. L059.admitted/accepted bind the
same input and accepted payload/bound. No input canonicality premise is added.
The geometry gather reads and casts its actual query before this constructor;
NEO_GeometryGather.accepted and NEB_GeometryIndices.aligned show the exact initial,
parent, aligned-left and aligned-right arguments. Since the native constructor
packet covers every usize, all these calls satisfy its domain, including the
first rejecting query. The index carrier is lossless on the two reachable
Result alternatives. It borrows no mutable memory and makes no observable oracle
calls. Rust error/ABI/std interpretation and NativeContractSemanticTransport
remain explicit root qualifications, not inner equality assumptions.

K071/K072 compare the actual opening on an arbitrary complete 57607-byte backing
allocation at every i<22 to E010's independently extracted safe reference. Equal
pointer and length832 in the same immutable allocation imply all selected byte
values and preserve its frame; no borrowed-return contract is substituted.
L052.opening is equality of the entire checked Result, including wrapping offset
arithmetic. L059.opening gives the exact bytes via the existing Port4B theorem.
The cohort op for opening is Port4B_Opening.opening installed by Port5Q1_QueryPorts;
NEB_InstalledOpening.same_return/accepted_query derive the same current ordinal
from the actual query read. The existing Port3_NativeQueryFrame.query_read_bound
proves next<22, using that same p.queries allocation. The root proof backing is
57607 bytes in both transactions. This closes this child use only; it does not
close query_values or transfer a theorem about an unrelated opening buffer.

Both native pairs use deployed features, offline frozen graph and unchanged
frozen lock, the exact KMX patch and matching failing K069/K070 controls. All
logs are local and no Option<fn> property or writable static is used. No
historically quarantined or suspended result is restored. Result, immutable
state/frame, ordered effects (none for these pure child bodies), native/source
and reference/cohort association are all checked separately.

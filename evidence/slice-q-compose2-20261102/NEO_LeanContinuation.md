Native K080 was terminal before this stage. No native run was repeated or added.
The continuation compiled the independent parser associations rather than
stopping when native credit was unavailable:

* L060/L061: opaque four-byte read lemmas and exact eight-byte reference Result.
* L063/L064: generic checked prefix/word locality, arbitrary CM31 slices and
  injective full carrier (both rejection and success).
* L066/L067/L069: two-CM31 QM31 plumbing, generic checked fixed windows,
  arbitrary QM31 slices, full carrier and pure frame.
* L070/L078/L082: all eight little-endian wide words, fixed32 association, then
  the complete wide Result on every length, including early wrong-length reject.
* L072: exact CM/QM reference binding to S8OwnedP6 via existing full transports.
* L073: generic approved-KMX selected bytes, disjoint frames and source rebasing.
* L077:17 ordered inverse model calls, all product/square reply laws/canonical
  domains witnessed, exact extracted addition-chain return, and zero assertion
  failure. This does not assert a native nonzero whole-body bridge.
* L080: short checked-slice failures and first-invalid-field rejection before
  touching a later window, preserving the source rejection prefix.
* L085: exact emitted weights.field32-byte selected view and unwrap, including
  symbolic machine-address arithmetic without wrap on its stated caller bounds.
* L086: one focused co-import of48 owned modules and98 top-theorem axioms audits;
  exit0,2.343955s,4932628KiB peak RSS,swap0, all standard axioms.
* L083: current four_dots_one scalar and all three QM31 tail-window bounds in
  the same608-byte input; no scalar/field product is normalized.

Rejected drafts are preserved by attempt. No failed declaration or its sorryAx
error-recovery output earns credit. No sorry, axiom, admit, native_decide,
heartbeat increase or recursion increase was added. Tiny closed scalar literals
are used only for fixed byte counts and source constants. Generic copy lemmas
are over KMX_CopyMeaning; no alternative native copy stub was written.

The independently compiled model laws do not imply a native arbitrary-backing
heap/borrow refinement. Native K053/55/57 use bounded16/32/64-byte allocations.
The complete joins for their actual caller allocations, and the same installed
cohort occurrence/Result/state/effect associations, are not registered. The
window review explicitly remains native-window-only. This is why the parser
rows are still OPEN even though the Lean value/reference theorems now compile.

Similarly, the inverse normal path native check runs a logged source fission;
the actual zero path is directly tested. Exact token erasure and legal model
calls are useful, but do not alone constitute an adopted proof that the actual
frozen nonzero invocation returns that same value with the same effects. Its
row remains OPEN. The false drafted zero label `.panic` was corrected to the
actual emitted `.assertionFailure`; Rust's panic interpretation is retained.

Every remaining function/edge is enumerated in NEO_REMAINING.json. Beyond these
independent model proofs, additional wrappers would merely repackage an open
native equality, heap/caller association, missing out-of-slice bridge or owner
adoption. No such assumption is hidden in a CLOSED certificate. Remaining work
requires new native budget/evidence or the named boundary/adoption, rather than
an unchanged Lean replay. The headline per-attempt soundness target, privacy
and two-transaction design are unchanged.

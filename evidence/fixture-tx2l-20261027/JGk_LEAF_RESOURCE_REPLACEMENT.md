# Leaf prefix proof shape

Native packed-key values are transported by the inherited KeyDecode.packed theorem. Leaf hashes are imported returning facts; their byte buffers and digest selectors are kept opaque. The physical scratch is a chain of at most twelve symbolic array writes. Each fresh leaf is justified by the previous written index; each body returns the actual Continue tuple. The source loop unfolds one step per named body and composes to the unchanged terminal continuation. No verifier, slot, batch or accepted wrapper success is supplied as a premise.

Rejected attempts 052–054 concern source syntax/elaboration and a missing simplification of the self-equality conditional in a last-write projection; none is a timeout or memory kill. The view append theorem was removed from the local helper because the imported write_prefix already supplies it; the actual scratch prefix construction does not need another copy.

# Emission association scope

JHf_Configuration.emission has an accepted exact-source receipt. It proves success of the selected installed source-runtime model on the real statement using JHb_EmitAdapter.source. This is stronger than choosing a constant successful reply: the model validates the exact statement/result, executes the actual checked codec, checks the result's full width/header, and records the source syscall event with the emitted bytes.

It does NOT prove that the frozen native emit_result/syscall is interpreted by this model. JHf_EmissionAssociation (prepared draft) states the full selected op53 function identity and exact state/event result, but neither that identity nor a computed return is a native-to-ELF association. No D188/native fidelity credit is claimed; mutable result-encoding stores remain subject to the narrowed boundary.

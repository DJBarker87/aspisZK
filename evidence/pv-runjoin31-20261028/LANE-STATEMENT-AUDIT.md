The source root is the frozen private `pair_forest_trace::lane_root`, not a
caller-selected digest. The structural source check binds its exact body to
the owned Rust reference. The finite native comparator compiles a name-only
copy of that private body against the pinned native leaf/parent functions;
it does not claim to invoke the inaccessible private symbol directly.

The owned reference changes ownership of the Copy witness, extracts the
conditional parent call into an owned helper, unrolls exactly the twenty
levels, and types those fixed counts as u32. Every difference is explicit.
`LaneCounts31.shift` checks the usize/u32 count conversion for every level in
Fin20. `LaneOrientation31.step_original` is the checked transport of
all branch conditions and operand order. `LaneFold31.fold_append` gives full

prove any of these claims.

`LaneDenotation31.complete_result` quantifies over every extracted Pair and
every ExternalLinear dictionary. Its target equates the complete emitted
Result to the leaf-first recurrence on List.range20, with both Result layers.
It has no success, canonicality, fixture or selected-input hypothesis. This
is a theorem about the source-associated owned reference, not a Kani theorem
or a side-channel theorem.

statements are explicit. Error adapters enumerate every constructor. `native`

outer fail/div and every inner Rust error. `successful_root` is a consequence

actual parent source results into any field K with characteristic P. It is
symbolic induction on the finite sequence of parents. The checked
`LaneRootField31.successful_root` assumes only the successful native call and
canonical membership siblings; it concludes canonical root words and their
field denotation. It neither assumes semantic Admission nor HonestInput.
`LaneCanonical31` is the checked specialization to the actual decoded
snapshot -> frozen outer wrapper route, deriving the sibling guards from
successful native runtime validation on that same witness.

Only accepted per-target receipts establish checking status. Draft statements

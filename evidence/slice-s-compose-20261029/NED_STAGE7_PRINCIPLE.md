# New edge shapes and their limits

1. Immutable field selector: K024/K025 assemble all six tuple coordinates
from the same original public record, using an arbitrary selector and word/byte
position. K028–033 check addresses or variant tags. K040 is address-only and
unpaired: it carries no copied-value/native semantic credit.
2. Abstract native caller control: K034/K035 execute the frozen validator and
compare its full Result and ordered call log to a mechanically checked source
fission. Cached child replies range over their full typed Results. The source
checker rejects a changed error map or call order. Callee Results must still be
associated with the adopted functions at those SAME arguments before any
root certificate can use this control fact.
3. Decoder borrowed window: K036–039 check exact payload slices and discriminator
and the common Box pointer at the reached payment call. Prior child replies
are reachability overapproximations. They are not model/value substitutions.
4. Boxed immutable child reply: NEC 8cdc45079a's imported shape composes an
arbitrary immutable afterstate child Result. Its library/allocator/ABI and
P6/D188 semantic transport qualifications remain explicit. NED's model
composition discharges the emitted child-execution equality; native child
association and root PhysicalInterpretation still need their own instances.
5. Raw cohort control fission: after a deterministic heartbeat exhaustion,
only the map-error/try and comparison prefixes are factored, then separately
proved against the already composed total late encoder. This prevents
reduction of the generated 1520-byte update program while comparing controls.

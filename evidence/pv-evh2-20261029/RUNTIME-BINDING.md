# D508 runtime binding

`PV_EVH_RuntimeBinding.rtDeployed` is a **partial binding with named missing
DATA**, not a supplied live runtime. No `OpenDeploymentInputs` value is claimed.
`privacy_headline_deployed_events_at` specialises the original statement and
bound to this binding. `DeployedLinks` is the authoritative specialised list.
No source simulator, model runtime, successful-only observer or erased failure
prefix is substituted for a missing deployed field.

Provenance aliases below resolve to the exact revision, path, Git blob and full
SHA256 in `binding-source-pins.json`. Source hashes pin the existing Lean
extractions/interfaces; they are not a new Rust/body-identity certification.
The read-only object chain is in `runjoin-resolution-*.json` and `prepare-*.json`.

The additional `invocation_OPEN` maps every original invocation to
`NativePublication55.Input T`; the real store and dictionary are explicit
parameters. This is missing native caller selection, not a new trust item.
`CapturedTransport60.complete` transports original pre-capture Result cases;
`NativeOriginalPublication60.complete` uses it to connect the exact actual and
model publication functions under the Produced links. It is cited, not assumed
as a finished runjoin link or rebuilt merely to create another wrapper.

Option-B's existing source counterexample theorem
`PV_OptB_SourceErrorSignal.success_vs_second_entropy` has explicit body/retry
hypotheses. It does not provide two admitted deployed equal-public witnesses;
we do not promote it to a deployed V400 refutation or replace the full signal
by its coarse entropy-error Boolean.

`LivePublication` names the separate nonempty actual publication-domain obligation
for this exact binding. It is unproved, is not added to T, and is not silently
assumed by the specialised theorem.

## Domain, substitution and induction

The constructor starts terms0 with raw limbs equal to the checkpoint's64 canonical weights. On each query the caller must establish canonical power, rho, rhs/value and node; NCI's accepted-resume model theorems derive the stored scalar domains. The incoming folded query value/node still need their own same-call producer bridges. `NCI_BasisBounds` derives the six stages1..32, writes<64, disjoint source/destination indices and terms advances for next10..21. It does not infer a native trace from model success.

At a group boundary raw<2^34. `NCI_ResidueBounds.product_bound/group_nowrap` proves each canonical limb product bound and every four-product sum fits U64. `NCI_ResidueWords.product_sum` proves the **checked emitted word primitives** succeed with exactly the cast/product/add natural values. `NCI_ResidueInvariant.step_valid/run_valid/run_mod` proves flushes at terms%4=3 retain raw<2^34 and preserve the exact sum moduloP, by induction on arbitrary products. Finish reduces, rather than silently assuming raw canonicality.

The only scalar reducer substitution returns exactly x%P and is paired with `NCI_PendingReducer.reducer_ok` on everyU64. The multiplication window uses the approved opaque-call-log form: native code records exact operands and arbitrary canonical reply; `NCI_FieldLog.instantiate` selects the actual emitted ok/product-mod-P reply within that class. No nonlinear assume or multiplication body is proved in Kani. Full `(stub,theorem,domain)` table is `LPh_STUBS.md`.

## Lower bridges and why remaining work needs native evidence

**VecRow64** is a lower std/native row-index/carrier/lifetime bridge, not an assumption that value returns the desired answer. **FilledRows64** is the exact U00 fallible allocation/initialization/ownership law for64 four-U64 rows. Both must concern the same buffers and indices as the caller. Pure U01 operations reuse the merged NBG/LPf/LPi bridges on their stated canonical/raw domains; their callback/dictionary installation in the adopted enclosing caller still needs source association. No unrelated U00 member blocks a getter or an independent basis/flush window.

All remaining parents need native pre-state/argument/borrow/iterator/call association or an open actual lower bridge. Their arithmetic, cursor, canonicality and model traversal obligations have been discharged or explicitly reused above. More conditional wrappers or duplicate model inductions cannot establish those native facts after Kani exhaustion. The next concrete deliverable is Raw1768/Weight64Native for U11 and UpdateRowNative/VecRow64 for U10, using the retained cache and unchanged caps.

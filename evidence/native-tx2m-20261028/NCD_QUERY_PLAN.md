# Query request observer

Regenerated NCD_queries.patch from frozen source plus the exact retained NBS/NCB scratch patch chain; NCB's unlaunched patch is not applied. This checks actual Transcript::queries request slices, ordering and unchanged replies. The queries_from_pairs summary overapproximates its Result; numeric sampler association remains an explicitly named lower bridge, not proved by the observer. No SHA evaluation occurs.

Before any positive request credit, run verifier::NCB_prefix::copy_negative against the same scratch source, lock/graph, KMX bodies and compilation configuration. It must fail the intended assertion, not time out. Every native run is optimized, offline, freshly admitted and validates the frozen lock graph and unchanged post-run lock hash. Runtime query values stay the existing SHA realization trust row. Parent syscall validity, lifetime, rejected-prefix composition and full caller ownership remain open until proved separately.

Transport and proof counters are separate. NCD_L002 has no receipt and is unresolved; it is conservatively reserved as a used compile slot, never retried. NCD_L004 stopped during admission only, with no compile launch. Retargeting generic offsets deliberately excludes concrete fixture tail certificates because they are not used by the generic native bridge.

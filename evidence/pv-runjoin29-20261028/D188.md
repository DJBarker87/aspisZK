# Per-function fidelity boundary

The EJR-resolved snapshot decoder constructs its twenty frontier cells as an
explicit array of twenty canonical-digest decoder return values. Its final
validator receives exactly that array and successful return preserves it.
No mutable data-borrow restoration is discarded in this path. The snapshot
validator and its digest/frontier loops read arrays without mutating them;
their only changing state is the loop index. The payment public validators
perform reads and comparisons. No XR-prefixed source/model/object is used.
The loop body proofs and symbolic induction retain the exact emitted functions.
This inspection is specific to these functions; no general D188 claim follows.

The raw-output native probe is a rejected candidate: its proposed inequality
fails because raw and canonical owner inputs have identical commitments. It
is not a source-refinement theorem or an admitted-domain counterexample.

# Receipt interpretation

All charged Lean attempts are retained, including syntax/type failures, the
controlled memory-review stops, and the interpreter memory exception. A failed
candidate's `sorryAx` diagnostic is never credited as an accepted theorem.
Every accepted proof is audited against the permitted standard axioms.

Admission refusals are not charged. The first refused 42056 was retried after
180 seconds with the same ID. Refused 42059 and the prematurely queued Unroll
check were both blocked before a compiler started; the cooldown guard prevented
a scope and neither consumed an attempt. The refused RootD attempt 42096 remains
unspent; compile-free work corrected the earlier installation's missing section
terminator. After the full cooldown the same unspent ID is assigned to that
necessary installation correction. The whole-root D law is included in the
combined supporting audit, rather than charged twice as an independent module.
Charon composition's refusal was retried after 180 seconds with a fresh receipt
suffix and the identical unlaunched extraction target.

Two native gate metadata labels were manually mistyped. Original receipts and
feature records are preserved beside corrected records. The corrections are
supported by exact frozen Rust inputs (720 pre-launch hashes), not by a rerun.
The fixture main's bytes are also checked against the correct pinned revision.
Later native wrappers read the frozen revision file directly. The original
metadata errors and corrections do not supply universal native equality credit.

The 262-field formal ExternalFuns dictionary exceeds Lean runtime IR's field
limit. Its installation is a noncomputable mathematical dictionary, as in the
accepted serializer carrier; the emitted arithmetic reference remains separately
executable. Section closing errors are retained as failed compile attempts.

The final three reserved IDs audit/replay the supporting emitted-reference and
carrier facts. They are not a claim that V244 or the privacy endpoint is closed,
and no full frozen privacy manifest replay is justified by this partial result.

fn q(a:[u32;4])->QM31{QM31{c0:CM31{a:M31(a[0]),b:M31(a[1])},c1:CM31{a:M31(a[2]),b:M31(a[3])}}}
fn words(x:QM31)->[u32;4]{[x.c0.a.0,x.c0.b.0,x.c1.a.0,x.c1.b.0]}
fn canonical(x:QM31)->bool{x.c0.a.0<P&&x.c0.b.0<P&&x.c1.a.0<P&&x.c1.b.0<P}
fn check(b:bool){assert!(b != cfg!(NKM_invert))}
#[derive(Clone,Copy,Debug,PartialEq,Eq)]
struct Event{kind:u8,a:QM31,b:QM31,out:QM31}
struct Log{replies:[QM31;7],events:[Event;7],len:usize,inverse_some:bool}
fn event(l:&mut Log,kind:u8,a:QM31,b:QM31)->QM31{
 assert!(l.len<7);assert!(canonical(a)&&canonical(b));
 let out=l.replies[l.len];kani::assume(canonical(out));
 l.events[l.len]=Event{kind,a,b,out};l.len+=1;out
}
fn square(l:&mut Log,a:QM31)->QM31{event(l,0,a,a)}
fn add(l:&mut Log,a:QM31,b:QM31)->QM31{event(l,1,a,b)}
fn inverse(l:&mut Log,a:QM31)->Option<QM31>{
 let out=event(l,2,a,QM31::ZERO);if l.inverse_some{Some(out)}else{None}
}
fn sub(l:&mut Log,a:QM31,b:QM31)->QM31{event(l,3,a,b)}
fn product(l:&mut Log,a:QM31,b:QM31)->QM31{event(l,4,a,b)}
pub fn secure_circle_point_from_parameter(
    parameter: QM31, l: &mut Log,
) -> Result<SecureCirclePoint, CirclePointError> {
    let square = square(l,parameter);
    let denominator = add(l,QM31::ONE,square);
    let inverse_denominator = inverse(l,denominator)
        .ok_or(CirclePointError::SingularParameter)?;
    Ok(SecureCirclePoint {
        x: { let n=sub(l,QM31::ONE,square); product(l,n,inverse_denominator) },
        y: { let n=add(l,parameter,parameter); product(l,n,inverse_denominator) },
    })
}
pub fn secure_ood_circle_point_from_parameter(
    parameter: QM31, l: &mut Child,
) -> Result<SecureCirclePoint, CirclePointError> {
    // Check the singularity first so `t = ±i` has the precise algebraic error
    // even though those two roots also lie in CM31.
    let point = child(parameter,l)?;
    if parameter.c1 == CM31::ZERO {
        return Err(CirclePointError::ParameterInCm31Subfield);
    }
    Ok(point)
}
pub fn circle_fallback_point(sample: usize,l: &mut Child) -> SecureCirclePoint {
    let parameter = CIRCLE_FALLBACK_PARAMETERS[sample % 2];
    match child(parameter,l) {
        Ok(point) => point,
        // Unreachable: `c1 = 1 ≠ 0` for both parameters.
        Err(_) => SecureCirclePoint {
            x: QM31::ONE,
            y: QM31::ZERO,
        },
    }
}
fn new_log(inverse_some:bool)->Log{
 let a:[[u32;4];7]=kani::any();
 let replies=[q(a[0]),q(a[1]),q(a[2]),q(a[3]),q(a[4]),q(a[5]),q(a[6])];
 let zero=Event{kind:0,a:QM31::ZERO,b:QM31::ZERO,out:QM31::ZERO};
 Log{replies,events:[zero;7],len:0,inverse_some}
}
#[kani::proof] #[kani::unwind(40)]
#[kani::stub(core::ptr::copy_nonoverlapping,KMX_copy_nonoverlapping)]
fn circle_full_cut(){
 let t=q(kani::any());kani::assume(canonical(t));let some:bool=kani::any();let mut l=new_log(some);
 let out=secure_circle_point_from_parameter(t,&mut l);
 assert_eq!(l.events[0].a,t);assert_eq!(l.events[0].b,t);assert_eq!(l.events[0].kind,0);
 assert_eq!(l.events[1].a,QM31::ONE);assert_eq!(l.events[1].b,l.replies[0]);assert_eq!(l.events[1].kind,1);
 assert_eq!(l.events[2].a,l.replies[1]);assert_eq!(l.events[2].kind,2);
 let expected=if some{
  assert_eq!(l.len,7);
  assert_eq!(l.events[3],Event{kind:3,a:QM31::ONE,b:l.replies[0],out:l.replies[3]});
  assert_eq!(l.events[4],Event{kind:4,a:l.replies[3],b:l.replies[2],out:l.replies[4]});
  assert_eq!(l.events[5],Event{kind:1,a:t,b:t,out:l.replies[5]});
  assert_eq!(l.events[6],Event{kind:4,a:l.replies[5],b:l.replies[2],out:l.replies[6]});
  Ok(SecureCirclePoint{x:l.replies[4],y:l.replies[6]})
 }else{assert_eq!(l.len,3);Err(CirclePointError::SingularParameter)};
 check(out==expected);
}
struct Child{parameter:QM31,reply:Result<SecureCirclePoint,CirclePointError>,count:usize}
fn child(t:QM31,l:&mut Child)->Result<SecureCirclePoint,CirclePointError>{assert_eq!(l.count,0);l.parameter=t;l.count+=1;l.reply}
fn child_record()->Child{
 let x=q(kani::any());let y=q(kani::any());let tag:u8=kani::any();kani::assume(tag<3);
 let reply=match tag{0=>Ok(SecureCirclePoint{x,y}),1=>Err(CirclePointError::SingularParameter),_=>Err(CirclePointError::ParameterInCm31Subfield)};
 Child{parameter:QM31::ZERO,reply,count:0}
}

This lane reconciles the headline and fixture namespaces and installed configuration.
It does not establish the full release security contract.

`AspisR1.RPx_Deployed.deployed` retains, among others, runtime entrypoint admissions,
`S2W_DigestExtraction.AeneasExtraction`, a `P1` SHA/oracle hypothesis, runtime syscall
semantics, both wrapper acceptance premises, a deployed pair execution, runtime
persistence, and a bound on issued queries. Co-importing a fixture cannot discharge

`stage : VTop_Stages.Ops`, `slot : U64`, and `FixturePdaRuntime base`.

That identity uses a six-field data map into `IDa_Deployed.Uninstalled`.
Neither that map nor the rewriting proves native-code refinement or release-artifact
connection, and no runtime premise is promoted to an adopted trust row.

# Statement and trust-boundary audit

This lane reconciles the headline and fixture namespaces and installed configuration.
It does not establish the full release security contract.

`AspisR1.RPx_Deployed.deployed` retains, among others, runtime entrypoint admissions,
`S2W_DigestExtraction.AeneasExtraction`, a `P1` SHA/oracle hypothesis, runtime syscall
semantics, both wrapper acceptance premises, a deployed pair execution, runtime
persistence, and a bound on issued queries. Co-importing a fixture cannot discharge
these universally or transfer an adaptive security experiment by acceptance alone.

`AspisR1.NDO_Joint.source` quantifies over `base : AdapterRw.Ops`,
`stage : VTop_Stages.Ops`, `slot : U64`, and `FixturePdaRuntime base`.
The runtime premise specifies seven enumerated PDA calls; it remains a hypothesis.
Its own documentation excludes traps, invalid memory, exhausted compute and unlisted
calls, and supplies no artifact identity. This task preserves that premise.

`NDR_CombinedAudit.sourceOnHeadline` preserves those quantifiers and the four
joint witness conjuncts (two TX1 wrapper results, saved-byte equality/length, TX2
wrapper result). It only rewrites the two native arguments with `firstNative`
and `secondNative`, themselves consequences of `NDO_InstalledIdentity.finalInstalled`.
That identity uses a six-field data map into `IDa_Deployed.Uninstalled`.
Neither that map nor the rewriting proves native-code refinement or release-artifact
connection, and no runtime premise is promoted to an adopted trust row.

The old phase alias remains FirstCaller.Phase via `retainedCarrier`. The emitted
producer phase is nominally distinct. Release None observers are explicitly mapped
with `observerToFirst none` and simplified by `noneToFirst`; a callback bijection
is not an arbitrary adaptive execution transport. The 23 reused replay source
changes and the three edited NDO copies are recorded in NDR_ADAPTATIONS.md.

All result claims must be read against the receipts: the combined source is only
prepared until NDR_A001 exits successfully and audits the two roots and helper
lemmas with standard axioms. Frozen Rust, protocol parameters, features, wire format,
and deployed artifacts have not been changed by this lane.

The prepared combined audit also checks each of the 76 historical gap module names
against the kernel environment import header and emits one exclusion marker per
name. These checks remain unexecuted until the sole combined replay.

The predecessor NDJ_RELEASE_MANIFEST.md also records 105 nonstandard imported
axioms that were unreachable from its audited roots (F-AXIOM remains OPEN).
Standard-only `#print axioms` for this lane's theorems is a reachable-root audit,
not a claim that the entire imported library contains only standard axioms.
This lane does not adopt or discharge those inherited import-wide findings.
Likewise, identifying installed constants is narrower than instantiating every
headline trust/game hypothesis; any final closure claim must preserve that limit.

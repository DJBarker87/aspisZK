# Proposed reconciled trust inventory for the replayed TAS_FinalB closure (NPI_, 2026-11-10)

Target not yet established. This is a proposal for the lead to adopt or amend. It edits no existing document, ledger row, trust row, contract text or frozen source. No row is removed: rows that the replayed cones do not reach are kept and marked UNREACHED or NOT-IN-CONE with the evidence.

## Basis

- Theorems: `AspisR1.TAS_FinalB.deployed_splitB` and `AspisR1.TAS_FinalB.deployed_charge` as credited on the L187 replayed objects (evidence/replay-l187-20261109/L187_FINAL_REPORT.md).
- Reachability: the L187 final raw ax2 REACHABLE lists, splitB sha256 0b316cbb…0090 (146,370 constants) and charge sha256 4ae9686f…6a58 (146,551), both re-hashed here before use. A constant counts as reached only if it is in both lists.
- Ledger: evidence/ledger30-20261111/NNN_LEDGER.json.xz (25 trust rows, 40 reviewed-transcription inventory entries, 599 rows).
- Census: NPI_L004 (one capped scope on the replayed objects) confirmed that all 1,099 ledger and RT roots exist in the closure and that all 146,446 cone names resolve.
- Machine-readable form: NPI_TRUST_REACH.json, which is generated by NPI_reach.py.

How a row can enter the theorems:

| Mode | Meaning |
|---|---|
| BINDER | a universally quantified hypothesis in the printed kernel statement |
| RUN_FRAME | a conjunct of `NOC_Run5bHost.retained` inside `S_host.GameFrame`. It is the hypothesis `run.frame` in deployed_splitB, and it sits inside the averaged event `Runs` in deployed_charge, where it is not a hypothesis |
| INSTANTIATED | the Lean structure is built by a term at the top. The row stays as the physical reading of what the term models |
| WINDOW | a window law of the (bn) stage1/stage2 fission, consumed by `NMV_ConcreteWindows.root240/root344` |
| LEDGER | a CLOSED ledger row whose root, or whose restated top field, is in the cones uses the row |
| META | the frozen function that makes the call is on the deployed path whose model is in the cones, but the CLOSED certificate root that uses the row is not in the cones. The row is needed to read the model as the physical run, not for the Lean proof |
| TOOL | tool trust (extraction, Kani, compiler), reached whenever its output is in the cones |

old caller-supplied `Renderer`. `NNC_ObservedWeak.transport` decorates EVERY
NMN_064.Native outcome, including parse reject/fail/div, resolved Rust Err,
modeled fail/div and the independent C04-stopped arm. It preserves the native
weak high-level Result/events law. `NNC_ObservedLaw.w` has exactly the
V2Lib.tx2auth shape and `writeFree` covers all observations, not only Ok.

`NNC_DigestTrace.Step.attempted` retains exact parts AND the complete partial
Result. `Step.pending` retains an unanswered syscall without inventing a
reply or continuation. The RSL event projection contains completed digest
replies only, because RSL.Event.digest has no failed/pending reply constructor;
the complete native attempts/pending calls remain in the observation witness.
No event is sorted, deduplicated, or reconstructed from a flat address.
`NNC_C04Trace.read_trace` proves that its answered projection is the original
charged native history and preserves pending parts. This proof requires no
Root0 or hash injectivity.

The remaining host obligation is literal interpretation of I.f064 as this
native observer (including the per-Env runtime oracle representation), plus
the selected weak-parent native cut/dictionary association. No theorem here
asserts those interpretations merely because an abstract TAS Sig/Impl exists.
An arbitrary/empty renderer is no longer needed for the new weak law, but the
old NNC_G1a.assemble constructor is retained unchanged as historical support.

The source-skeleton native correspondence and each child certificate retain
their existing P6/D188/extraction qualifications. This is event-carrier
composition, not new extraction, Kani, runtime trust, ELF evidence or a repair
of historical emission provenance.
